# 量化前端设计语言

## 信息层级

- 先展示能回答当前决策的问题，再展示解释、分解和操作。
- 首屏限制同级主视觉数量；摘要、主图、排行/明细形成明确阅读顺序。
- 用留白、字号、字重和背景层级组织信息，避免靠重边框和高饱和色堆砌。

## 颜色与金融语义

- canonical 色值来自 `src/theme/`；透明度使用 theme channel/`varAlpha()`。
- 涨为 `error` 红，跌为 `success` 绿，零/缺失为中性。
- 涨跌颜色同时配合 `+/-`、箭头或文字；类别色不借用红绿制造方向误读。
- 不使用装饰性渐变、霓虹、玻璃拟态或大面积高对比黑色壳。

## 排版与几何

- 标题、正文、caption 使用现有 Typography variants；最小 12px。
- 表格数字右对齐，单位写在表头/标签，不在每个单元格重复。
- 间距使用 theme spacing；圆角、阴影和控件高度复用主题或既有组件。

## 状态与可访问性

- loading 不造成布局跳变；empty 与 error 语义分开；retry 可操作。
- hover 不能是唯一入口；键盘焦点可见；IconButton 有 accessible name。
- 动效短、可中断，并尊重 `prefers-reduced-motion`。

## 桌面范围

- 默认视口 `1440×900`，兼顾常见更宽桌面。
- 不为移动、平板、触控或窄屏新增专用布局，除非用户明确改变产品范围。
