# 前端方案检查表

## 业务与契约

- 用户、入口、核心问题、主动作、成功/失败明确。
- 数据权威来源、刷新/新鲜度、权限和敏感性明确。
- POST 路径、Body、响应、错误、`null`、日期、单位和兼容性明确。

## 页面与状态

- 信息层级按决策价值排序，主要任务在首屏可发现。
- 路由、View、私有组件、共享组件和 Hook 边界明确。
- 远程、URL、局部交互、认证和图表状态所有权明确。
- loading、empty、error/retry、stale/partial、forbidden、disabled、submitting 明确。

## UI/UE

- 使用 `src/theme/` 和既有组件，无重复设计常量。
- 涨红跌绿同时配合文字/符号；图表类别色不滥用涨跌色。
- 表格、图表、筛选、Drawer/Dialog 的键盘和焦点行为明确。
- `1440×900` 无页面级 overflow；暗/亮主题和 reduced-motion 在影响范围内可用。

## 性能与质量

- 路由懒加载、数据请求、缓存、取消、长列表和重型图表生命周期明确。
- API/纯函数/Hook/组件/E2E 的测试边界明确。
- 验收命令、fixture、浏览器步骤和回滚方式可执行。

## 原型

- 新页面或重大重构具有可编辑 HTML/SVG 源文件。
- 原型使用真实或明确标注的 fixture，不包含密钥与私人数据。
- 已渲染并人工检查桌面层级、溢出、状态和可访问性。
