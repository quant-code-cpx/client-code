# 前端设计文档模板

按适用性保留以下结构，删除无信息章节，不填模板废话。

## 1. 业务理解

- 用户、入口、核心问题、主要/次要动作、成功和失败。
- 金融口径、数据来源、新鲜度、权限和待确认技术事实。

## 2. 现状与问题

- 当前路由、View、组件、API、状态与测试地图。
- 问题、证据、影响和对应改进；新页面可标记不适用。

## 3. 契约与数据

- API 路径/Body/响应/错误表。
- 日期、单位、精度、空值、枚举和 fixture/MSW 策略。

## 4. 信息架构与交互

- 页面结构、组件树、状态所有权和交互流。
- loading、empty、error/retry、权限、提交和边界状态。

## 5. UI 与原型

- 视觉层级、主题 token、图表/表格规则、键盘和可访问性。
- 原型源文件、`1440×900` 渲染、视觉检查结论。

## 6. 实现与验收

- 受影响文件与实施顺序。
- 测试、性能、兼容、回滚和可执行验收命令。
