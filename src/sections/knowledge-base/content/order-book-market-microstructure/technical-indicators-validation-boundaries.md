技术指标是对价格、成交量或时间的确定性变换，不是独立于这些输入的新事实，更不是收益因果关系。要让结果可复算，研究开始前应冻结一份“计算合同”：证券与交易场所、时区和交易日历、逐笔或 K 线频率、K 线聚合规则、原始价或复权价、成交量单位、缺失值政策、窗口是否跨会话、初始化、最少有效观测数、舍入精度，以及信号可见后允许在哪个时点成交。软件参数 `adjust` 常指指数加权的有限样本归一化，不能与除权除息的“复权价格”混为一谈。

## 移动平均 {#simple-moving-average}

简单移动平均（SMA）给最近 `n` 个数相同权重。若输入为收盘价，完整窗口的定义是 `SMA(n,t) = (C[t] + C[t-1] + ... + C[t-n+1]) / n`。必须同时写明输入字段和窗口端点；“20 日均线”通常指 20 个交易日收盘价，而不是 20 个自然日，也不当然等于 20 根任意频率 K 线。

以表中数据为例，`SMA(3,t3) = (10.20 + 10.50 + 10.30) / 3 = 10.3333`，`SMA(3,t4) = 10.5667`。若把窗口改为 2，`SMA(2,t3) = 10.4000`。这不是计算误差，而是参数改变了被平均的信息范围。研究报告应保留未舍入值，展示时再统一舍入。

初始化政策要明确：严格完整窗口时，t1、t2 的三期 SMA 应为缺失；允许“至少一个有效值”的平台可能提前输出不同结果。遇到缺失 K 线，跳过缺失、把缺失计入时间衰减、前向填充或直接令该窗口无值，含义都不同；前向填充还会人为制造零收益。日线通常跨交易日滚动，盘中执行基准则可能在每个会话重置。拆股、分红等公司行动前后的价格若不在同一复权口径，均线会出现机械跳变。SMA 平滑了噪声也带来滞后，价格穿越均线只是所定义条件成立，不保证随后方向。

## 指数移动平均 {#exponential-moving-average}

指数移动平均（EMA）让较新观测获得较大权重。递推形式为 `E[t] = alpha * x[t] + (1 - alpha) * E[t-1]`，其中 `0 < alpha <= 1`。常见“跨度 n”约定取 `alpha = 2 / (n + 1)`，但也可直接给 alpha、半衰期或质心；它们是参数化方式，不是唯一自然定律。Wilder 平滑常取 `alpha = 1 / n`，不应与跨度为 n 的标准 EMA 混称。

有限历史上至少有三种常见起点。对表中收盘价取跨度 3，故 `alpha = 0.5`：

- 以首个观测为种子并递推：`E1 = 10.20`，`E2 = 10.3500`，`E3 = 10.3250`，`E4 = 10.6125`。
- 先用前三期 SMA 作种子：`E3 = 10.3333`，之后 `E4 = 0.5 * 10.90 + 0.5 * 10.3333 = 10.6167`。
- 对现有有限样本的指数权重归一化：t3 的权重为 `1、0.5、0.25`，故 `E3 = (10.30 + 0.5 * 10.50 + 0.25 * 10.20) / 1.75 = 10.3429`。

三者在短样本上不同，历史足够长时影响才逐渐衰减。完整实现还要固定最少观测数、缺失值是否消耗一个衰减间隔、等间隔还是按真实时间衰减、是否跨会话，以及复权价格版本。把平台显示值当作“标准答案”而不记录这些设置，无法复现。EMA 反应较快并不等于更准确；alpha 越大，滞后较小但噪声敏感度通常越高。

## 相对强弱指标 {#relative-strength-index}

相对强弱指标（RSI）比较同一序列近期上涨与下跌的平滑幅度，并不是一只证券相对另一只证券的强弱。先定义 `Delta[t] = C[t] - C[t-1]`、`G[t] = max(Delta[t], 0)`、`D[t] = max(-Delta[t], 0)`。Wilder 的 n 期口径先用前 n 个价格变动初始化 `AvgG`、`AvgD`，再递推：

`AvgG[t] = ((n - 1) * AvgG[t-1] + G[t]) / n`

`AvgD[t] = ((n - 1) * AvgD[t-1] + D[t]) / n`

`RS[t] = AvgG[t] / AvgD[t]`，`RSI[t] = 100 - 100 / (1 + RS[t])`。

表中取 `n = 3`，前三个变动为 `+0.30、-0.20、+0.60`，因此 t4 的 `AvgG = 0.3000`、`AvgD = 0.0667`、`RS = 4.5`、`RSI = 81.8182`。t5 上涨 0.20 后，Wilder 平滑得到 `AvgG = 0.2667`、`AvgD = 0.0444`、`RSI = 85.7143`；t6 下跌 0.30 后为 `AvgG = 0.1778`、`AvgD = 0.1296`、`RSI = 57.8313`。n 个变动需要 n+1 个收盘价，不能把“3 期 RSI”误写成只需 3 个价格。

若平均损失为 0 且平均收益大于 0，RSI 按极限取 100；平均收益为 0 且平均损失大于 0 时取 0；两者都为 0 时原式是 `0/0`，实现可能返回缺失、50 或其他约定，必须声明。Cutler RSI 用简单平均，另一些实现用 `2/(n+1)` 的 EMA；种子、预热长度和缺失值政策也会造成差异。70、30 和 14 期只是常用设置，不是普适阈值；高 RSI 可能与持续上涨并存，不能由“超买”直接推出反转。

## 移动平均收敛发散 {#macd}

移动平均收敛发散（MACD）是同一价格序列两条 EMA 的差。给定快、慢、信号跨度 `f < s` 与 `g`：`MACD[t] = EMA_f(C)[t] - EMA_s(C)[t]`，`Signal[t] = EMA_g(MACD)[t]`，`Histogram[t] = MACD[t] - Signal[t]`。常见的 12、26、9 不是唯一标准，日线参数直接搬到分钟线会改变经济时间尺度。

可复算的 MACD 必须让三条 EMA 使用同一套 alpha 映射、有限样本归一化或递推约定、种子、缺失值政策和复权价格。慢线尚未达到完整预热时，有的平台输出早期值，有的平台保持缺失；信号线又有第二层预热。若回测使用平台最终历史图，却在实盘只能获得未完成 K 线上的即时 MACD，还会混入可见时点差异。

MACD 上穿信号线只表示“快慢均线之差超过其自身平滑值”，柱体缩短也只是差值变化，不自动等于趋势反转、收益为正或风险下降。它与 SMA、EMA 高度同源；把三者同时“确认”不能机械地算作三份独立证据。

## 布林带 {#bollinger-bands}

布林带以滚动均线为中轨，以同一窗口价格的标准差形成上下轨。对 n 个收盘价，`M[t] = SMA_n(C)[t]`，`U[t] = M[t] + k * sigma[t]`，`L[t] = M[t] - k * sigma[t]`。带宽可写为 `Bandwidth[t] = (U[t] - L[t]) / M[t]`；中轨为 0 或接近 0 时，该比率没有稳定含义。20 期、两倍标准差是创作者的常用默认值，而不是对所有证券和频率都最优的定理。

标准差分母必须明示。表中 t1—t3 收盘价均值为 10.3333，离差平方和为 0.0466667。总体标准差（`ddof = 0`）为 `sqrt(0.0466667 / 3) = 0.1247`，取 `k = 2` 得上下轨约 `10.5828、10.0839`；样本标准差（`ddof = 1`）为 `sqrt(0.0466667 / 2) = 0.1528`，上下轨变成 `10.6388、10.0278`。同样的数据和“2 倍标准差”因 ddof 不同就会给出不同边界。

实现还需固定均线类型、价格字段、窗口完整性、缺失与会话政策。滚动价格并非独立同分布正态样本，上下两倍标准差不能直接解释为“未来价格有 95% 概率留在带内”；当前价格还参与了当前均值和标准差。触及上轨也不是自动卖出信号。参数、证券、频率和成本后的样本外表现，才是应检验的对象。

## 真实波幅 {#true-range-atr}

真实波幅（TR）把当期高低范围和相对前收的跳空放在一起：`TR[t] = max(H[t] - L[t], abs(H[t] - C[t-1]), abs(L[t] - C[t-1]))`。第一根记录没有前收，可令 TR 缺失，或明确采用 `H - L`；两种做法会改变首次 ATR 的位置和值。平均真实波幅（ATR）可用 n 期简单平均，也常用 Wilder 递推：先以 n 个 TR 的简单平均为种子，之后 `ATR[t] = ((n - 1) * ATR[t-1] + TR[t]) / n`。

若表中 t1 取 `H-L = 0.60`，则 t2、t3、t4 的 TR 分别为 `0.50、0.50、0.70`；t4 的 0.70 捕捉了相对 t3 前收 10.30 的上跳。前三期种子 `ATR(3,t3) = (0.60 + 0.50 + 0.50) / 3 = 0.5333`，Wilder 更新得到 `ATR(3,t4) = (2 * 0.5333 + 0.70) / 3 = 0.5889`；三期简单滚动 ATR 则为 `(0.50 + 0.50 + 0.70) / 3 = 0.5667`。若每个会话重置前收，t4 的 TR 只剩 `11.00 - 10.60 = 0.40`，隔夜跳空被排除；这必须是研究目的驱动的显式选择。

拆股等公司行动前后的高、低、前收必须处于一致价格口径，期货连续合约的换月拼接也会制造非经济跳空。ATR 是价格单位的范围指标，不是收益率标准差，也不直接给方向；若除以收盘价形成百分比 ATR，分母时点和异常价格仍需说明。

## 成交量加权均价 {#vwap}

逐笔成交 VWAP 的基本式是 `VWAP = sum(p[j] * q[j]) / sum(q[j])`，其中只纳入事先定义窗口和资格范围内的成交，`p` 是成交价，`q` 是股数、合约数或名义金额中的一种一致权重。分母为 0 时结果应为缺失。开收盘竞价、大宗交易、盘后成交、更正或撤销记录是否纳入，取决于市场数据和研究定义；“VWAP”不天然指全市场、全日或所有场所。

只有 OHLCV K 线时，常见代理是用典型价 `P* = (H + L + C) / 3` 乘柱成交量。表中 A 会话三根柱的代理 VWAP 为 `(10.1333*100 + 10.4000*150 + 10.4000*200) / 450 = 10.3407`；B 会话为 `10.9215`。若错误地不在会话边界重置，六根柱合并值为 `10.6602`。会话切分改变指标，不是小数位差异。

柱级代理无法从高、低、收推回柱内真实成交分布，因而不等于逐笔 VWAP。成交量还要区分单边统计、双边统计、合约数与名义金额。VWAP 可以是执行基准或场内交易统计，但不是基金净值、证券“公允价值”或保证可成交的报价；价格高于 VWAP 也不能单独证明买方付贵了，因为决策时点、订单方向、规模和机会成本都未被控制。

## 突破 {#breakout}

“突破前高”若只凭图形目测，研究者可在知道结果后移动窗口和阈值。可编码的一种事前定义是 `B[t] = 1{C[t] > max(H[t-n], ..., H[t-1]) + delta}`：使用此前 n 根高点，明确排除当前高点，`delta` 可预先设为固定跳动单位、百分比或只由 t 时点已知数据计算的波动缓冲。还要冻结用收盘、盘中成交还是报价触发，等号如何处理，连续几根确认，以及停复牌、涨跌幅限制和公司行动的处理。

若以 t 时点收盘确认，信号直到该收盘形成后才可见，回测不能仍按 t 的收盘价无摩擦成交；通常至少使用下一可交易事件，并模拟跳空、盘口深度和未成交。若要求随后 h 根 K 线确认，信号时间应记为 t+h，不能把标记回填到 t。滚动窗口必须只读当时数据版本。

突破条件只是历史价格相对关系。它可能反映新信息、订单失衡，也可能是噪声、机械除权或短暂流动性冲击；触发不等于因果，更不保证继续上涨或下跌。实务上应同时报告未触发样本、假突破定义、等待与成交规则，并与简单持有或风险匹配基准比较。

## 支撑阻力 {#support-resistance}

支撑、阻力若要进入验证，必须从“区域直觉”改写成当时可计算的函数。例如，可把 `S[t] = min(L[t-n], ..., L[t-1])`、`R[t] = max(H[t-n], ..., H[t-1])` 定为滚动支撑与阻力，再用预先冻结的容差 `delta` 定义区域 `[S-delta, S+delta]` 和 `[R-delta, R+delta]`。也可用历史成交密集区、分位数或枢轴点，但价格字段、窗口、权重、聚类方法和区域宽度必须逐项写明，不能混成同一个指标。

局部低点若定义为“两侧各 k 根都更高”，右侧 k 根在当时尚未知；该点只能在 k 根之后被确认。回测可把它作为 t-k 时点的图形标注，但交易信号不得早于确认时点。触碰次数也须按当时已存在的区域计算，避免先看完整历史再挑“多次有效”的水平线。

支撑或阻力不是法律约束，也没有统一精确价位。报价最小变动单位、价格限制、复权、跨会话缺口和流动性会改变观察结果；一次穿越既不能证明区域失效，也不能证明未来必然延续。更可靠的表达是条件命中率、收益分布和不确定区间，而非“价格一定守住”。

## 趋势线 {#trendline}

手绘趋势线容易随结论移动锚点。一个可复现替代是，在 t 时点仅用过去 n 根数据，对 `y[i] = log(C[i])` 与时间 `tau[i]` 拟合 `y[i] = a + b*tau[i] + epsilon[i]`，并保存 n、是否取对数、时间单位、回归损失、异常值政策和最低观测数；t+1 的趋势线预测为 `a + b*tau[t+1]`。若用两个高点或低点连线，则锚点选择、并列处理和枢轴确认延迟也要算法化。

等间隔 K 线可用序号作时间，但有停牌或不规则逐笔数据时，序号斜率与真实时间斜率不同。中心窗口、全样本回归或用未来第二锚点画回历史都会泄露未来。趋势线“突破”还需给价格字段、缓冲、确认、信号可见和成交时点，不能仅以图上交叉计收益。

斜率描述所选窗口内的价格方向，不是结构性增长率；换窗口、线性价或对数价、是否复权都会改变它。拟合优度高也不证明趋势会延续。趋势线的价值只能通过预先定义、样本外和成本后比较来评价。

## 参数敏感 {#parameter-sensitivity}

参数敏感是指结论对窗口、阈值、平滑、价格字段、会话或成本假设的小变化反应很大。前述算例已经显示：t3 的 SMA 从三期 10.3333 变为两期 10.4000；同一跨度 3 的 EMA 在首值种子、SMA 种子和有限样本归一化下得到不同早期路径；布林带的 `ddof` 改变上下轨；VWAP 是否按会话重置则从两个局部基准变成 10.6602。平台默认值只提供起点，不提供经济正当性。

实务检验应事先确定合理参数区域，展示收益、回撤、换手、命中率等“参数曲面”，观察相邻参数而非只报最优点；同时改变数据供应商、起止日、频率、复权和执行假设。参数选择本身必须留在训练或内层验证集，外层样本外只评估已冻结方案。若不断查看外层结果再调参，外层也已成为训练数据。

大片相邻区域表现较稳定通常比孤立尖峰更可信，但仍可能来自共同样本偏差或某一历史制度。对参数不敏感也不等于有因果优势；应报告尝试总数、选择规则和失败规格，而不是只展示事后赢家。

## 指标同源 {#indicator-redundancy}

许多指标只是同一 OHLCV 的不同滤波：SMA、EMA、MACD 和布林带主要变换收盘价；RSI变换收盘价差；TR/ATR 增加高、低和前收；柱级 VWAP 又由 OHLC 与成交量近似。它们同时给出相似方向，可能只是重复放大同一价格趋势，而不是多条独立信息。

可在严格样本外把指标标准化后检查相关矩阵、滞后相关、主成分和条件数。若相关矩阵特征值为 `lambda[i]`，诊断性的有效维数可写为 `N_eff = (sum lambda[i])^2 / sum(lambda[i]^2)`；它取决于样本、状态和标准化方法，不能当成真实“独立信号数”。线性相关低也不排除非线性或共同尾部暴露。

实务上先写每个指标新增的经济信息：是价格趋势、区间、成交参与、流动性，还是完全不同的数据来源。把三个同源指标设为“三票通过”可能只是更严格的同一个过滤器，并增加参数和多重检验。真正的增量价值应通过剔除一个指标后的样本外差异、稳定性和成本变化验证；“确认越多越安全”没有普遍保证。

## 重绘 {#repainting}

重绘不是单一现象，应按信息何时可得拆开：

- 未完成 K 线的高、低、收、量持续更新，依赖它的指标同步变化，这是实时数据的正常属性；只有 K 线结束后数值才冻结。
- 居中均线、双侧滤波或需右侧 K 线确认的枢轴会利用未来观测；若把确认后的值画回原时点，历史图很漂亮，但信号当时不可得。
- 数据商可能更正错单、晚报成交或历史 K 线；公司行动复权会把新信息回填到更早价格，连续期货换月规则也可能重建历史。
- 算法或平台版本、会话划分和时区变更会重算历史。多周期指标在高周期 K 线未结束时也会反复更新。

真正的前视偏差，是回测在决策时使用了当时不可见的数据或最终修订值。校正办法是同时保存事件时间与可用时间、原始数据快照或 vintage、复权因子发布日期、指标版本、K 线完成状态和信号首次产生时点；用当时版本逐步重放，而不是只对最终历史表向量化计算。未来确认的枢轴可以合法使用，但成交必须延后到确认之后。

重绘本身不必然意味着指标无效，更不能只靠“图线不重绘”证明策略无泄漏。供应商修订和正常实时更新要与算法偷看未来分开；最终应比较实时可得序列与最终序列的信号差异。

## 多重检验 {#multiple-testing}

每试一个窗口、阈值、证券、样本期、止盈止损或指标组合，通常都增加一次隐含检验。若 K 个检验相互独立且每个显著性水平为 5%，至少出现一个假阳性的概率为 `1 - (1 - 0.05)^K`；K=100 时约为 99.41%。金融规则往往相关，独立公式不能直接给精确概率，但相关性不会自动消除“从许多候选里挑最好”的选择偏差。

偏差还包括反复窥看同一数据、事后选择起止日、只保留存续证券或基金的幸存者偏差、只发表成功规则的发表偏差，以及删除失败尝试后少报试验次数。Bonferroni 控制族错误率较保守，FDR 控制发现中的预期错误比例；选择哪种方法取决于研究目标和检验依赖。预注册候选宇宙、记录所有试验、使用当时成分和退市样本，是任何校正的前提。

White Reality Check 用重采样检验预先给定候选集中最佳模型是否优于基准；SPA 检验通过学生化等处理减少劣质候选对检验能力的拖累；PBO 则以组合对称交叉验证观察样本内赢家在样本外落到较差排名的频率。它们回答的问题和假设不同，不能互换，也不能修复前视、错误价格、低估成本、制度变化或未披露的更大搜索宇宙。最有说服力的结果仍应来自冻结规则后的真正样本外、独立复制和诚实的不确定性表达。

## 成本后验证 {#post-cost-validation}

指标值能复算只是第一关，策略必须在现实交易链上验证。总成本至少包括买卖价差、市场冲击、佣金、交易所及监管费用、税费、滑点、行情与下单延迟、融资利息、借券费及召回、换手、容量约束、部分成交和未成交机会成本；市场、产品、账户和时点不同，不能套一个固定费率。若执行价模型已包含价差与冲击，再另行逐项扣除会重复计费。

买入订单的实施落差可写成一个可复算框架。计划买 `Q` 单位，决策价 `P0`，实际成交 `q` 单位、成交均价 `Pexec`，评估终点价格 `PT`，显性费用 `F`：`IS_buy = q*(Pexec-P0) + (Q-q)*(PT-P0) + F`。第一项是已成交落差，第二项是未成交机会成本；卖出时价格差方向反转。它不是纯粹的市场冲击估计，因为等待期间的共同市场变化也会进入结果。容量测试应让冲击、成交概率和借券可得性随订单相对市场成交量变化，而不是无限按同一收益率放大资金。

验证顺序必须保持时间方向：训练只用过去，验证用于选规则，最终测试集在冻结数据清洗、特征、参数、风险约束、执行和成本模型后只使用一次；滚动或扩展窗口的 walk-forward 每一步也只能读取当时信息。标签持有期重叠时，应在训练与测试边界留出足够间隔，防止同一未来收益跨集合泄漏。基准应可投资且风险、币种和持有期可比，并同时报告毛收益与净收益、换手、容量、成交率、极端成本情景和置信区间。

样本外通过仍不是未来盈利保证：市场结构、税费、参与者和容量会变。上线前可用实时影子组合记录理论信号、实际可见行情、拒单与未成交；上线后也应把与回测的偏离作为新证据，而不是不断回改历史规则。技术指标最可靠的边界，是把它当作可审计的特征和假设生成器，而不是把历史拟合包装成确定性预测。
