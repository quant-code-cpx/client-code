比较全球市场，最容易犯的错误是把一个交易所的一条规则写成某个国家乃至全球惯例。本页采用统一比较键：

\[
\text{比较键}
=\text{市场／场所}
\times\text{证券／产品}
\times\text{投资者身份}
\times\text{账户／渠道}
\times\text{日期}
\]

五项缺一，诸如“T+1”“可以卖空”或“有涨跌幅限制”都不是完整结论。同一发行人的证券可能在多个场所、以不同货币和不同托管链交易；同一场所也可能对股票、债券、基金和衍生品采用不同制度。

先建立一张可复用字段模板：

| 字段组 | 至少记录什么 |
| --- | --- |
| 比较对象 | 法域、监管者、市场与具体执行场所、证券或产品代码 |
| 投资者与渠道 | 居民或非居民、个人或机构、账户类型、直接会员或经纪渠道 |
| 时间 | 当地时区、UTC 偏移、夏令时、交易日期、资料截至日 |
| 交易 | 交易货币、每手或最小数量、价格档位、订单簿或报价方式、交易时段 |
| 波动控制 | 价格限制、个股机制、市场级熔断、临停及恢复方式 |
| 交易后 | 名义交收周期、交易与结算日历、中央对手方／结算机构、客户到账 |
| 权利与成本 | 卖空条件、税费、资产隔离、赔偿或保险、争议救济 |
| 披露 | 语言、会计准则、频率、截止时间、重大事项和官方访问渠道 |
| 版本证据 | 规则名称、文号或版本、生效状态、官方 URL、as-of 日期 |

以下动态示例均核验至 **2026 年 8 月 13 日**，只用于示范比较方法，不代替交易当日对具体市场和产品的重新核查。

## 交易时区 {#trading-time-zone}

交易时段必须同时写当地钟点、时区标识和日期规则。“纽约时间上午九点半”仍不够，因为夏令时会改变它与北京时间、UTC 的对应关系。建议保存 IANA 时区名称，例如 America/New_York，而不是把 EST 当作全年不变的标签。

至少核对四层时间：

1. 订单何时可以录入；
2. 订单何时参与撮合；
3. 开盘、连续、收盘和延长时段分别在哪个交易日；
4. 清算、交收和公司行动使用哪个市场日历。

以截至本页复核日的纽约证券交易所股票为例，核心交易时段为当地东部时间 9:30—16:00。纽约处于标准时，其 UTC 对应时间是 14:30—21:00；处于夏令时则是 13:30—20:00。固定写成“北京时间 22:30 开盘”会在夏令时切换后失效，还会忽略两地切换日期并不同步的短暂窗口。

跨午夜市场还要保存“交易日标签”。某些期货或电子时段在当地前一自然日晚间开始，却归入下一交易日；日线开高低收和保证金日期应按场所规则归属，不能按投资者电脑的零点切割。节假日、半日市、临时停市和严重天气安排也应来自场所年度或临时公告。

## 交易货币 {#trading-currency}

交易货币只是订单、报价和通常结算所用货币，不等于以下三者：

- 发行人功能货币，即其主要经营环境所使用的货币；
- 财务报表列报货币；
- 投资者衡量财富的本币或基准货币。

IAS 21 明确区分功能货币和列报货币；一家公司可以用一种货币经营、用另一种货币编报，而其股票又在不同柜台以第三种货币交易。存托凭证、双币柜台和跨境基金尤其不能从证券简称猜测经济货币暴露。

比较记录应拆成“报价货币—成交货币—交收货币—股息货币—费用货币—投资者基准货币”，再核对券商是否自动换汇、使用何时的汇率、收取何种点差。若一单位交易货币折合投资者本币的汇率回报为 \(R_{FX}\)，证券以交易货币计的回报为 \(R_L\)，忽略费用时本币回报是：

\[
R_{\text{base}}=(1+R_L)(1+R_{FX})-1
\]

因此证券以美元交易，不证明发行人的经营现金流主要来自美元，也不证明中国投资者没有汇率风险。反过来，投资者做了汇率套期保值，也只是改变部分货币暴露和成本，不改变证券的发行法律关系。

## 交易单位 {#trading-unit}

交易单位要分别记录数量最小值和数量步长：

\[
q=q_{\min}+k\Delta q,\qquad k=0,1,2,\ldots
\]

其中 \(q_{\min}\) 是可申报最小数量，\(\Delta q\) 是增加步长。它们还可能随买卖方向、订单簿、证券价格或渠道变化。价格最小变动单位是另一个字段，不能与每手数量混为一谈。

股票市场常见概念包括每手、整手、圆手和零股，但法律和系统含义并不全球统一。截至本页复核日，香港证券的每手股数通常由发行人确定；不足一手的零股不进入自动对盘的整手订单簿，而有专门的碎股交易安排。这说明“港股一手等于固定股数”是错误概括。

在另一些市场，单股甚至经纪商提供的碎股权益可以交易；但经纪商账内的碎股未必能转至另一家机构，也未必享有与直接登记整股完全相同的公司行动处理。美国监管数据中的 round lot 还可能用于报价和行情口径，而不必然等于客户最低可成交数量。

债券通常按面值或名义金额申报，报价却可能按每百单位面值表示；期权、期货则要乘合约乘数。比较“最低投入”时应计算数量、成交价、乘数、应计利息、货币和费用，不能只看屏幕价格。

## 竞价方式 {#auction-method}

市场组织方式至少分为：

| 方式 | 价格如何形成 | 核对重点 |
| --- | --- | --- |
| 订单驱动 | 买卖订单进入订单簿，按价格、时间或其他优先级撮合 | 订单类型、可见性、优先级、开收盘集合竞价 |
| 报价驱动 | 做市商或交易商报出买卖价，客户与其成交 | 报价义务、最小规模、交易商是否以本金身份交易 |
| 混合 | 订单簿与指定做市商、询价或人工机制并存 | 哪些产品、时段或订单使用哪套机制 |
| 场外或询价 | 双边、经纪撮合、RFQ 或电子平台协商成交 | 对手方、报价覆盖、成交报告、清算和透明度 |

集合竞价是在一个时间窗口聚合订单，按规则确定单一或少数成交价；连续竞价则在交易时段持续匹配。开盘价和收盘价常由专门竞价产生，但并非每个证券、每个交易日都必然成功形成竞价成交价。

多场所市场还要区分主要上市地、实际执行地和订单路由地。客户在一个券商界面下单，订单可能被送往交易所、其他交易场所、电子通信网络或由经纪商内部执行。比较成交质量时应同时看价格改善、点差、速度、成交概率、订单规模和路由成本，不能把“上市交易所”自动当作每笔订单的成交地点。

订单驱动不保证流动性更好，报价驱动也不保证随时成交。市场深度、参与者结构、透明度和做市义务必须回到具体产品与时段判断。

## 价格限制 {#price-limits}

“价格不能超过某个范围”可能指四类不同机制：

1. 静态每日价格限制：相对前收盘价或其他基准给出全天申报或成交区间；
2. 动态价格带：相对近期参考价滚动计算可成交区间；
3. 订单价格保护：拒绝明显偏离参考价的委托，未必限制市场最终价格；
4. 经纪商风控边界：比场所规则更窄，只约束该渠道客户。

每条记录需写参考价、上下幅度、适用品种、方向、交易阶段、首次上市或复牌例外、公司行动调整和触发后结果。仅写“涨跌幅 10%”没有可迁移意义。

美国全国市场系统股票的 Limit Up-Limit Down 机制，以滚动参考价格形成个股价格带并阻止价格带外成交；香港交易所的 VCM 采用动态参考价，对选定证券在特定连续交易时段触发冷静期。截至本页复核日，香港交易所明确说明 VCM 不是日涨跌幅制度，也不等同于停牌。这两个例子都不能套用于各自市场的所有证券或全部时段。

触及价格限制不等于一定能成交。订单簿可能只有同方向订单，实际可成交量为零；限制还可能把价格发现推迟至次日或恢复阶段。用收盘“封板价”估算可变现价值时，应同时检查成交量、队列位置和退出机制。

## 熔断 {#circuit-breakers}

熔断要与价格限制、VCM 和监管临停逐项区分：

- 市场级熔断依据宽基指数或全市场条件，协调多个场所暂停；
- 个股波动机制针对单只证券，可能先进入价格带状态，再触发暂停或冷静期；
- VCM 可能限制冷静期内的成交价格而不停掉全部交易；
- 信息待公布、监管调查、技术故障或公司行动导致的临停，不一定与价格波动有关。

比较模板应记录触发指标、参考值、方向、阈值、适用时段、暂停长度、一天可触发次数、订单如何处理、恢复竞价以及是否跨场所协调。

作为特定法域示例，截至 2026 年 8 月 13 日，NYSE Rule 7.12 所述美国市场级熔断以标普 500 指数相对前收盘的单日跌幅设三级阈值：7%、13% 和 20%；不同等级和触发时点对应暂停或当日停止交易。它与单只 NMS 股票的 LULD 价格带是两套机制，不能互称，也不能外推给其他国家、债券或衍生品。

熔断只改变交易过程，不保证止损价格、恢复后价格或损失上限。暂停期间新信息仍可能累积，恢复竞价可能跳空；场外工具、相关期货和其他时区的替代品是否同步暂停，也要分别核对。

## 交收周期 {#settlement-cycle}

\(T+N\) 表示按该制度定义的交易日 \(T\) 后第 \(N\) 个结算日完成标准交收，不表示成交日后经过 \(N\times24\) 小时，更不表示客户银行账户必然在同一刻可取。

完整时间轴是：

\[
\text{委托}
\rightarrow\text{成交确认}
\rightarrow\text{清算与净额计算}
\rightarrow\text{证券、资金交收}
\rightarrow\text{最终性}
\rightarrow\text{客户账户可用／可取}
\]

CPMI-IOSCO《金融市场基础设施原则》把证券结算系统、中央证券存管和中央对手方分别纳入风险管理框架。比较时应核对是否采用券款对付、交收最终性何时发生、净额还是逐笔、是否中央清算、失败交收如何处理，以及托管人和外汇资金链。

名义周期不是全球统一。美国适用的多数经纪交易自 2024 年 5 月 28 日起采用 T+1，但 SEC 规则列有证券和交易例外；截至本页复核日，香港交易所通过 CCASS 完成的通常交易所交易，证券和资金头寸一般为 T+2，而沪深港通部分证券腿又有不同安排。两者只是特定市场示例。

跨境投资还要叠加两地假期、货币到账截止时点、预先备券或备款、托管层级和公司行动登记日。成交具有约束力却发生交收失败时，应按结算机构的补救和违约规则处理，不能简单说“交易自动作废”。

## 卖空制度 {#short-selling-regime}

卖空不是一个“允许／禁止”开关，应拆成六个问题：

1. 哪些证券和哪些投资者可以卖空；
2. 下单前需借到、预借还是仅合理确认可借；
3. 订单如何标记；
4. 是否存在价格测试或触发后限制；
5. 净空头或交易活动向谁报告、何时公开；
6. 交收失败如何补购、关闭和处罚。

证券借贷是取得或调度证券的合同安排，卖空是出售当时并不拥有或通过借入交付的证券，两者相关但不相同。用期权、期货或差价合约取得负向经济暴露，也不必然属于现货规则定义的卖空，却可能进入另一套持仓和披露制度。

美国 Regulation SHO 是法域特定例子：其制度包括 long、short、short exempt 标记，locate、交付失败关闭和在条件触发时的卖空价格测试。香港现货市场则限定可卖空指定证券，并要求满足借券和交易规则。由此不能推出所有合法卖空都必须用同一种预借模式，也不能把“裸卖空”在某地的口语含义直接套到另一地的违法构成。

实际成本包括借券费、抵押品、股息补偿、召回和被迫平仓风险。卖空制度允许不代表券商必然向该客户提供标的；账户权限、库存、所有权申报和跨境限制仍属于比较键的一部分。

## 税费 {#taxes-fees}

税费比较必须固定法域、纳税居民身份、证券法律类型、收入性质、买卖方向和发生日期。国籍、居住地、税收居民和证券上市地可能是四个不同概念，任何缺失都不应给个人税务结论。

成本可分为：

- 交易成本：佣金、平台费、交易所费、监管费、清算费和买卖价差；
- 持有成本：托管费、市场数据费、融资利息和借券费；
- 货币成本：换汇点差、汇款及资金占用；
- 税款：交易税或印花税、股息或利息预提税、资本利得税及其他可能税目。

回转交易的可复算全成本为：

\[
C_{\text{all-in}}
=C_{\text{buy}}
+C_{\text{sell}}
+C_{\text{holding}}
+C_{\text{FX}}
+T_{\text{transaction}}
+T_{\text{income/gain}}
\]

每一项都要标明计费基数、最低收费、方向、币种和生效日。香港股票印花税由香港税务主管机关按时期公布，历史税率表本身就说明费率会变；美国国税局对非居民、美国来源收入、预提和税收协定条件另有规则。这些例子只说明身份与日期的重要性，不构成任何人的纳税建议。

券商页面可能只展示其收取的费用，不包含来源国预提、居住国申报或托管链扣费。税收协定待遇也常取决于实益所有人、表格和申领流程，不能把名义协定税率直接当成实际到账率。

## 盘前盘后 {#pre-market-after-hours}

盘前、盘后和夜间时段要先问“订单只是被接收，还是已经进入可成交订单簿”。经纪商允许提前录入，不等于交易场所已经开盘；不同场所的延长时段也可能不互联。

比较时记录：

- 哪个场所提供时段，以及当地时区和交易日归属；
- 可交易证券、订单类型和有效期；
- 是否有开收盘竞价、做市或统一行情；
- 价格带、最佳执行和订单保护在该时段如何适用；
- 成交如何清算、是否进入官方成交量和哪一个收盘价口径。

截至本页复核日，NYSE 的 9:30—16:00 ET 是核心交易时段；NYSE 集团旗下其他场所还存在各自的早盘或晚盘安排。不能把某个券商显示的“美股盘前盘后”写成 NYSE 上市股票只在 NYSE 同一订单簿连续交易。

延长时段通常参与者更少、点差更宽、深度更浅，公告后的价格可能跳跃。盘后最后一笔成交价不当然替代主要上市市场收盘竞价形成的正式收盘价；指数估值、基金净值、公司行动和日线数据应使用各自方法规定的价格。

## 做市制度 {#market-making}

做市商以规则或合同约定的身份提供双边报价，交易商还可能以自身库存与客户成交。它与普通投资者偶尔挂出双边限价单不同，也不等于交易所承担成交对手方。

比较做市制度至少记录：

| 字段 | 核对内容 |
| --- | --- |
| 资格 | 谁批准或指定，适用哪个场所和产品 |
| 报价方式 | 连续报价、询价回应、竞价参与或混合 |
| 义务 | 最小数量、最大价差、报价覆盖率和指定时段 |
| 例外 | 停牌、极端行情、技术故障和无标的可对冲情形 |
| 激励与约束 | 费用优惠、优先权、资本要求、监控和处罚 |
| 利益冲突 | 本金交易、库存风险、关联发行人或订单流安排 |

订单驱动市场也可以为 ETF、期权或特定股票设置指定做市商，因此“有订单簿”和“有做市”并不互斥。报价驱动的场外债券市场又可能由多家交易商竞争，并通过询价而非中央连续订单簿成交。

做市义务通常只保证在规定条件下达到最低报价标准，不保证任何规模都能成交、价差恒定或价格不跳空。香港交易所针对不同交易所买卖产品和衍生品设有不同的做市商或流动性提供者计划，正说明产品规则不能互套。

## 投资者保护 {#investor-protection}

投资者保护不是“亏了就赔”，而是一组不同风险对应的制度：

- 客户资产和客户资金隔离，降低中介机构挪用或破产混同风险；
- 中介资本、托管和账簿记录要求；
- 最佳执行、订单处理、利益冲突和适当性义务；
- 发行与持续披露、反欺诈和市场操纵执法；
- 投资者赔偿、保险或破产清算安排；
- 投诉、调解、仲裁、行政救济和法院诉讼。

比较赔偿制度时要查成员资格、客户定义、账户归集方式、受保护资产、触发事件、上限、现金子限额、地域或身份限制和排除项。截至本页复核日，美国 SIPC 对符合条件的 SIPC 会员经纪商清算中客户现金和证券缺失提供有限保护，每名客户的法定上限为 50 万美元，其中现金子限额为 25 万美元；它不保护市场价格下跌，也不同于银行存款保险。这只是美国特定制度，不能套成“海外券商账户保险”。

最佳执行也不是保证全市场最低成交价。以美国 FINRA Rule 5310 为例，会员须以合理勤勉评估在当时条件下可获得的最佳市场，判断包含价格、市场特征、订单规模和可达性等事实。其他法域的法律来源、适用主体和衡量方式可能不同。

跨境账户尤其要确认法律上的客户是谁、资产记在谁名下、是否为综合账户、上层和下层托管人分别受哪地法律约束。资产隔离主要应对中介失败，不能消除发行人违约、产品价格、汇率或国家风险。

## 信息披露 {#information-disclosure}

信息披露比较不能只数“每年发几份报告”。应同时记录：

1. 披露语言以及译本是否具有同等法律效力；
2. 采用 IFRS、美国公认会计原则或本地准则，财年是否一致；
3. 年度、半年度或季度报告的频率、截止日和审计要求；
4. 重大事项是持续披露、及时披露还是按表格事件申报；
5. 董监高、主要股东、关联交易和公司行动的披露口径；
6. 原始文件在监管者、交易所还是指定信息系统获取，数据是否可机器读取；
7. 外国发行人、第二上市、存托凭证或特定规模主体是否有豁免和替代安排。

IOSCO 的发行人及定期披露原则提供高层比较框架，但允许各法域按市场和发行人特征落实，因此不能据此假定季度报告、披露语言或具体期限全球一致。公司官网新闻稿和投资者关系演示可以补充理解，不能替代法定申报；数据商时间戳也不一定等于监管系统正式接收或公开时间。

把不同市场指标放在一起前，应统一会计期间、币种、每股口径、持续经营范围和重述版本。披露较频繁不自动意味着信息质量更高；披露较少也不能脱离法定持续披露和重大事项制度作判断。

最后用“误区核对法”收口：

- 这条结论是否写全了市场／场所、证券／产品、投资者身份、账户／渠道和日期？
- 比较的是否是同一种订单、同一交易阶段和同一法律权利，而非相似名称？
- 数字是否附当地时区、币种、计量单位、生效日和官方来源？
- 是否分开监管底线、交易场所规则、结算机构安排和券商执行参数？
- 是否把成交、交收、客户到账，把报价币、功能币、投资者本币分别处理？
- 是否检查了至少一个反例；若另一个场所或产品不成立，就不能称为全球惯例？
