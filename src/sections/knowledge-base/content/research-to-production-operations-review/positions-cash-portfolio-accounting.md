头寸、现金和组合会计是在回答三个不同但必须勾稽的问题：经济上已经承担多少风险，法律或结算系统目前登记了什么，以及按既定会计与估值政策应报告多少净资产。成交发生后，交易账可以立即增加经济头寸；证券和现金却可能仍在交收途中；券商前台、清算、托管和会计总账因职责与截止时点不同，短期不一致并不必然是错误，但每个差异都应有金额、原因和预计消除日。

以下统一案例全部为虚构，不构成投资、法律或税务建议。组合记账本位币为人民币，基金份额固定为1,000,000份，无申购赎回。为复算损益，内部业绩账采用加权平均成本，并把可归属交易费用纳入批次净成本或净收入；法定财务报告仍应按适用准则分类处理。例如，中国现行《企业会计准则第22号》要求常规方式买卖金融资产按交易日确认，并规定以公允价值计量且变动计入当期损益的工具，其交易费用直接计入当期损益。内部成本分析与法定会计科目必须有清晰映射，不能互相冒充。

统一账本跨三个估值时点：

- D0：人民币现金1,000,000元、美元现金50,000美元；持有 `CN-A` 10,000股，历史成本20元、收盘22元；持有 `US-X` 1,000股，历史成本40美元、收盘45美元；美元兑人民币为7.20。
- D1：借入人民币200,000元，年利率3.65%、ACT/365；划出100,000元作为期货保证金，当日变动保证金收益3,000元。买入 `CN-A` 10,000股的订单只成交8,000股，其中5,000股×23.00、3,000股×23.10，费用184.30元，余下2,000股仍为活动限价单并冻结资金。原10,000股在除息日取得每股0.50元股息权利，假设案例扣缴率10%。另借入并卖空 `US-Y` 500股×30美元，卖出费用5美元，D1尚未交收；借券费年率6%、ACT/360。D1收盘：`CN-A` 24元、`US-X` 47美元、`US-Y` 29美元，汇率7.25。
- D2：`CN-A`买入交易交收，2,000股余单取消；收到净股息4,500元并完成500元扣缴。人民币融资累计两日利息40元。`US-Y`卖空交易交收，随后回补200股×28美元、费用2美元但回补款仍在途，余下经济空头300股；两日借券费合计5美元。期货当日变动保证金损失1,200元。D2收盘：`CN-A` 23.50元、`US-X` 46美元、`US-Y` 31美元，汇率7.30。

本例明确采用交易日经济账、结算日现金与托管账并行。真实市场的交收周期、税率、融资、借券、保证金与资金可用规则必须按账户、产品、法域和日期另行核验。

## 初始持仓 {#opening-positions}

初始持仓是一个带截止时点和来源的快照，不是从数据库随手取出的“当前数量”。至少应保存证券、市场、账户、方向、数量、已结算与未结算标志、成本币种、成本法、价格、汇率、公司行动权利和数据来源。

D0组合资产为：人民币现金1,000,000元；美元现金折人民币 `50,000×7.20=360,000` 元；`CN-A`市值 `10,000×22=220,000` 元；`US-X`市值 `1,000×45×7.20=324,000` 元。无负债时初始净值为1,904,000元，每份净值1.904元。

成本与市值必须分开。`CN-A`历史成本200,000元，但D0市值220,000元；权益持仓不是可随时提取的现金。初始持仓还要标明是否已经包含上日成交、待交收交易或公司行动，否则当天成交会被重复加入。

## 成交回报 {#execution-reports}

成交回报是经济头寸变化的起点。订单确认、部分成交、全部成交、撤单和拒单是不同事件；只有权威成交才改变成交数量。每笔应保存唯一成交ID、订单链、交易日、证券、方向、数量、价格、费用、币种、场所及后续取消或更正。

D1的 `CN-A`成交量为8,000股，本金：

`5,000×23.00 + 3,000×23.10 = 184,300` 元，连同184.30元费用形成184,484.30元待交收负债。成交均价为23.0375元；若内部成本批次包含费用，新批次单位成本为 `184,484.30÷8,000=23.0605375` 元。

订单目标10,000股不等于成交10,000股。余下2,000股仍是活动订单，只进入潜在仓位和冻结资金，不进入已成交持仓。成交更正或取消时要以相反事件冲回原记录，不能直接覆盖历史行。

## 在途交易 {#unsettled-trades}

在途交易已经在交易日形成经济权利义务，但证券或现金尚未在结算日完成交付。本例交易日账在D1增加8,000股 `CN-A`并确认184,484.30元应付交收款；托管持仓在交收前可能仍只显示原10,000股。D2交收时，托管证券增加、现金减少并冲销应付款，不再第二次确认买入损益。

美元卖空同理：D1确认15,000美元卖出款应收和500股空头替代义务，D2才把卖出款转入现金。D2回补200股的5,600美元本金和2美元费用尚在途，因此经济空头已降至300股，托管或借券系统却可能仍显示借入500股，直至回补证券交付并归还。

中国现行金融工具准则对常规买卖采用交易日确认；其他法域、基金合同或运营子账可能采用不同显示方式。关键不是强迫所有系统同日相等，而是用在途应收应付把交易日账与结算日账桥接，避免重复资产或负债。

## 可用资金 {#available-funds}

可用资金是按账户规则能够继续下单、划转或提取的金额，不等于银行或券商界面上的现金余额。一般要从现金余额扣除在途买入、活动订单预占、费用税费、保证金要求、提款冻结和其他优先义务，并加入规则允许使用的已结算卖出款或信用额度。

D1人民币现金账在融资到账、保证金划转后为 `1,000,000+200,000−100,000=1,100,000` 元。扣除 `CN-A`在途应付款184,484.30元及活动余单冻结46,446.40元后，案例可用人民币资金为：

`1,100,000−184,484.30−46,446.40=869,069.30` 元。

这个数没有扣除尚未到期的200,000元贷款本金，却应在流动性计划中考虑其到期。卖出款能否当日再用、融资额度能否提款、跨币种现金能否即时兑换，都由具体市场和合同决定，不能凭净值推断。

## 冻结资金 {#restricted-cash}

冻结资金仍可能是组合资产，但在限制解除前不能自由使用。来源包括未成交买单预占、短卖所得限制、保证金、司法或监管冻结、提款指令和交收失败缓冲。冻结不是费用，也不必然减少净值；把自由现金转到保证金账户只是资产内部重分类。

D1未成交2,000股按限价23.20元及假设0.1%费用预占：`2,000×23.20×1.001=46,446.40` 元。D2余单取得权威取消确认后才能释放。另有100,000元转为期货保证金；美元短卖15,000美元所得在D2进入现金，但案例假设继续受短卖安排限制。

系统应分别列示现金余额、冻结原因、冻结金额、开始和预计释放时间。只保存一个 `available_cash` 会让净值账无法解释“钱去了哪里”，也可能在撤单请求尚未确认时过早释放资金。

## 应收股息 {#dividends-receivable}

应收股息在持有人按公司行动和适用会计政策取得收款权利时确认，不等于公告日或现金到账日。权利取决于登记日、除息日、证券借贷和交收状态；不同市场的权利链必须核对。

本例只有D0已持有的10,000股 `CN-A`取得每股0.50元股息，D1确认应收股息5,000元。D1在除息日买入的8,000股不在本例权利范围内。D2收到净现金4,500元，同时冲销5,000元应收和500元应付扣缴税。

除息导致价格机械调整时，股息收入与价格变化要共同计入总回报，不能只看股价跌幅。应收股息也有延迟、撤销、更正和汇率风险，尚未到账时不能无条件当可用现金。

## 应付税费 {#taxes-payable}

应付税费是已发生但尚未支付或扣缴的义务，应与交易费用、净股息和可用资金分开。本例假设股息扣缴率10%，D1确认 `5,000×10%=500` 元应付税费，D2由支付方扣缴后结清，组合收到4,500元。

该10%仅为教学参数。真实税负取决于投资者身份、账户、持有期、证券、税收协定、市场和政策日期；同一公司行动对个人、机构、基金或跨境投资者可能不同。系统要保存gross、withholding和net三个字段，而不是只存到账净额后失去税务桥。

估计税和最终税不一致时，应通过版本化调整记录差额。本文只讲账本闭合，不提供个体税务结论。

## 融资 {#financing}

融资取得现金的同时形成等额负债，不会在借入时创造净值。真正影响损益的是利息、承诺费、抵押品机会成本、汇率和违约或提前还款条款。贷款、券商融资、回购和透支的法律结构不同，不能统一成负现金。

D1借入200,000元后，现金增加200,000元、融资负债增加200,000元，净影响为零。年利率3.65%、ACT/365，两日累计利息为：

`200,000×3.65%×2÷365=40` 元。

D1计提20元、D2累计40元。利息减少净值，即使尚未支付也应进入应付利息。贷款本金未到期不代表没有流动性风险；可用资金和净值分析都要保留偿还时间表与契约限制。

## 借券 {#securities-borrowing}

借券取得的是在约定条件下使用并返还同种证券的安排，不是无偿获得一项多头资产。卖空后，组合取得卖出款，同时承担回购并归还证券的经济义务；还可能支付借券费、提供抵押品、被召回并补偿出借人股息。

本例借入并卖出500股 `US-Y`，卖出款15,000美元、开仓费用5美元。借券费按15,000美元参考价值、年率6%、ACT/360计两日：

`15,000×6%×2÷360=5` 美元。

D2回补200股后，交易日经济空头降至300股，余下空头按31美元计负债9,300美元。回补交易仍在途，借券系统要等证券交付后才可减少实际借入数量。若借券期间发生分红，空头通常还可能承担替代股息支付；具体合同和税务结果需另行核验。

## 保证金 {#margin}

保证金是为履约风险提供的现金或证券担保，不等于衍生品成本、最大损失或合约名义金额。本例期货名义敞口假设为1,200,000元，初始划出保证金100,000元；资产从自由现金转到保证金账户，组合净值在划转时不变。

D1每日结算收益3,000元，使保证金余额变为103,000元；D2损失1,200元，余额变为101,800元，累计期货损益1,800元。若每日变动保证金按规则现金结算，结算后的期货未实现损益可归零并进入现金或保证金余额；盘中仍可能存在未结算变化。

保证金余额充足也不表示风险有限。跳空、价格限制、追加保证金、抵押品折扣和强平失败都可能产生超过初始保证金的损失。不同期货、期权、融资融券和场外衍生品制度不能互套。

## 多币种 {#multi-currency}

多币种账本要同时保存原币金额和记账本位币金额。对每个估值时点，`本位币价值 = 原币数量 × 当时适用汇率`；还要冻结报价方向，本例USD/CNY表示1美元对应多少人民币。交易汇率、估值汇率和实际换汇成交价可能不同。

D0美元净资产为 `50,000现金+45,000 US-X=95,000` 美元，按7.20折为684,000元。D1美元净资产为97,492.5美元，按7.25折为706,820.625元。D2在卖空交收与部分回补后，美元净资产为：

`64,995现金 + 46,000 US-X − 5,602回补应付 − 9,300剩余空头负债 − 5借券费 = 96,088` 美元，折人民币 `96,088×7.30=701,442.40` 元。

D1到D2的美元本位币变化可精确拆成原币变化和汇率变化：`(96,088−97,492.5)×7.25 + 96,088×(7.30−7.25) = −5,378.225` 元。拆分方法必须固定；不同顺序会产生交叉项。受限或缺乏可兑换性的货币还需按适用会计规则处理，屏幕中间价不一定可兑换。

## 估值 {#valuation}

估值是在明确时点、市场和退出视角下给资产与负债赋值。活跃市场证券可采用政策指定的收盘价、结算价或其他可观察输入；停牌、无成交、价格限制和非活跃市场需要估值技术与层级披露。公允价值是计量日市场参与者有序交易中的退出价格概念，不等于历史成本或管理层目标价。

本例D1用 `CN-A=24、US-X=47美元、US-Y=29美元、USD/CNY=7.25`；D2用 `23.50、46美元、31美元、7.30`。多头按可得资产价值计量，空头按转移或结清义务所需价值计负债；买卖价差中的具体取点应按一致估值政策，不可为改善净值在bid、ask、last之间选择。

估值源、抓取时间、时区、价格状态、公司行动和人工覆盖必须保留。券商屏幕价可以是验证源，却不自动成为基金或企业会计的唯一权威价。

## 净值 {#net-asset-value}

净值是估值资产减负债，不是现金余额、保证金余额或累计投入：`NAV_t = ΣAssets_t − ΣLiabilities_t`；每份净值为 `NAV÷流通份额`。本例无外部资金流和份额变化，三日可完整复算：

| 资产或负债（人民币） | D0 | D1 | D2 |
| --- | ---: | ---: | ---: |
| 人民币现金 | 1,000,000.000 | 1,100,000.000 | 920,015.700 |
| 保证金资产 | 0 | 103,000.000 | 101,800.000 |
| `CN-A`市值 | 220,000.000 | 432,000.000 | 423,000.000 |
| 应收股息 | 0 | 5,000.000 | 0 |
| 美元现金折算 | 360,000.000 | 362,500.000 | 474,463.500 |
| `US-X`市值折算 | 324,000.000 | 340,750.000 | 335,800.000 |
| 短卖款应收折算 | 0 | 108,750.000 | 0 |
| 资产合计 | 1,904,000.000 | 2,452,000.000 | 2,255,079.200 |
| `CN-A`交收应付 | 0 | 184,484.300 | 0 |
| 应付税费 | 0 | 500.000 | 0 |
| 融资本金 | 0 | 200,000.000 | 200,000.000 |
| 应付融资利息 | 0 | 20.000 | 40.000 |
| `US-Y`空头负债折算 | 0 | 105,125.000 | 67,890.000 |
| 美元费用及回补应付折算 | 0 | 54.375 | 40,931.100 |
| 负债合计 | 0 | 490,183.675 | 308,861.100 |
| 净值 | 1,904,000.000 | 1,961,816.325 | 1,946,218.100 |
| 每份净值 | 1.904000 | 1.961816 | 1.946218 |

D0至D2总净值增加42,218.10元，无外部现金流时累计收益率为 `42,218.10÷1,904,000≈2.2173%`。融资增加了资产和负债，短卖同时产生应收与替代义务，所以不能通过只看总资产判断盈利。

## 已实现损益 {#realized-profit-loss}

已实现损益必须先固定成本法、交易日或结算日口径、费用、税、币种和汇率。加权平均、先进先出和逐笔指定会给同一卖出不同成本；会计准则对金融工具类别的列报也可能不同。内部业绩归因应与总净值损益勾稽，但不必把所有收入都叫“已实现资本利得”。

本例多头股票没有出售，因此没有股票处置实现损益。`US-Y`开仓净收入按开仓费用分摊后为每股 `30−5÷500=29.99` 美元；回补200股、费用2美元的净实现损益为：

`200×(29.99−28.00)−2 = 396` 美元。

余下300股继承每股29.99美元净开仓基准。期货每日结算累计实现1,800元；净股息4,500元属于投资收入，融资利息40元和借券费5美元属于期间费用。若交易费用在法定会计中已直接进损益，就不能又在处置损益中重复扣除；本文的内部成本分摊只是为了复算批次表现。

## 未实现损益 {#unrealized-profit-loss}

未实现损益是估值与尚未处置头寸成本基准的差额，不是可保证兑现的现金。它依赖估值价、成本法、费用政策、汇率和会计分类；前期已有的未实现损益不能再次当成本期收益。

D2 `CN-A`加权成本总额为 `200,000+184,484.30=384,484.30` 元，市值423,000元，累计未实现收益38,515.70元。与D0相比，其中只有18,515.70元是本观察期新增变化，因为D0已含20,000元未实现收益。

`US-X`原币累计未实现收益为 `(46−40)×1,000=6,000` 美元。若历史成本40,000美元按取得时7.20折算为288,000元，D2市值335,800元，则本位币累计差额47,800元，可按冻结方法拆为价格与汇率效应。`US-Y`剩余300股的未实现损益为 `300×(29.99−31)=−303` 美元；两日借券费另列，不得再次塞入未实现价差。

每日结算后的期货在结算点可没有未实现余额，但合约风险仍存在。未实现为零不等于仓位为零，更不等于不需保证金。

## 账实一致 {#books-and-records-reconciliation}

账实一致不是要求所有系统在每个毫秒显示同一数字，而是每个来源的职责、截止时点和差异桥都明确，且在约定期限内与更高权威记录闭合。交易系统权威于订单与成交事件，券商或清算权威于未结算义务，托管权威于登记证券，银行权威于存款，基金或企业会计账按既定政策汇总；单一系统不能包揽所有事实。

D2关键复核为：

- `CN-A`经济持仓：`10,000+8,000=18,000` 股；活动余单权威取消后为零；
- 人民币现金：`1,000,000+200,000融资−100,000保证金−184,484.30交收+4,500净股息=920,015.70` 元；
- 保证金：`100,000+3,000−1,200=101,800` 元；
- 美元现金：`50,000+15,000短卖款−5开仓费=64,995` 美元，另有5,602美元回补应付和5美元借券费应付；
- `US-Y`经济空头300股，借券/托管数量在200股回补交收前仍可能显示500股，差异由在途交易解释；
- 资产2,255,079.20元减负债308,861.10元，净值1,946,218.10元。

数量和现金不可用“净值差不多”替代逐项核对。每个差异要记录来源、金额、币种、首次出现时间、责任人、预计解决日和最终凭证；来源不明、持续不消除或超过容忍度时，应禁止扩大风险。账实一致是一套持续控制，不是月末一次把残差塞入“其他”科目。
