组合计算的第一原则不是先套公式，而是先固定三类口径：资产和负债在同一估值时点的价值、外部现金流发生在收益区间的哪一侧，以及收益所用币种、费用、税和再投资假设。以下用完全虚构的“澄明组合”贯穿：基础币种为人民币，金额单位为万元，A 为股票、B 为债券、C 为现金；资产收益均为含收入的总回报，暂不计税费、交易成本和管理费。外部申购或赎回只在季末估值后发生，因此每季收益可以准确切开。

| 季度 | 期初价值 | 期初 A/B/C 权重 | A/B/C 单期收益 | 组合收益 | 期末流入（流出）前价值 | 外部现金流 | 流后价值 |
| --- | ---: | --- | --- | ---: | ---: | ---: | ---: |
| Q1 | 1,000.0000 | 60% / 30% / 10% | 10% / 2% / 0.5% | 6.65% | 1,066.5000 | +400 | 1,466.5000 |
| Q2 | 1,466.5000 | 70% / 20% / 10% | -10% / 3% / 0.5% | -6.35% | 1,373.3773 | 0 | 1,373.3773 |
| Q3 | 1,373.3773 | 50% / 40% / 10% | 8% / -2% / 0.5% | 3.25% | 1,418.0120 | -300 | 1,118.0120 |
| Q4 | 1,118.0120 | 55% / 35% / 10% | 4% / 1% / 0.5% | 2.60% | 1,147.0803 | 0 | 1,147.0803 |

这张教学账本刻意把“投资表现”和“投资者投入金额”分开。下文风险数字主要采用历史波动率模型；它是对特定样本和假设的估计，不覆盖违约、流动性、跳空、模型失效等全部风险，也不构成投资建议。

## 持仓权重 {#holding-weights}

在估值时点 `t`，普通现货多头组合的资产权重通常定义为 `w_i,t = V_i,t / V_t`，其中 `V_i,t` 是第 `i` 项持仓的同币种公允价值，`V_t = ΣV_i,t` 是组合净资产价值。三项都必须来自同一时点；把昨收股票、当日债券和未折算外币现金混在一起，权重即使加总为 100% 也没有可比意义。

例中 Q1 期初 A、B、C 的价值分别为 600、300、100，因此权重为 60%、30%、10%。若期内不交易，Q1 收益后它们分别变为 660、306、100.5，总计 1,066.5；流入发生前的漂移权重变为 61.8847%、28.6920%、9.4233%。因此“目标权重”“期初实际权重”“期末漂移权重”和“平均权重”不能互换。

含空头、衍生品或借款时还要同时报告净暴露和总暴露，例如 `净暴露 = Σw_i`、`总暴露 = Σ|w_i|`。净值作分母时，多空权重可以为负且总暴露可超过 100%。期货按名义金额、Delta 等价暴露还是保证金占用计权，会回答不同问题，必须先声明；保证金小不代表经济风险小。现金、应收应付、应计费用和未结算交易也不能无声遗漏。

## 单期收益 {#single-period-return}

若区间内没有外部现金流，且用区间开始时的价值权重，组合简单收益为：

`R_p,t = Σ_i w_i,t-1 × R_i,t`。

Q1 可直接复算为 `60%×10% + 30%×2% + 10%×0.5% = 6.65%`，价值增加 `1,000×6.65%=66.5`。每项 `w_iR_i` 是对组合收益的算术贡献：A 贡献 6.00 个百分点、B 贡献 0.60 个百分点、C 贡献 0.05 个百分点。

公式要求权重和收益使用一致的币种、总回报或价格回报口径及时间区间。400 万元申购是外部现金流，不是 Q1 收益；若现金流发生在区间中间，必须在流入前估值并切分子期间，或明确使用近似现金流调整法。资产层面的分红若已包含在总回报中，组合现金账户又收到一次分红时不能重复计入。

## 多期收益 {#multi-period-return}

相邻期间简单收益必须复利链接，而不是相加：

`1 + R_0,T = ∏_(t=1)^T (1 + R_t)`。

例中四季链接为 `1.0665×0.9365×1.0325×1.026−1 = 5.804969%`。6.65%、-6.35%、3.25%、2.60% 的和为 6.15%，它不是四季实际总回报。

有外部现金流时，价值账本应写成 `V_t^- = V_(t-1)^+×(1+R_t)`、`V_t^+ = V_t^- + CF_t`；上标减号表示现金流前，上标加号表示现金流后。本例最终价值 1,147.0803，投资者现金利润为 `1,147.0803 + 300 − 1,000 − 400 = 47.0803` 万元。这个金额不能用“净投入 1,100×时间加权收益”推导，因为 400 的流入和 300 的流出承担了不同季度的收益。

链式收益还要求期间无缝、无重叠，并保留足够精度到最后一步再四舍五入。对数收益可相加，但当简单收益达到 -100% 时对数不存在；杠杆组合简单收益低于 -100% 时，普通正财富复利解释也会失效。

## 时间加权收益 {#time-weighted-return}

时间加权收益率（TWR）把每次外部现金流前后的估值点作为子期间边界，先算各段投资表现，再按 `∏(1+r_j)−1` 几何链接。它尽量剥离投资者无法归因于投资管理决策的申购、赎回规模和时点，适合比较组合策略或管理人的投资表现。本例现金流都位于季末估值之后，所以 TWR 就是 5.804969%。

这并不表示现金流“消失”：现金流决定下一子期间的资本基数，却不被当成当期投资收益。若只有月末净值而月中发生大额现金流，就不能声称得到精确日级 TWR；需要流时估值，或披露 Modified Dietz 等近似方法及其误差。

截至 2026-08-14，2020 版 GIPS 标准仍把 TWR 作为多数合规展示的核心方法，并在满足特定控制现金流、封闭式或固定期限等条件时允许或要求使用 MWR。GIPS 是自愿采用的全球行业标准，不是对所有账户普遍适用的监管法；本页引用它是为了说明口径，而非宣称本例满足 GIPS 合规要求。

## 资金加权收益 {#money-weighted-return}

资金加权收益率（MWR）把投资者现金流的金额和时点一并纳入，通常求使现金流现值为零的内部收益率。按投资者视角，本例等间隔季度现金流为：

`C_0=-1,000，C_1=-400，C_2=0，C_3=+300，C_4=+1,147.0803`。

季度 MWR 是方程 `Σ_(t=0)^4 C_t/(1+r)^t=0` 的根，数值约为 `r=0.947553%`；若假定四个等长季度且以复利年化，则为 `(1+r)^4−1=3.844426%`。它低于 5.804969% 的 TWR，主要因为追加的 400 在负收益 Q2 前进入，赎回的 300 又在正收益 Q4 前离开。这里 MWR 描述这组投资者现金流的体验，不宜直接归因于管理人。

实际日期不规则时应使用 `Σ C_j/(1+r)^(年数_j)=0`，并披露日数规则、求根区间和年化约定。现金流多次变号时可能出现多个 IRR，某些现金流结构甚至没有实数 IRR；软件返回一个根不代表经济上唯一。此时应列示全部现金流，并辅以净现值随折现率变化、Modified Dietz 或其他清楚定义的回报指标。

## 算术平均 {#arithmetic-mean}

`T` 个单期收益的算术平均为 `R̄_A = (1/T)ΣR_t`。本例四季组合收益的算术平均是 `(6.65%−6.35%+3.25%+2.60%)/4 = 1.5375%` 每季。它是样本中“一期收益”的平均，常用于估计下一同长度期间的期望收益；并不等于投资者实际每季复合增长率。

把它乘以 4 得 6.15%，只是季度期望收益线性年化的表达。在独立同分布、均值存在等假设下，预期单期收益可以这样缩放；它不是本例实际年度财富增长。平均数也容易受极端值、样本选择和非平稳状态影响，应同时报告样本区间、频率、离散程度和是否含缺失或异常值。

截面平均与时间平均也不能混同：同一天 100 只股票的平均收益回答资产横截面问题，一只组合四个季度的平均收益回答时间序列问题。市值加权、等权和资金加权的“平均”各有不同分母。

## 几何平均 {#geometric-mean}

几何平均收益率是使同一初始财富经过每期相同增长后达到相同终值的常数：

`R̄_G = [∏_(t=1)^T(1+R_t)]^(1/T)−1`。

本例为 `(1.0580496859)^(1/4)−1 = 1.420679%` 每季，连续复利四季恰好回到 5.804969%。它低于 1.5375% 的算术平均，差额来自波动拖累；只有各期收益相同等特殊情形，两者才相等。

普通几何平均要求每个财富因子 `1+R_t` 为正。若某期损失 100%，终值为零且后续有限百分比收益不能恢复；若使用杠杆后简单收益低于 -100%，需要回到实际现金流、追加保证金和有限责任边界，不能机械开方。几何平均也不能消除期间选择、幸存者偏差或现金流路径问题。

## 组合方差 {#portfolio-variance}

在固定权重、线性资产收益模型下，组合方差为 `σ_p² = w'Σw`，波动率为 `σ_p = √(w'Σw)`。为避免把动态调仓和风险快照混在一起，本节另冻结 Q1 期初权重 `w=(0.6,0.3,0.1)'`，将四季 A、B、C 收益都按该权重重算，得到 6.65%、-5.05%、4.25%、2.75%，平均 2.15%。

使用样本分母 `T−1=3`，组合偏差为 4.50、-7.20、2.10、0.60 个百分点，样本方差为：

`s_p²=(4.50²+(-7.20)²+2.10²+0.60²)/3 = 25.62 pp²`，

`s_p=√25.62=5.0616%` 每季。若用小数收益计算，同一方差是 0.002562；百分数与小数单位不能混算。

历史波动率不是损失上限，也未描述偏度、尾部、流动性或违约。由季度波动率乘 `√4` 年化，需要收益尺度一致且无自相关等条件；一般多期方差还包含不同期收益的自协方差。动态权重、期权等非线性头寸和交易成本需要更完整的情景或重估模型。

## 协方差矩阵 {#covariance-matrix}

协方差衡量两个资产收益相对各自均值共同变化的方向与尺度。使用同一四季样本、同一频率和样本分母 `T−1`，A 的均值为 3%，偏差为 7、-13、5、1 个百分点；B 的均值为 1%，偏差为 1、2、-3、0；C 每季均为 0.5%。由此得到单位为 `pp²` 的矩阵：

|  | A | B | C |
| --- | ---: | ---: | ---: |
| A | 81.3333 | -11.3333 | 0 |
| B | -11.3333 | 4.6667 | 0 |
| C | 0 | 0 | 0 |

代入权重可复算：`w'Σw = 0.6²×81.3333 + 0.3²×4.6667 + 2×0.6×0.3×(-11.3333)=25.62 pp²`。协方差与计量单位有关；相关系数再除以双方标准差，本例 A、B 相关系数约为 -0.5817。C 在这四个观测中方差为零，所以与它的相关系数没有定义，不能写成“相关为零”。

四个观测极少，这个矩阵只是教学样本，且会因常数现金序列而奇异。实务上要锁定收益频率、交易日对齐、币种、缺失处理、复权版本和估计窗口；逐对删除缺失值可能得到不半正定矩阵。收缩、因子模型或稳健估计可以改善估计稳定性，但不会把估计误差变成已知事实。

## 边际风险 {#marginal-risk}

若风险度量取组合波动率 `σ_p=√(w'Σw)`，第 `i` 项的边际风险为局部偏导：

`MRC_i = ∂σ_p/∂w_i = (Σw)_i/σ_p`。

本例 `Σw=(45.4,-5.4,0)' pp²`，所以 A、B、C 的 MRC 分别约为 8.9695、-1.0669、0 个波动率百分点/单位权重。权重 A 增加 1 个百分点、其他权重暂时不变时，一阶近似令组合波动率增加 `0.01×8.9695=0.0897` 个百分点；B 的同类变化约减少 0.0107 个百分点。

“其他权重不变”意味着组合净投资额随之改变，不是自融资调仓。若从 B 移 1 个百分点给 A，方向导数应使用 `MRC_A−MRC_B`。B 的负边际风险只表示在本样本、本权重附近具有对冲作用，不表示 B 没有自身风险，更不保证样本外仍为负。约束、离散交易、非线性工具和不可微风险度量下，必须另行定义有限变化或情景边际风险。

## 贡献风险 {#risk-contribution}

对一阶齐次且可微的波动率，Euler 分解给出单项波动率贡献 `RC_i = w_i×MRC_i`，并满足 `ΣRC_i=σ_p`。本例：

| 项目 | A | B | C | 合计 |
| --- | ---: | ---: | ---: | ---: |
| 波动率贡献（百分点） | 5.3817 | -0.3201 | 0 | 5.0616 |
| 占组合波动率 | 106.32% | -6.32% | 0% | 100% |

贡献可以为负，因此各项占比可能超过 100%，这不是算错，而是分散化或对冲的体现。若分解的是方差，则应使用 `VC_i=w_i(Σw)_i`：A 为 27.24、B 为 -1.62、C 为 0 `pp²`，合计 25.62 `pp²`。方差贡献和波动率贡献的单位不同，不能放在同一列相加。

风险贡献不是独立归因于某资产的“固有风险”：它依赖整个协方差矩阵和当前权重。换一个组合、窗口或风险模型，贡献就会改变。VaR、预期损失、回撤等度量只有在各自满足相应光滑性、齐次性和分配规则时才能照搬 Euler 逻辑；尾部高度非线性或离散情景下可能需要增量风险、Shapley 分配或压力测试。

## 跟踪误差 {#tracking-error}

跟踪误差（TE）衡量组合相对明确基准的主动收益波动，而不是平均跑输幅度。设同频组合收益为 `R_p,t`、基准总回报为 `R_b,t`，定义算术主动收益 `a_t=R_p,t−R_b,t`，事后样本 TE 为：

`TE = √[Σ(a_t−ā)²/(T−1)]`。

给虚构基准四季总回报 5%、-4%、2%、3%，例中实际动态组合的主动收益为 1.65、-2.35、1.25、-0.40 个百分点，均值 0.0375 个百分点，季度 TE 为 `√3.320625=1.8223%`。在独立同分布等假设下乘 `√4` 得 3.6445% 年化；只有四期，估计极不稳定。

累计组合 TWR 为 5.804969%，基准累计总回报为 `1.05×0.96×1.02×1.03−1=5.900480%`，相对财富回报为 `1.0580496859/1.0590048−1=-0.090190%`。它不等于四季主动收益简单相加的 0.15 个百分点，说明必须声明“主动收益”是算术差还是财富比率。

事前 TE 则来自风险模型和主动权重。若基准权重为 `(0.5,0.4,0.1)`，Q1 主动权重 `x=(0.1,-0.1,0)`，沿用上节协方差矩阵，则预测季度 TE 为 `√(x'Σx)=√1.086667=1.0424%`，与事后 1.8223% 不必相等。基准必须匹配币种、价格/总回报、税费、再平衡和可投资范围；TE 低也不代表没有绝对损失、流动性风险或持续小幅落后。

## 路径依赖 {#path-dependence}

路径依赖是指结果不仅取决于一组收益或现金流的总量，还取决于它们发生的顺序、时点及中途状态。在没有外部现金流、杠杆、强制交易、税费或路径依赖合约时，固定简单收益的乘积可交换，调换顺序不会改变终值；因此不能把一切波动都笼统称为路径依赖。

本例保留相同四个季度收益和现金流时点，只把收益顺序改为 6.65%、2.60%、3.25%、-6.35%。TWR 仍是 5.804969%，但账本变为 `(((1,000×1.0665+400)×1.026×1.0325−300)×0.9365)=1,173.9303`，投资者利润变成 `1,173.9303+300−1,400=73.9303` 万元，高于原路径的 47.0803 万元。原因不是收益集合改变，而是较多资本承担了不同阶段的收益；MWR也会随之变化。

实际组合中，回撤触发追加保证金或强平、波动目标调整仓位、期权障碍、税收批次、赎回、再平衡和流动性枯竭都会扩大路径差异。方差和协方差把时间顺序压缩掉，不能单独回答最大回撤、破产概率或中途融资需求。完整评估应保留逐时持仓、现金流、订单、保证金和可用价格，并用压力路径检验“能否活到终点”，而不只比较终点平均收益。
