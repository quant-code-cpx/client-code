面板数据把“谁”和“何时”同时放进一张表。它能利用同一公司的时间变化，也能比较同一时期的公司差异；但重复观测不会自动消除遗漏变量，更多行数也不等于更多独立信息。本页以截至 **2026-08-14** 的经典方法资料为边界，用一组完全虚构的公司×时期数据贯穿点估计与推断。

`company_id` 为稳定法律实体标识，`t=1,2,3` 为三个等长会计期间；`x` 在期初已知，`y` 在期末实现，均为教学单位。每格只有一条观测：

| 公司 | `t=1`：`x,y` | `t=2`：`x,y` | `t=3`：`x,y` |
| --- | ---: | ---: | ---: |
| A | `1,4` | `2,9` | `4,5` |
| B | `2,6` | `4,13` | `5,10` |
| C | `4,10` | `3,11` | `6,15` |

为便于复算，数据由 `y_it=a_i+λ_t+2x_it+e_it` 生成，其中 `a=(1,2,3)`、`λ=(0,3,-2)`，残差矩阵为：

```text
       t1   t2   t3
A       1    1   -2
B       0    0    0
C      -1   -1    2
```

残差各行、各列之和均为零，并与两向去均值后的 `x` 正交，所以两向固定效应会精确得到教学斜率 2。这是人为构造的核算条件，不代表现实中满足外生性，更不是因果结论。

## 个体维度 {#individual-dimension}

**个体维度** `i=1,...,N` 必须对应稳定、可追溯的统计单位。统一账本中 `N=3`，单位是公司，不是股票代码。现实里一家法律实体可能发行多类股票、跨市场上市或属于同一集团；若把每个证券代码当独立公司，会重复资产、基本面和共同冲击。反过来，合并、分拆、借壳或代码变更也不能仅靠字符串把不同法律主体拼成一条历史。

数据键至少应含 `entity_id`、`security_id`、合并范围、有效起止日和来源版本。公司层解释变量配证券层收益时，要明确多证券映射与权重；母公司和子公司行不能同时进入却把它们当相互独立。`N` 是实体数，`NT` 是最多观测格数，两者不等于有效独立样本数。

个体维度允许存在不随时间变化的未观测差异 `a_i`，例如长期管理模式或地理位置。但“同一公司重复出现”只提供控制这些差异的可能；若公司选择、会计口径或经营实体随时间改变，稳定个体假设已经破裂。个体固定效应也不会吸收随时间变化的治理、行业暴露或测量误差。

## 时间维度 {#time-dimension}

**时间维度** `t=1,...,T` 必须统一期间边界、信息可得日与经济含义。统一账本 `T=3`，且每家公司三个时期齐全，属于平衡面板。实际研究要区分财年、自然年、交易日和公告日：2025 财年数据在 2026 年披露，不能因为参考期写 2025 就在 2025 回测中使用。

同一 `t` 的公司可能承受共同宏观、政策或市场冲击 `λ_t`。本例 `t2` 的共同时间效应为 `+3`、`t3` 为 `-2`；若不控制，`x` 与这些时期状态的联动会进入斜率。时间固定效应只能识别每期横截面共同截距，无法估计只随时间变化、对所有公司完全相同的变量之独立系数。

短 `T` 长 `N` 与长 `T` 短 `N` 的渐近理论不同。三期数据即使有十万家公司，也不能支持依赖“大量时间簇”的推断；一百期、三家公司也不能支持依赖“大量个体簇”的推断。缺失、部分期间和频率错配不能用零填充，滞后项还会进一步减少可用时期。

## 合并回归 {#pooled-regression}

**合并回归（pooled OLS）**把所有公司—时期行堆叠：

```text
y_it = α + β x_it + u_it
```

它隐含同一截距、同一斜率，并把个体效应、时间效应和其他遗漏项放进复合误差。斜率一致需要解释变量与复合误差满足相应外生条件；同方差、无序列相关和无横截面相关则是传统 OLS 标准误的额外条件，不是点估计公式本身。异质斜率下 pooled 系数通常是由变异结构决定的加权对象，并非公司斜率的简单平均。

统一九格数据：

```text
x_bar = 31/9 = 3.4444
y_bar = 83/9 = 9.2222
Σ(x-x_bar)² = 182/9 = 20.2222
Σ(x-x_bar)(y-y_bar) = 298/9 = 33.1111
β_pooled = (298/9)/(182/9) = 149/91 = 1.6374
α_pooled = 9.2222 - 1.6374×3.4444 = 3.5824
```

`1.6374` 不是生成式中的 2，因为公司与时期差异同 `x` 一起变化。换聚类标准误只能改变不确定性估计，不能修复遗漏效应造成的点估计偏差。反例是 pooled 回归显著且残差稳健：标准误正确也不等于条件均值或因果结构正确。

## 固定效应 {#fixed-effects}

个体**固定效应（FE）**模型允许每家公司有自己的截距：

```text
y_it = a_i + βx_it + u_it
```

within 变换从每行减去该公司时间均值：

```text
y_it-y_i_bar = β(x_it-x_i_bar) + (u_it-u_i_bar)
```

本例公司均值为 `x_i_bar=(7/3,11/3,13/3)`、`y_i_bar=(6,29/3,12)`。去均值后 `Σx_tilde²=14`、`Σx_tilde y_tilde=44/3`，所以：

```text
β_within = (44/3)/14 = 22/21 = 1.0476
```

FE 消除了 `a_i`，却没有消除本例 `λ_t`，所以仍未得到 2。线性平衡面板中，公司虚拟变量最小二乘（LSDV）与 within 斜率等价，虚拟变量须省略一类或施加和为零约束；系数基准不同不改变斜率。

一阶差分 `Δy_it=βΔx_it+Δu_it` 也能消除时间不变 `a_i`，但它和 within 并非普遍相同：`T=2` 时二者斜率等价；`T>2` 时效率取决于误差动态，差分会使相邻误差相关，并会跨缺失期改变间隔。随机游走型误差可能偏向差分，水平白噪声常偏向 within，不能按习惯机械选择。

任何时间不变变量都与完整个体 FE 共线，无法单独估计其水平系数；可研究其与时间变量的交互、采用有明确假设的组间/相关随机效应方法，但不能把被吸收变量“强行放回”。静态 FE 常要求解释变量对整条个体误差路径严格外生；反向因果、预期效应、动态因变量和时间变化遗漏项仍会破坏识别。固定效应是控制方式，不是因果开关。

## 随机效应 {#random-effects}

**随机效应（RE）**把 `a_i` 作为误差成分，并要求它与该个体所有解释变量独立或至少均值独立：

```text
y_it = α + βx_it + a_i + ε_it
E(a_i | x_i1,...,x_iT) = 0
E(ε_it | x_i1,...,x_iT,a_i) = 0
```

在标准误差成分模型下，GLS 对每个变量作准去均值 `z_it-θz_i_bar`；平衡面板常见：

```text
θ = 1 - σ_ε / sqrt(σ_ε² + Tσ_a²)
```

`θ=0` 接近 pooled，`θ=1` 接近 within。RE 能估计时间不变变量，是因为它同时使用组内与组间变异；若高 `x` 公司也有较高未观测 `a_i`，这项效率优势会变成不一致。本例生成式直接给出不同 `a_i`，但仅凭观察不到的构造不能断言它与 `x` 独立。

Hausman 思路比较在原假设下都一致、但 RE 更有效率的估计量，与在备择下仍一致的 FE。其原始框架见 [Hausman 1978 年规格检验论文](https://doi.org/10.2307/1913827)。检验不是“p 值替你选择真模型”：两估计量必须估同一系数集并满足各自一致性条件，协方差估计也要与检验版本一致；协方差差非正半定、稳健推断、有限样本和模型错设都会破坏机械卡方解释。不拒绝还可能只是功效低。

Mundlak/相关随机效应可在 RE 中加入个体解释变量均值，把组内与组间关系分开，并直接检验相关结构；它不能修复时间变化内生性。FE、RE 的选择应先由目标总体、可识别变异和外生假设决定，再用规格检验诊断。

## 时间效应 {#time-effects}

**时间效应** `λ_t` 是同一期作用于全部个体的共同截距：

```text
y_it = α + λ_t + βx_it + u_it
```

只控制时间 FE 等价于每期横截面去均值。本例时间均值为 `x_t_bar=(7/3,3,5)`、`y_t_bar=(20/3,11,10)`，得到：

```text
Σ(x_it-x_t_bar)² = 26/3
Σ(x_it-x_t_bar)(y_it-y_t_bar) = 70/3
β_time_FE = (70/3)/(26/3) = 35/13 = 2.6923
```

时间 FE 消除了 `λ_t`，但未消除 `a_i`，所以也不等于 2。把个体与时间 FE 同时加入，在平衡面板可用两向去均值：

```text
x_dd = x_it - x_i_bar - x_t_bar + x_bar
y_dd = y_it - y_i_bar - y_t_bar + y_bar
```

本例两向去均值矩阵为：

```text
9×x_dd = [ -2,  1,  1 ; -5,  7, -2 ;  7, -8,  1 ]
9×y_dd = [  5, 11,-16 ;-10, 14, -4 ;  5,-25, 20 ]
Σx_dd² = 22/9，Σx_dd y_dd = 44/9
β_two_way_FE = (44/9)/(22/9) = 2
```

精确得到 2 来自教学残差的正交构造，不是时间 FE 的普遍保证。时间虚拟变量会吸收所有完全共同的时间序列变量；若宏观冲击对公司有不同载荷，单一 `λ_t` 不能完全消除横截面相关。非平衡面板中行、列投影不再这样简单正交，不能机械套一次“双重去均值”。

## 个体效应 {#individual-effects}

**个体效应** `a_i` 汇总所有在观察窗内不随时间变化、并以加法进入截距的公司差异。它与“个体固定效应估计值”“公司处理效应”和“公司特有斜率”不是同一概念。共同斜率 FE 仍假设 `β_i=β`；若真实斜率异质，估计值是由组内变异加权的对象。

虚拟变量系数依赖基准公司或和为零归一化，不能把 A 的系数为零解释成 A 没有个体效应。在线性模型中，即使固定 `T` 下单个 `a_i` 估计很嘈杂，within 斜率仍可在适当条件下随 `N` 增长一致；非线性固定效应模型则可能出现不同的偶然参数问题，结论不能照搬。

本例真正的教学生成值 `a=(1,2,3)` 已事先给定；现实研究看不到它。估计出的公司截距可能同时含长期遗漏特征、测量标尺和样本均值，不能贴上“管理质量”标签。个体 FE 只控制时间不变的加法混杂，无法处理随经营状态变化的战略、共同趋势的异质载荷、反向因果或选择性退出。

## 聚类标准误 {#clustered-standard-errors}

**聚类稳健标准误**允许同一簇内误差任意异方差和相关，并依赖不同簇近似独立、簇数足够大。在线性回归吸收固定效应后，令 `x_tilde` 为变换后的设计、`u_hat` 为残差，单向 CR0 协方差为：

```text
S_g = Σ_(obs in g) x_tilde_it u_hat_it
V_cluster = (X_tilde'X_tilde)^(-1)
            [Σ_g S_g S_g']
            (X_tilde'X_tilde)^(-1)
```

它允许公司内跨期任意相关，但不允许不同公司间仍有未处理共同相关。[Arellano 1987 年论文](https://doi.org/10.1111/j.1468-0084.1987.mp49004006.x)给出 within 估计量的稳健协方差构造；聚类改变推断，不改变 FE 点估计。

用两向 FE 的教学残差按公司聚类，三个公司得分为 `S_A=-1/3、S_B=0、S_C=1/3`：

```text
cluster meat = ΣS_i² = 2/9
X_tilde'X_tilde = 22/9
CR0 Var(β_hat) = (2/9)/(22/9)² = 0.03719
CR0 SE = 0.19285
```

这个 SE 只能演示结构：仅 3 个公司簇，常规大簇近似完全不可信。有限样本倍率、按簇自由度、CR2 或 wild cluster bootstrap 会给不同结果，极少簇时也未必可靠；不存在适用于所有不平衡度和杠杆点的神奇簇数阈值。应报告簇数、最大簇占比、修正和参考分布。

聚类层级由误差或处理分配机制决定，不由“哪个 SE 更显著”决定。公司层政策需至少公司聚类，行业层冲击可能要在更高层聚类；嵌套或交叉结构另处理。逐行异方差稳健 SE 不能替代公司内序列相关修正。

## 双向聚类 {#two-way-clustering}

若误差可能同时在公司内跨期相关、又在同一期跨公司相关，可使用公司×时间**双向聚类**。Cameron–Gelbach–Miller 的包含—排除形式为：

```text
V_two-way = V_firm + V_time - V_firm∩time
```

最后一项扣除被前两项重复计算的交集；每个公司—时间只有一格时，交集项对应逐格异方差稳健贡献。不能把两个单向方差或两个标准误直接相加。[Cameron、Gelbach 与 Miller 的多向聚类论文](https://www.nber.org/papers/t0327)给出线性及多类估计量的多向聚类框架。

统一两向 FE 算例的未缩放 meat 为：

```text
M_firm = 2/9
M_time = (-1)² + 1² + 0² = 2
M_cell = 14/9
M_two-way = 2/9 + 2 - 14/9 = 2/3
CR0 SE = sqrt[(2/3)/(22/9)²] = 0.33402
```

`0.33402` 同样不能用于显著性：公司簇和时间簇都只有 3 个。双向修正至少需要两个维度各有足够有效簇；一个维度很少仍是少簇问题。有限样本下包含—排除估计可能非正半定，软件修剪特征值或采用不同自由度会改变结果，应披露而非静默处理。若两个聚类维度实际嵌套或相同，也不能重复套用双向公式。

## 横截面相关 {#cross-sectional-dependence}

**横截面相关**指同一时期不同公司的误差相关，来源可包括共同宏观冲击、行业供应链、网络传染、共同所有权、指数资金流或同步测量误差。时间 FE 只移除载荷完全相同的加法共同冲击；若公司对因子载荷不同，`u_it=γ_i f_t+ε_it` 在扣除时间均值后仍会相关。

双向聚类主要修正标准误，不会自动清除遗漏共同因子对斜率的偏误。Driscoll–Kraay 协方差允许较一般横截面和时间依赖，但原始理论依赖时间维度趋大，并需选择核与带宽；三期面板显然不适用。[Driscoll 与 Kraay 1998 年论文](https://doi.org/10.1162/003465398557825)明确以较长 `T` 下的一般空间相关为目标。

共同相关效应（CCE）把因变量和解释变量的横截面均值加入个体回归，以代理未观测多因子结构。[Pesaran 2006 年论文](https://doi.org/10.1111/j.1468-0262.2006.00692.x)在大 `N`、大 `T` 及特定因子、弱外生和异质性条件下推导 pooled/mean-group CCE；它不是“小样本加两个均值就解决相关”的技巧。空间权重、网络模型、因子模型和行业×时间 FE各依赖不同结构，需由机制和渐近维度选择。

## Fama–MacBeth 回归 {#fama-macbeth}

**Fama–MacBeth（FMB）回归**先在每个时期做横截面回归，再对时期系数取时间平均：

```text
y_it = a_t + b_t x_it + u_it
b_bar = (1/T) Σ_t b_t
SE_naive(b_bar) = sd(b_t)/sqrt(T)
```

这不是把所有行堆叠的 pooled OLS，也不是用公司 within 变换的面板 FE。本例三个横截面分别为：

```text
t1：x=(1,2,4)，y=(4,6,10)，b_1=2
t2：x=(2,4,3)，y=(9,13,11)，b_2=2
t3：x=(4,5,6)，y=(5,10,15)，b_3=5
b_bar = (2+2+5)/3 = 3
sd(b_t) = sqrt(3) = 1.7321
SE_naive = 1.7321/sqrt(3) = 1
t_naive = 3
```

只有三个时期，`SE=1、t=3` 没有可信渐近含义；它只是完整复算。若 `b_t` 有序列相关，第二步应对系数时间序列使用与频率、重叠期限和样本长度匹配的 HAC/Newey–West 修正；每期横截面稳健 SE 不能替代 `b_bar` 的时间序列 SE。[Fama 与 MacBeth 1973 年原始论文](https://doi.org/10.1086/260061)以逐期横截面风险—收益回归建立这种推断思路。

在资产定价中，`x` 若是先用时间序列估计的 beta，存在生成回归量和测量误差；传统第二步精度可能被高估，[Shanken 1992 年研究](https://doi.org/10.1093/rfs/5.1.1)讨论相应修正。若 `x` 是公司特征，`b_bar` 是平均横截面特征—收益关联，不自动等于可交易因子的风险价格。特征必须在每期收益形成前可见，退市、微盘权重、截面缺失和重叠收益都要进入设计。

## 不平衡面板 {#unbalanced-panel}

**不平衡面板**中各个体观察期数 `T_i` 不同。把统一账本改为：B 在 `t2` 后退出，C 的 `t2` 因数据缺口缺失，D 在 `t3` 新进入且 `x=2、y=7`。可见行数从 9 变为 8，观测均值从 `83/9=9.2222` 变为：

```text
(83 - B,t3的10 - C,t2的11 + D,t3的7) / 8
= 69/8 = 8.625
```

均值下降可能只是样本构成变化，不能直接解释为公司表现恶化。进入、退市、并购和停牌往往与结果有关，属于信息性选择；供应商漏报则是另一种缺失机制。缺失并非随机时，仅对已观察格回归可能改变估计总体，FE 也不会自动修复幸存者偏差。

不平衡面板的公司 FE 仍可通过虚拟变量或正确投影吸收，但两向去均值不能一般地只做一次 `x-x_i_bar-x_t_bar+x_bar`；行列样本不同使两个投影不正交。单例公司 D 没有公司内变化，对纯个体-within 斜率不提供信息，却可能影响时间效应和横截面结果。设置“至少两期”会排除 D，也会把估计总体改成较长寿公司。

逐观测等权会让长历史公司权重更高；先估公司系数再平均则给公司等权，逆概率权重又依赖选择模型。任何权重都要说明目标总体和估计分母。不能把缺失 `y` 填零、把退市收益丢弃或用最终存活名单回填历史。最终台账应保存进入、退出、缺失原因、公司行动、实体映射、观察窗口和当时可见版本；“不平衡”是数据结构描述，不是无偏保证。
