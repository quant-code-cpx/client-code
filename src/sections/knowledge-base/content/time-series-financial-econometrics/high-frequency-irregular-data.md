## 事件时间 {#event-time}

**事件时间**把每次指定事件记作一步：第 `k` 笔成交、第 `k` 次报价变化或第 `k` 条订单消息相邻。一步代表一个事件，不代表一秒或任何固定现实时间。活跃时段被拉长为许多步，安静时段被压缩；事件时间模型回答“经过若干事件后”，不能直接解释为“经过若干分钟后”。

把 X 每两笔成交组成一个 event bar：

| event bar | 成交 | 现实跨度 | O/H/L/C | 数量 |
| --- | --- | ---: | --- | ---: |
| E1 | `seq 3、4` | 0.6 秒 | 100.01 / 100.01 / 99.99 / 99.99 | 180 |
| E2 | `seq 5、8` | 2.4 秒 | 100.01 / 100.11 / 100.01 / 100.11 | 170 |
| E3 | `seq 11、13` | 1.7 秒 | 100.14 / 101.35 / 100.14 / 101.35 | 270 |
| E4 | `seq 18、20` | 3.2 秒 | 101.31 / 101.31 / 101.25 / 101.25 | 150 |

四根 bar 都含两笔成交，却覆盖 `0.6、2.4、1.7、3.2` 秒。按 bar 比较收益若忽略跨度，会把活动强度差异混入波动。成交数 bar、等成交量 bar 和等金额 bar又是不同事件时钟。

同一交易所时间戳可以有多个事件：`seq 4、5` 时间相同但顺序不同。时间戳精度不足、批量撮合或聚合报告都可能产生零现实间隔；应使用序列号/频道规则处理，不能随机排序或删除。事件到达本身可能受价格与波动影响，因此事件时间抽样通常是内生抽样。

## 日历时间 {#calendar-time}

**日历时间**用固定现实区间聚合，例如 X 的右开 5 秒成交 bar `[00,05)、[05,10)、[10,15)`：

| calendar bar | O/H/L/C | 成交量 |
| --- | --- | ---: |
| `[00,05)` | 100.01 / 100.11 / 99.99 / 100.11 | 350 |
| `[05,10)` | 100.14 / 101.35 / 100.14 / 101.35 | 270 |
| `[10,15)` | 101.31 / 101.31 / 101.25 / 101.25 | 150 |
| `[15,20)` | 无成交 | 0 |

最后一根空 bar 没有可观察的成交 O/H/L/C。若供应商用 last observation carried forward（LOCF）填 `101.25`，得到的零成交收益是“旧成交价未更新”的插补结果，不是证明有效价格没变；成交量仍应为零，陈旧标记不能丢。若用于估值而携带最后中间价，则是 `101.26`，也不能与最后成交价混称。

bar 必须声明边界包含规则、会话、拍卖、盘前盘后、午休、部分交易日和时区。开盘价是区间内第一笔合格事件，不是交易所每日开盘参考价；高低价也取决于是否纳入更正、场外报告和异常成交。空 bar 保持缺失、LOCF、插值或删除会产生不同收益序列，没有全球统一答案。

## 不等间隔 {#irregular-intervals}

相邻事件时间差 `d_k=t_k-t_(k-1)` 称为 duration。X 成交时间为 `.4、1.0、1.0、3.4、6.0、7.7、11.0、14.2` 秒，对应可观察成交间隔：

```text
0.6，0.0，2.4，2.6，1.7，3.3，3.2 秒
```

第一笔之前的间隔因观察窗左边界未知而左删失。平均 duration 与强度互为倒数只在口径和条件明确时成立；例如平均 2 秒约对应 0.5 笔/秒，但时间变化强度应写作 `λ(t|F_t)`，不能由全日平均代替。

不等间隔收益要同时保存收益和 `Δt`。若理想连续扩散在短区间内局部方差率为 `σ²`，则条件方差近似 `σ²Δt`，按事件比较可考虑 `r/√Δt`；但 duration 若由信息和波动内生决定，这种标准化不恢复独立同分布。收益单位是价格比例，方差率单位是“收益平方/秒”，duration 单位是秒，三者不能混写。

没有事件不同于缺失数据：前者是观测到某事件类型未发生，后者可能是丢包、停牌或权限中断。跨午休、隔夜与夏令时也不能当成普通长 duration；会话中断应单独编码。

## 买卖价反弹 {#bid-ask-bounce}

即使有效中间价不动，成交在 bid 与 ask 间切换也会制造负的一阶价格变化协方差。事件流开头中间价均为 100，三笔 X 成交 `100.01→99.99→100.01`，变化 `-0.02、+0.02`，视觉上就是 **bid–ask bounce**；它不表示有效价格先跌后涨。

Roll 的理想模型写作：

```text
P_t = M_t + cQ_t
Q_t ∈ {-1,+1}，独立且等概率
Cov(ΔP_t,ΔP_(t-1)) = -c²
estimated spread = 2sqrt[-Cov(ΔP_t,ΔP_(t-1))]
```

若半价差 `c=0.01`，理论协方差为 `-0.0001`，隐含全价差 `2√0.0001=0.02`，与 `99.99/100.01` 一致。[Roll 1984 年原始论文](https://doi.org/10.1111/j.1540-6261.1984.tb03897.x)要求有效价格增量无序列相关、稳定价差和简化成交方向等强条件。只有两次价格变化的教学片段不能可靠估计协方差；直接用唯一乘积 `-0.0004` 会错误得到 0.04，正说明短样本不可复算成可靠成本。

若样本一阶协方差为正，`√(-cov)` 没有实数结果，应报告 Roll 估计不可用，而不是取绝对值或强设为零。库存控制、信息冲击、相关成交方向、价格离散、时变价差和中间价自相关都会破坏公式；有同步报价时应直接分析 quoted/effective spread，同时保留成交方向推断误差。

## 微观结构噪声 {#microstructure-noise}

常用观测模型为：

```text
observed_price_t = efficient_price_t + noise_t
```

有效价格是潜在概念，不可直接观测；中间价也会因队列、隐藏流动性和陈旧报价偏离它。`noise_t` 可来自买卖价反弹、最小变动单位、离散报价、撮合优先级、订单拆分、成交更正、价格限制、不同场所、时钟误差和延迟，并可能与有效价格及交易强度相关，不能默认独立白噪声。

事件流中 `seq 5` 比 `seq 4` 更早被研究系统收到。按接收时间排序会把成交顺序改为 `100.01→100.01→99.99`，进而改变收益、方向和队列解释。交易所时间、网关时间、供应商接收、本机接收和处理完成时间应分别存储；精度为微秒或纳秒不等于时钟准确、跨源同步或低延迟。

截至本页日期，[Nasdaq TotalView-ITCH 5.0 规范](https://www.nasdaqtrader.com/content/technicalsupport/specifications/dataproducts/NQTVITCHspecification.pdf)把其时间戳定义为自午夜起纳秒数，并使用消息字段与序列化数据描述订单事件；这只支持该具体场所和数据产品，不能推广为所有交易所字段。行情重放、丢包恢复和更正必须先完成，之后才可估计收益或 duration。

## 异步交易 {#asynchronous-trading}

**异步交易**表示不同资产的可观察价格在不同时间更新。X 在 `07.500` 的中间价从 `100.13` 跳到 `101.34`，Y 到 `09.000` 才从 `50.00` 更新到 `50.50`。两次更新可能源于共同信息、真实反应滞后或纯粹成交/报价稀疏；事件流本身不能识别因果。

若每 0.5 秒用 previous tick 同步，X 的新价格会在 Y 更新前被重复携带三格，Y 产生多次插补零收益，随后才跳变。这会压低同格相关、制造 X 领先 Y 的外观，并影响高频 beta；缩短网格通常更严重，这类短间隔相关下降与 [Epps 1979 年研究](https://doi.org/10.1080/01621459.1979.10482508)讨论的问题相关。

同步方法包括较粗日历格、refresh time、重叠区间协方差或 Hayashi–Yoshida 类估计，但各自需要连续半鞅、无噪声或抽样机制等条件。previous tick 不是“真实同步”，线性插值更会利用未来价格。还应统一交易所时间而非混用接收时间，并处理跨市场休市、午休和时区。异步造成的 lead–lag 与经济价格发现是两种假设，不能仅凭回归领先项显著就定性。

## 价格持续时间 {#price-duration}

**价格 duration**需先定义“价格变化”：成交价任意变化、中间价变化一个 tick，或累计移动超过阈值都不同。本页用 X 中间价每次变化定义。中间价序列为：

```text
时间(秒)  0.1   3.2    5.1    5.8    7.5     8.3    10.8   14.0
mid      100  100.10 100.05 100.13 101.34 101.24 101.30 101.26
duration       3.1    1.9    0.7    1.7     0.8    2.5    3.2
```

观察窗若在 20 秒结束，14.0 后没有下一次变化的 6 秒是右删失：只知道 duration 至少 6 秒，不能当成完整 6 秒事件。0.1 前的 duration 则左删失。同一时间戳发生多次不同价格会出现零 duration，必须按序列与时间精度判断；连续正分布模型不能直接吞下零值，不能无说明加一个微秒。

价格 duration 同时受 tick size、价差、波动、订单强度和价格限制影响。高价证券一个固定货币 tick 与低价证券不可直接比较；变更 tick table 会造成制度断点。duration 短可能表示信息快、噪声多或报价竞争激烈，不自动等于流动性更好。

## 成交持续时间 {#trade-duration}

**成交 duration**是相邻合格成交的时间差。X 的 `0.0` 秒间隔来自两个同时间戳但不同序列的成交；它可能是同一撮合批次、时间精度限制或拆单，不应删除。场外延迟报告、组合成交、取消与更正还会改变“合格成交”集合，需预先固定过滤规则。

基本 ACD(1,1) 模型把正 duration 写成：

```text
x_k = ψ_k ε_k，E(ε_k|F_(k-1))=1
ψ_k = ω + αx_(k-1) + βψ_(k-1)
```

常用充分条件 `ω>0、α≥0、β≥0`；在标准指数 ACD 下，`α+β<1` 给有限无条件均值 `E(x)=ω/(1-α-β)`。取虚构参数 `ω=0.4秒、α=0.2、β=0.6`，上一完整 duration `x=2.6秒`、上一条件均值 `ψ=2秒`：

```text
ψ_next = 0.4 + 0.2×2.6 + 0.6×2 = 2.12 秒
E(x) = 0.4/(1-0.2-0.6) = 2 秒
```

若 `ε` 为均值 1 的指数分布，事件间条件 hazard 为 `1/ψ_next=0.4717 次/秒`；Weibull 或其他误差分布的 hazard 还取决于已等待时间，不能普遍把强度写成 `1/ψ`。[Engle 与 Russell 1998 年 ACD 原始论文](https://doi.org/10.2307/2999632)专门处理不规则交易到达。零 duration、会话删失、日内季节性和信息性抽样需扩展或重新编码，普通连续 ACD 不是万能模型。

## 抽样频率 {#sampling-frequency}

提高频率会减少连续价格路径的离散化误差，却放大买卖价反弹、tick 离散与其他微观结构噪声；降低频率能缓和噪声，却丢掉日内变化和跳跃时点。这是噪声—离散化偏差权衡，不是“越多数据越准”。

事件流的所有中间价变化得到下节 RV `1.4765 %²`；以 `0.1` 秒首个中间价为起点，并在 5、10、15 秒取 previous-tick 中间价，得到 `100.00→100.10→101.24→101.26`。三段对数收益为 `0.09995%、1.13242%、0.01975%`，RV 为：

```text
0.09995² + 1.13242² + 0.01975² = 1.29277 %²
```

两个结果不同，不能仅因细网格更大就断言真实波动是 1.4765。真实数据可画 volatility signature plot、比较多个预先指定频率，并采用显式噪声模型、子抽样、pre-averaging 或 realized kernel；参数要在训练样本决定。[Aït-Sahalia 与 Mykland 关于抽样频率的研究](https://www.nber.org/papers/w9611)证明有微观结构噪声时有限抽样频率可能最优；具体最优点依赖资产、市场、时期和估计目标。

“5 分钟”只是常见经验值，不是全球通用最优。成交稀疏资产、活跃期货、隔夜电子盘和开盘集合竞价需要不同处理；用全样本结果挑选使回测最漂亮的频率还会产生选择偏差。

## 已实现方差 {#realized-variance}

给定同一会话、同一价格对象的日内对数收益，**已实现方差（realized variance, RV）**为平方和：

```text
RV = Σ_j r_j²
```

X 的清洗中间价变化产生七段对数收益，单位为百分点：

```text
[0.099950,-0.049963,0.079928,1.201186,-0.098726,0.059248,-0.039494]
RV = 1.476539 %²
realized volatility = sqrt(RV) = 1.215129%
```

在连续半鞅、观测网格趋密且噪声可忽略等条件下，RV 逼近二次变差；有跳跃时包含跳跃平方。[Andersen、Bollerslev、Diebold 与 Labys 的实现波动研究](https://doi.org/10.1111/1468-0262.00418)建立高频度量和条件协方差的联系。此处按每次中间价变化求和还带有内生事件抽样，不能冒充理想等距极限。

RV 必须标方差还是平方根、收益用小数还是百分数、会话是否含隔夜及年化因子。盘中 RV 不含前收至开盘的跳空；若需要整日总变差，应单列隔夜平方与盘中项，而非把隔夜均摊到 bar。跨日总方差可加总相同口径 RV，但标准差不能直接相加。

子抽样平均多个网格、pre-averaging 平滑局部噪声、two-scale 与 realized kernel 利用不同校正结构。[Zhang、Mykland 与 Aït-Sahalia 的 two-scale 研究](https://doi.org/10.1198/016214505000000169)说明最高频朴素 RV 在噪声下失效；这些方法仍依赖噪声、平滑参数、交易时钟和渐近条件，不能把一个校正结果当无误差真值。

## 跳跃检验 {#jump-testing}

在合适连续扩散条件下，双幂变差（BPV）估计连续积分方差：

```text
BPV = μ_1^(-2) Σ_(j=2)^M |r_j||r_(j-1)|
μ_1 = E|N(0,1)| = sqrt(2/π)
```

统一七段收益的相邻绝对乘积之和为 `0.231774`，所以：

```text
BPV = (π/2)×0.231774 = 0.364069 %²
RV-BPV = 1.476539-0.364069 = 1.112470 %²
```

大差额主要来自 `7.5` 秒附近约 `1.20%` 的中间价变化，但它只是描述性跳跃候选。正式 BNS 类统计量还要用 tripower quarticity 等尺度估计、有限样本修正并选择显著性水平；[Barndorff-Nielsen 与 Shephard 的原始检验研究](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=922904)给出相应渐近框架。

微观结构噪声、错序、错误报价、开盘价格发现、交易暂停后复牌和 tick 变化都可能使 RV 相对 BPV 变大。只有七段的教学流不能作显著性结论；全日反复逐 bar 检验还需控制多重检验。统计跳跃表示连续路径原假设下的异常离散变化，不自动证明某新闻是原因，也不表示在中间价格可成交。

## 日内季节性 {#intraday-seasonality}

许多股票市场的成交强度、价差和波动呈开收盘高、中段低的 U 形，但它不是跨资产、跨市场定律。外汇、夜盘期货、集合竞价、午间休市、公告窗口、半日市和夏令时会形成不同轮廓。[Andersen 与 Bollerslev 1997 年研究](https://doi.org/10.1016/S0927-5398(97)00004-2)展示显著日内周期会影响高频波动持续性与相关分析。

可在仅含过去日期的训练集，按固定会话槽 `j` 估计尺度 `s_j`，再标准化 `z_(d,j)=r_(d,j)/s_j`。假设三个教学槽的历史 RMS 波动为 `0.9%、0.4%、0.8%`，先用 `sqrt[(0.9²+0.4²+0.8²)/3]=0.732575%` 归一化，得到：

```text
s = (1.22854, 0.54602, 1.09204)
mean(s_j²) = 1
```

归一化保留全日尺度，槽因子只描述相对季节。应按交易所本地时区和会话状态映射，午休没有连续交易 bar，半日市不能硬塞进普通尾盘槽；公告尖峰可单列事件，而非用平滑 U 形吞掉。

使用当天全部数据估当天 `s_j` 会把未来时段泄露到早盘；全样本季节因子也会污染历史回测。季节模式应滚动更新并保存版本、样本天数、节假日和制度断点。duration 的季节调整方向与波动不同：高强度时 duration 通常更短，不能拿收益波动的 `s_j` 直接相除。季调后的残差仍可能有波动聚集、跳跃与噪声，季调不是风险消除。
