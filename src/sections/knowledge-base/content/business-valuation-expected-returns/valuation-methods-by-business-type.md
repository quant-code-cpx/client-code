估值方法不是行业标签的固定配方，而是把特定主体、特定权利和可分配现金流在同一基准日配对的工具。成熟制造商、银行和矿山都能“盈利”，但制造商的借款通常是融资，银行的存款更像经营原料，矿山的现金流又受有限储量约束；若不先识别价值来源和资本权利，选择哪个倍数只是表面问题。

下文统一以 2026-08-13 为价值基准日，金额均为人民币百万元，股数为百万股，税率、折现率和监管缓冲均为教学假设。每类企业依次回答六个问题：价值来自什么；哪种现金流可预测；资本、牌照或监管如何限制分配；倍数的关键分母是什么；首选与交叉方法是什么；什么条件下该方法失效。企业价值方法必须匹配融资前现金流，股权价值方法必须匹配归普通股的现金流；净债务、非控股权益、非经营资产和潜在稀释只可在价值桥中各处理一次。

| 方法 | 直接估计的价值主体 | 典型分母或现金流 | 使用前最低检查 |
| --- | --- | --- | --- |
| FCFF 折现 | 经营企业价值 | 融资前企业自由现金流、WACC | 税、租赁、再投资和净债务口径一致 |
| FCFE／股利折现 | 普通股权益价值 | 融资后可分配现金流、权益成本 | 借款变化和监管分配约束已建模 |
| 剩余收益 | 普通股权益价值 | 期初账面权益、超额 ROE | 会计口径可调整，清洁盈余关系可解释 |
| NAV／资产基础法 | 资产或权益，依模型声明 | 单项资产税后可实现价值 | 未把经营现金流和同一资产重复相加 |
| 相对估值 | 企业或权益，依倍数声明 | 正常化利润、收入、账面权益等 | 分子分母、增长、风险、资本结构和会计口径可比 |
| SOTP | 通常为集团普通股权益 | 各分部最适合的方法 | 各段价值主体统一，集团层扣减不重不漏 |

[《资产评估执业准则——企业价值》](https://book.hjyweb.cn/appraisal/aas/aaps/201838.html)自 2019-01-01 起施行，要求结合评估目的、价值类型、资料和方法适用条件选择模型；[IVS 2025](https://ivsc.org/new-edition-of-the-international-valuation-standards-ivs-published/)自 2025-01-31 生效，也把价值基础、方法、输入、模型和企业权益分开。二者都不支持“某行业只能用某倍数”的机械映射。本页是投研教学，不替代法定资产评估、审计或交易定价意见。

## 成熟企业 {#mature-companies}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 既有客户、品牌、产能和稳定竞争优势产生的可持续回报 |
| 可预测现金流 | 正常化利润率下的 FCFF；资本结构稳定时也可用 FCFE 或可持续股利 |
| 资本／监管约束 | 维持性资本开支、养老金、租赁、债务契约和必要营运资金 |
| 关键分母 | 正常化 EBIT、EBITDA、净利润或 FCFF，而非某个异常年度数字 |
| 首选／交叉方法 | 稳定或两阶段 DCF；以同行 P/E、EV/EBIT、FCF 收益率交叉 |
| 禁用条件 | 业务正被颠覆、资本结构将突变、利润依赖一次性处置或终值增长无再投资支撑 |

成熟不等于零增长，也不等于可以直接使用永续公式。它意味着收入增速、经营利润率、再投资率和资本回报逐步收敛到可持续区间，显式预测期应覆盖这段收敛。若企业当前正常化 FCFF 为 120，下一年增长 2% 至 122.4，名义 WACC 为 8%、长期增长率为 2%，稳定模型的经营企业价值为：

`EV₀ = FCFF₁/(WACC−g) = 122.4/(8%−2%) = 2,040`。

若净债务 400、非经营资产 60，则普通股权益价值为 `2,040−400+60=1,700`。这个算例只在 `WACC>g`、120 已扣足维持性资本开支和营运资本、长期增长与再投资相容时成立。把 120 误当下一年现金流，价值会变成 2,000；时点差一个年度就产生 40 的差异。

稳定股利企业可以用股利折现交叉，但“历史分红稳定”不证明分红等于剩余可分配现金。管理层可能在借债分红，也可能因并购计划暂时少分；应先做 FCFE—分红—净借款勾稽。EV/EBITDA 能弱化折旧政策差异，却忽略资本开支和营运资本；资本密集成熟企业不能因 EBITDA 稳定就视其现金流稳定。

反例是一家看似成熟的报业公司：过去利润和股息平稳，但用户迁移导致收入永久下降。用历史平均利润和 2% 永续增长会把结构性衰退误写成周期波动。此时应显式预测萎缩、重组成本与有限经营期，并以资产处置价值作为边界，而非继续套“成熟企业倍数”。

## 高成长企业 {#high-growth-companies}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 可扩张市场、产品优势、客户留存、单位经济和未来竞争优势期 |
| 可预测现金流 | 分阶段收入、利润率、再投资和融资需求；近年现金流常为负 |
| 资本／监管约束 | 生存资金、后续融资稀释、人才与算力投入、获客渠道及合规成本 |
| 关键分母 | 同口径收入、毛利、活跃客户或单位贡献；不能把增长本身当价值 |
| 首选／交叉方法 | 多阶段、情景化 DCF；单位经济和同阶段 EV/收入作交叉 |
| 禁用条件 | 直接使用稳定增长模型、用成熟同行利润率却不计达到它的成本、忽略失败与融资稀释 |

高增长 DCF 的核心不是把收入增长率延长，而是同时说明规模如何转化为利润、增长需要多少资本、竞争优势何时衰减。假设某企业未来五年 FCFF 为 `−45、−20、5、35、60`，第 6 年 FCFF 为 70，WACC 为 11%、稳定增长为 3%。年末口径下：

`PV(显式期) = −45/1.11 −20/1.11² +5/1.11³ +35/1.11⁴ +60/1.11⁵ = 5.55`；

`TV₅ = 70/(11%−3%) = 875.00`；

`PV(TV)=875/1.11⁵=519.27`；故 `EV≈524.82`。

终值现值占 98.94%，不是“公司几乎没有近期价值”，而是模型把绝大多数证据压在远期利润率、再投资和资本成本上。研究员应至少披露收入留存、成熟毛利率、销售与研发效率、稳定期资本回报及融资轮次的敏感性。若第 6 年 70 的现金流只是削减研发带来的短期结果，便不能同时保持 3% 永续增长。

EV/收入只能在毛利率、总额／净额列报、增长、留存和资本需求可比时交叉使用。两家公司收入都为 500，一家毛利率 80%、净留存率 120%，另一家毛利率 20%、靠补贴维持客户，不能享受同一倍数。所谓“总可寻址市场”也不是现金流：市场份额、价格、监管、竞争反应和实现年限都要进入概率情景。

## 亏损企业 {#loss-making-companies}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 可修复的单位经济、可分离资产、技术或牌照，以及转为正现金流的选择权 |
| 可预测现金流 | 生存、扭亏、出售或清算等条件情景下的股权现金流 |
| 资本／监管约束 | 现金跑道、债务优先权、融资可得性、契约违约和重组成本 |
| 关键分母 | 毛利、贡献利润、现金消耗、客户经济；负净利润不是可解释的 P/E 分母 |
| 首选／交叉方法 | 情景概率 DCF、调整后资产或清算价值；收入倍数仅作有条件交叉 |
| 禁用条件 | 对负 EPS 计算 P/E、把研发等所有亏损自动资本化、假设公司可无限融资 |

先区分“为高回报增长主动投入”与“每卖一单都扩大亏损”。贡献利润为负、留存恶化且没有定价权时，规模越大可能越毁值；会计亏损也可能含一次性减值，不能只看净利润符号。现金跑道公式可写为 `可用现金÷月度净现金消耗`，但消耗会随裁员、季节和营运资本变化，并非恒定倒计时。

可复算情景：企业在第 2 年末有 60% 概率扭亏后股权价值 300，有 40% 概率清算后普通股剩余 40；假定这些是同一时点价值、情景概率与 20% 风险调整权益成本相容，则：

`V₀ = [60%×300 + 40%×40]/1.20² = 136.11`。

若现有股东还须立即投入 30 才能走到该分布，投前归属价值为 `136.11−30=106.11`。必须避免既给失败情景极低概率与极低回收，又任意提高折现率来重复加入同一风险；可用一致的风险调整现金流、风险中性权重或经校准的风险溢价，但不能混搭“多重保守”。

清算价值是下行边界而非必然地板：客户名单、专用设备和资本化研发在被迫出售时可能折价，员工、税务、诉讼和关停成本具有优先性。相反，若债权人拥有全部处置价值，企业仍可能有正资产价值而普通股为零。使用 EV/收入时还要扣未来烧钱和稀释；“同类公司 5 倍收入”并没有替现有股东支付下一轮融资。

## 周期企业 {#cyclical-companies}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 穿越需求、价格和库存周期的正常化产能与成本位置 |
| 可预测现金流 | 覆盖完整周期的价格、销量、利润率、营运资本和资本开支 |
| 资本／监管约束 | 周期底部流动性、债务到期、维持产能支出和库存融资 |
| 关键分母 | 中周期 EBIT/EBITDA/FCFF 或正常化资本回报 |
| 首选／交叉方法 | 周期路径 DCF、正常化利润倍数、重置成本作交叉 |
| 禁用条件 | 峰值利润永久化、谷底亏损直接资本化、用短历史平均覆盖结构变化 |

假设某企业完整五年周期 EBIT 为 20、80、160、220、120，简单平均为 120；规范化税率 25%，正常折旧 40、资本开支 50、营运资本增加 10，则中周期 FCFF 为：

`120×(1−25%)+40−50−10 = 70`。

若下一期正常化 FCFF 增长 2%、WACC 9%，稳定状态示例价值为 `70×1.02/(9%−2%)=1,020`。在峰值 EBIT 220 上套倍数会夸大价值，在谷底 EBIT 20 上套相同倍数又会过度压低；正常化不是挑一个“看起来舒服”的数字，而要覆盖价格、利用率、成本和库存的完整周期。

简单历史平均也有边界。新增低成本产能、需求永久替代、碳成本、汇率或行业集中度变化会让旧周期失去代表性；此时应按成本曲线和供需情景重建未来周期。资本结构会造成路径依赖：即使长期均值正确，公司也可能在谷底因债务到期而先违约，股权价值不能只看跨周期平均。

同行倍数应放在相近周期位置，或同时使用正常化分母。周期股在利润高点常呈现“低 P/E”，在利润低点呈现“高 P/E”甚至无 P/E；低倍数不自动便宜。Damodaran 的[周期与负盈利估值资料](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/lectures/val.html)同样强调正常化或显式周期路径，这属于方法参考，不是对中国企业的统一参数规定。

## 银行 {#banks}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 存贷与非息业务的风险调整利差、客户关系、成本效率及资本回报 |
| 可预测现金流 | 满足资本、拨备和流动性约束后的可分配股利或股权剩余收益 |
| 资本／监管约束 | 核心一级资本、风险加权资产、杠杆率、流动性及审慎缓冲 |
| 关键分母 | 有形普通股权益、正常化净利润、风险加权资产；存款不是普通净债务 |
| 首选／交叉方法 | 股利能力／FCFE、剩余收益；P/B—ROE 与 P/E 作交叉 |
| 禁用条件 | 用工业企业 FCFF 把存款全作外部债务、忽略资产质量和资本补充需求 |

银行以吸收资金、承担信用和期限转换风险为核心，利息支出和多数金融负债属于经营过程，传统“EBIT 后加折旧减资本开支”的 FCFF 很难稳定定义。估值通常直接落到股权：预测净息差、非息收入、信用成本、费用、税和风险加权资产，再计算维持目标资本后可分配的现金。

稳定清洁盈余关系下，P/B 与 ROE 的联系可由股利折现推导：

`P/B₀ = (ROE−g)/(Kₑ−g)`。

若前瞻 ROE 为 12%、权益成本 10%、长期增长 4%，则 `P/B=(12%−4%)/(10%−4%)=1.333`；期初普通股账面权益 1,000，对应价值约 1,333.33。公式隐含留存支持增长、`Kₑ>g`、ROE 可持续且账面权益可解释。若不良贷款确认不足、OCI 波动或资本交易破坏清洁盈余，必须先调整，不能把 1.33 倍当行业合理值。

等价的剩余收益表达为 `V₀=B₀+Σ[(ROE_t−Kₑ)×B_{t−1}/(1+Kₑ)^t]`。ROE 高于资本成本只有在信用损失、资金成本和所需资本都充分计量后才创造价值；通过提高杠杆或压低拨备抬高 ROE，不等于经济改善。

[《商业银行资本管理办法》](https://www.gov.cn/gongbao/2024/issue_11126/202401/content_6928796.html)由国家金融监督管理总局令 2023 年第 4 号公布，自 2024-01-01 施行，并以资本净额相对风险加权资产等指标约束银行。实际估值应采用报告期适用的监管口径和银行自身缓冲，不把法定最低线当可自由分配线。P/B 低于 1 既可能反映预期 ROE 低于权益成本，也可能反映资产质量、治理或账面价值可信度问题，不是自动的清算套利。

## 保险 {#insurance-companies}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 承保利润、投资收益、在手保单未来利润及持续新业务能力 |
| 可预测现金流 | 满足赔付和偿付能力后归股东的现金；寿险需按保单群组与期限建模 |
| 资本／监管约束 | 最低资本、实际资本、偿付能力、资产负债匹配及分红限制 |
| 关键分母 | 调整后权益、在手业务价值、年化新业务价值或可持续利润，口径须披露 |
| 首选／交叉方法 | 股权剩余收益／股利能力；嵌入价值及新业务价值仅作定义清楚的补充 |
| 禁用条件 | 把保费当普通收入倍数、把新业务价值无限资本化、忽略保证与尾部风险 |

保险负债本身就是产品义务，不能像制造企业借款一样从一个粗略企业价值中机械扣除。寿险价值要区分调整后净资产、现有有效保单未来税后利润、维持所需资本成本和未来尚未承保的新业务；财险还要重视赔付发展、准备金冗余／不足、再保险可收回性和巨灾尾部。

资本约束微例：保险公司实际资本 180、最低资本 100，综合偿付能力充足率为 `180/100=180%`。若公司内部目标为 150%，在其他条件不变下，估值日可释放资本上限只是 `180−100×150%=30`，并非当期会计利润 80。若新业务使最低资本增加 20，所需目标资本随之增加 30，新增利润在资本释放前不能全额分给股东。

嵌入价值可以写成 `调整后净资产 + 在手业务未来利润现值 − 尚未包含的资本/期权成本`。若调整后净资产 300、在手业务扣除资本成本后的现值 170，则嵌入价值为 470。假设本年新业务价值 50，不代表应再无期限加上 `50×固定倍数`：未来销售量、利润率、资本、退保、渠道和竞争均未被证明，而且现有保单与未来新业务不能重复计入。

财政部[财会〔2025〕12 号](https://kjs.mof.gov.cn/zhengcefabu/202506/t20250612_3965538.htm)明确：新《企业会计准则第 25 号——保险合同》此前已在部分上市企业实施，其他执行企业会计准则的企业原则上自 2026-01-01 执行，确有困难的保险公司存在按通知申请暂缓的主体边界；因此跨公司比较必须核对实际采用版本。[IFRS 17](https://www.ifrs.org/issued-standards/list-of-standards/ifrs-17-insurance-contracts/)自 2023-01-01 起在 IFRS 口径生效，也不能与中国特定公司的过渡状态混写。

偿付能力方面，[金规〔2024〕22 号](https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=1191096&itemId=915)只将规则Ⅱ过渡期延长至 2025 年底；截至本页基准日，不应在没有公司特定依据时继续把该过渡优惠当作 2026 年常态。会计合同服务边际、行业公布的内含价值和监管实际资本也不是同一个量，不能互相替代。

## 券商 {#securities-firms}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 经纪、财富、投行、资管、做市与自营的周期风险调整收益 |
| 可预测现金流 | 满足净资本、流动性和业务风险准备后可归股东的现金 |
| 资本／监管约束 | 净资本、风险覆盖率、资本杠杆率、流动性覆盖率和稳定资金率 |
| 关键分母 | 正常化净利润、调整后净资产、净资本及分部收入，而非单年牛市利润 |
| 首选／交叉方法 | 股权剩余收益、正常化 P/B 或 P/E；业务差异大时 SOTP |
| 禁用条件 | 用工业企业 EV/EBITDA 统一覆盖客户资金、自营头寸和融资业务 |

券商同属金融机构，但经纪手续费、承销、资管、自营和资本中介的风险、资本占用与周期不同。稳定客户资产和收费率可支持经纪/财富现金流，自营收益却应按风险敞口和完整周期正常化；把一轮牛市中的交易量和投资收益永久化，会同时高估利润与可分配资本。

监管容量微例：某券商净资本 200、各项风险资本准备合计 120，风险覆盖率为 `200/120=166.67%`。新业务若使风险资本准备增加 50，在净资本不变时降至 `200/170=117.65%`。即使教学中只看 100% 监管底线仍未跌破，公司若维持 140% 内部缓冲，也没有足够容量；需要减仓、留存利润或补充资本。这个例子不替代完整监管报表，其他杠杆和流动性指标也可能先约束业务。

证监会公告〔2024〕13 号发布的[《证券公司风险控制指标计算标准规定》](https://www.csrc.gov.cn/csrc/c101954/c7507765/content.shtml)自 2025-01-01 施行，现行[《证券公司风险控制指标管理办法》](https://www.csrc.gov.cn/csrc/c106256/c1653957/content.shtml)同时规定风险覆盖率、资本杠杆率和流动性指标。估值应按基准日实际计算规则和公司业务结构建模，不能把旧标准下净资本序列不加调整地与新口径比较。

P/B 仍应由可持续 ROE、权益成本和增长解释；若自营资产按市场计量，账面权益会随市场波动，须区分已实现收益、OCI 和风险暴露。投行业务可用中周期收入/利润交叉，资管可参考管理资产和费率，但客户资产不属于券商自身资产，不能纳入 NAV。

## 房地产 {#real-estate}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 可售项目剩余现金、出租物业收益、土地权利及开发管理能力 |
| 可预测现金流 | 逐项目销售、回款、建安、税费、融资和交付现金流 |
| 资本／监管约束 | 预售资金用途、项目公司债务、交付义务、土地和融资条件 |
| 关键分母 | 项目税后 NAV、可售货值、租金 NOI；合同销售不等于会计收入 |
| 首选／交叉方法 | 项目 DCF/NAV；稳定出租资产收益法；正常化利润倍数仅作交叉 |
| 禁用条件 | 用合同销售直接套 P/S、把预售现金当超额现金、忽略剩余成本和税负 |

地产应先拆开发存货、投资性物业、自用资产和管理服务。项目 NAV 不是“土地账面价值加售价”，而是估值日对未来可收售价减去剩余建安、营销、税费、融资和时间风险后的现值。权属、规划、施工、去化、回款和交付任何一环变化，都会改变现金流。

微型 NAV：项目 A 的剩余销售回款现值 600，剩余建安及营销 250，项目税费 50，净项目价值为 300；稳定出租物业价值 400，其他可处置土地税后价值 120，可支配现金 70，集团债务 350，非控股权益 20，总部成本现值 50，则：

`权益 NAV = 300+400+120+70−350−20−50 = 470`。

若项目 A 的 600 只是未折现名义货值，或没有按权益比例计入，470 就不可用。已收预售款支持现金，却同时附带建造交付义务，受监管或项目限制的余额不能全部当超额现金。项目债务若已从项目净现金流扣除，就不能在集团层再扣。

某年合同销售 500、达到控制权转移条件而确认的收入只有 200，两者不是可互换分母。财政部修订的[《企业会计准则第 14 号——收入》](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694006.htm)以履约义务完成、客户取得商品控制权为收入确认核心；签约、开票、预收或网签均不能单独替代判断。因此用市值/合同销售与同行对比时，只能视为经营指标倍数，不能称会计 P/S。

反例是高周转开发商与长期持有出租物业公司：前者价值受项目毛利、回款和土地再投资驱动，后者受 NOI、资本化率、租约和利率驱动，同属“房地产”却不应使用同一首选方法。困境企业还须引入债权优先、停工续建资金和清算折价，账面 NAV 不构成股权地板。

## 资源企业 {#resource-companies}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 有合法权利且经济可采的储量、品位、成本位置和开发选择权 |
| 可预测现金流 | 逐矿山产量、实现价、回收率、现金成本、资本开支、税费与闭矿现金流 |
| 资本／监管约束 | 矿业权、许可、生态修复、安全、基础设施和大额前置资本 |
| 关键分母 | 同一储量规范下的可采量、产量和单位成本；资源量不能冒充储量 |
| 首选／交叉方法 | 有限寿命矿山 DCF／NAV；EV/储量、EV/产量仅作同口径交叉 |
| 禁用条件 | 现货价永续、把未探明资源全量计价、忽略品位地点回收率和弃置责任 |

资源企业不是普通永续增长企业。一个矿山的经济寿命受可采储量、产能、品位、回收率、价格、成本和许可共同决定；勘探资源可能具有期权价值，却不能按已开发储量的单位价值直接相乘。跨公司比较还要统一储量报告规范、权益比例、矿种、品位和截止日期。

微例：经济可采储量 10 百万吨，计划年产 2 百万吨，静态储量寿命为 `10/2=5 年`。假设实现价 800 元/吨、现金成本 500 元/吨、维持资本开支 100 元/吨、资源税费及修复准备对应现金成本 50 元/吨，则正常年份税前矿山现金流为：

`2 百万吨 × (800−500−100−50)元/吨 = 300`。

估值仍须逐年处理爬坡、品位下降、所得税、扩建资本和第 5 年闭矿现金流，不能把 `300/(折现率−增长率)` 永续化。若商品价下降到 600，单位余量只剩 `−50`，高成本储量可能转为不经济，储量本身也会随经济假设变化。

2024 年修订的《矿产资源法》自 2025-07-01 施行；[《矿产资源法实施条例》](https://www.cgs.gov.cn/zcjd/202605/t20260521_860444.html)由国务院令第 839 号公布，自 2026-06-15 施行。截至本页基准日，两者均已生效。估值应核查矿业权登记、勘查／采矿许可和生态修复义务，不能把法律上的国家矿产资源所有权、矿业权和会计资产混为一项“永久资源所有权”。

周期正常化仍要保留价格敏感性：长期价格可以用成本曲线、供需和可替代性建立情景，但敏感性不是预测。EV/储量低可能来自低品位、偏远地点、巨额开发资本或权利期限，并不自动便宜。

## 公用事业 {#utilities}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 受监管或合同允许的资本回报、服务量、效率和剩余特许期限 |
| 可预测现金流 | 价格机制、准许成本／收益、回款、资本开支和移交安排下的现金流 |
| 资本／监管约束 | 价格核定、服务质量、资本计划、政府支付、特许经营和资产移交 |
| 关键分母 | 受监管资产基础、容量、销量、允许收益或正常化 EBITDA，依制度限定 |
| 首选／交叉方法 | 监管／合同驱动 DCF；稳定资产可用股利或 EV/EBITDA 交叉 |
| 禁用条件 | 假设所有成本自动传导、把特许期写成永续、机械移植外国监管资产会计 |

公用事业的低波动来自制度和需求条件，不代表无风险。必须先分清价格受监管业务、竞争性发售业务、政府付费项目和特许经营项目。监管回报率是特定定价制度下对认可资产与成本的参数，不是所有中国公用事业的统一 WACC，也不保证每期实际赚到。

假设某受监管环节认可资产基础为 1,000，教学允许回报率 7%，认可折旧 50、可转嫁运营成本 500，则简化准许收入为：

`1,000×7% + 50 + 500 = 620`。

这只是价格模型起点；实际股权现金流还要考虑销量偏差、核价滞后、效率奖惩、税、资本开支、回款和债务。若资本开支没有及时进入认可资产，或成本被认定不审慎，620 不会自动实现。国家发展改革委 2025 年发布的[输配电定价成本监审及定价办法](https://zfxxgk.ndrc.gov.cn/web/iteminfo.jsp?id=20567)说明具体受监管环节须按现行办法核定，不能把示例 7% 泛化。

若特许经营权剩余 20 年且期末无偿移交，模型应折现 20 年内股权现金流和合同约定终值，不能用永久增长。现行[《基础设施和公用事业特许经营管理办法》](https://www.ndrc.gov.cn/xxgk/zcfb/fzggwl/202404/t20240409_1365563.html)由六部门第 17 号令公布，自 2024-05-01 施行；具体项目权利仍来自协议、行业法和审批。中国一般企业会计准则没有可对所有公用事业机械确认“监管资产”的统一模型，经济上的未来回收预期不自动成为会计资产或无风险价值。

## 平台企业 {#platform-companies}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 多边网络、匹配效率、用户留存、数据和生态变现能力 |
| 可预测现金流 | 各侧用户、交易额、收费率、补贴、履约成本、固定投入和监管成本 |
| 资本／监管约束 | 获客资金、数据与算法治理、竞争规则、商户关系和内容责任 |
| 关键分母 | 净收入、毛利、贡献利润、活跃用户与留存；GMV 不是会计收入 |
| 首选／交叉方法 | 分层单位经济驱动 DCF；EV/收入或 EV/毛利在统一总额净额后交叉 |
| 禁用条件 | 直接给 GMV 收入倍数、把用户数等同可变现用户、假设网络效应必然垄断 |

平台连接多边主体，交易总额只描述在规则口径内发生的交易规模。平台是主要责任人还是代理人，决定其收入可能按商品总额或净佣金列报；这个会计判断与商业影响力、GMV 定义也不是同一问题。[收入准则](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694006.htm)要求以商品转移给客户前是否控制商品判断主要责任人，不能只看谁开票或收款。

微例：平台 GMV 为 10,000，名义收费率 5%，毛收费为 `10,000×5%=500`；假设付给客户且不换取可区分服务的激励 60 应冲减交易价格，净收入为 440。履约、支付和客服等变动成本 260，贡献利润 180；技术和总部固定成本 250，故经营亏损 70。GMV 看似庞大，却没有说明成熟利润率或未来现金流。

如果另一平台作为商品主要责任人，把 2,000 的商品销售总额列为收入，二者 EV/收入不可直接比较；应重构毛利或贡献利润。用户增长也要与获取成本、留存、跨边转化和欺诈率配对。网络效应可能被多归属、互操作、低切换成本或监管削弱，不是“赢家通吃”的估值许可证。

[国务院反垄断委员会关于平台经济领域的反垄断指南](https://www.samr.gov.cn/zt/ndzt/2025n/sqxzjcgs/jcbz/art/2025/art_27c2be1ca40b42a9949c12dbd213ba8e.html)界定平台为使相互依赖的双边或多边主体交互的商业组织形态，并要求在反垄断法框架下分析。估值应把潜在合规成本、商业模式调整和竞争反应写成情景，不应把合规风险简单变成任意折价率。

## 控股公司 {#holding-companies}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 对上市与非上市持股的经济权利、资本配置能力和控制安排 |
| 可预测现金流 | 子公司可上缴股息、资产处置净额及控股层费用和融资现金流 |
| 资本／监管约束 | 分层债务、质押、少数股权、分红限制、税和跨境汇回 |
| 关键分母 | 按持股比例的税后资产净值、母公司净债务和总部成本 |
| 首选／交叉方法 | 穿透 SOTP／NAV；股利折现检验现金能否真正到达母公司 |
| 禁用条件 | 用子公司市值加总后漏扣层层债务，或在结果上机械再加“控股折价” |

控股公司估值应逐层画出法律主体、持股比例、债务位置、担保与现金上行路径。子公司的账面现金不能自动偿还母公司债务；受监管子公司、合资协议或质押可能限制分红。上市持股的屏幕市值也只是在特定流动性下的标记，大宗退出、税和控制权会改变可实现额。

微型穿透 NAV：上市股权持仓按归属份额价值 800，非上市业务股权价值 400，已扣项目债务的物业权益 NAV 200，母公司可用现金 100；母公司债务 300，潜在处置税 60，总部成本现值 50，则：

`控股公司普通股价值 = 800+400+200+100−300−60−50 = 1,090`。

由于三个持股项目输入的都是股权价值，其子公司债务已在各自价值中反映，不能再汇总扣除。反之，若某项目输入的是企业价值，必须先扣该项目净债务和非控股权益，再进入控股层。

若控股公司市场市值为 900，观察到的 NAV 折价为 `1−900/1,090=17.43%`。这不是可在 1,090 上再机械扣 17.43% 的独立负债；折价可能已反映税、总部成本、治理、资本配置、流动性和上行限制。应把能量化的原因放入现金流，剩余折价只作为市场比较和情景，而不能为了拟合市场重复扣减。

## 资产重组企业 {#restructuring-companies}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 重组前各项权利、交易对价、可实现协同及重组后资本结构 |
| 可预测现金流 | 原业务、置入／置出资产、整合成本和协同的分阶段现金流 |
| 资本／监管约束 | 交割条件、审批、业绩承诺、锁定安排、债务承接和少数股权 |
| 关键分母 | 重组后同范围利润、净资产、股份和净债务；历史分母常已失效 |
| 首选／交叉方法 | 交易前后桥接、情景 DCF 与形式 SOTP；可比交易仅作交叉 |
| 禁用条件 | 用旧股数除新利润、把公告协同全额资本化、把商誉当新增价值 |

重组估值必须明确“签约、批准、交割、并表、协同实现”不是同一时点。价值基准日若尚未交割，应对失败、延期、融资和条件变更建情景；若已交割，则使用更新后的资产范围、净债务、非控股权益和潜在股份。业绩承诺是合同安排，不是经营结果保证，补偿能力和条款也要单独估值。

换股微例：收购方重组前普通股价值 1,200、在外股份 100，价值 12 元/股；目标独立价值 600，预计可实现协同 150。双方约定目标股东取得 50 百万股新增股份；假设无债务变化和费用，则重组后总权益价值为：

`1,200+600+150 = 1,950`；

`重组后每股价值 = 1,950/(100+50)=13.00 元`。

原股东持有价值 `100×13=1,300`，较原 1,200 增加 100；目标股东的新增股份在该情景下价值 `50×13=650`，相对目标独立价值取得 50，二者合计恰为协同 150。这是用重组后价值反推固定换股比例下的价值分配，不是说签约日 50 百万股已具有确定的 650 对价。若整合损失 80、交易成本 20，重组后价值降为 1,850、每股 12.33；公告中的协同不能跳过实现成本。

支付对价超过可辨认净资产公允价值形成的会计商誉，不等于交易创造了同额经济价值，也不能在 DCF 上再加一次。置出亏损资产可能改善未来利润，却也可能失去营运现金、担保或税收资产。反向收购、借壳和资产注入还会改变会计购买方、比较期间和每股分母，必须分别处理法律交易与会计控制。

证监会第 230 号令发布的[2025 年修改决定](https://www.csrc.gov.cn/csrc/c101953/c7558586/content.shtml)自 2025-05-16 公布之日起施行，[《上市公司监管指引第 9 号》](https://www.csrc.gov.cn/csrc/c101954/c7558564/content.shtml)同日施行。截至本页基准日，上市公司重组应核对现行办法、注册审核、交易所规则和具体方案，不能沿用旧版比例或程序；本页算例仅解释价值分配，不判断个案是否构成重大资产重组。

## 分部加总估值 {#sum-of-the-parts-valuation}

| 统一框架 | 判断 |
| --- | --- |
| 价值来源 | 各分部不同风险、资本结构和现金流的组合，以及集团层协同或拖累 |
| 可预测现金流 | 每个分部独立、可核对且不含重复总部或内部交易的现金流 |
| 资本／监管约束 | 分部债务与资本、现金上行、非控股权益、税、总部承诺和或有负债 |
| 关键分母 | 各段各自最有经济意义的分母，最终统一到同一价值基准日和权益层级 |
| 首选／交叉方法 | 分部 DCF、剩余收益、NAV 或相对估值后统一桥接；集团 DCF 作交叉 |
| 禁用条件 | 把企业价值与股权价值直接相加、漏扣净债务、重复总部成本或机械控股折价 |

SOTP 不是“挑每段最高估值再相加”，而是对不同价值主体使用相配方法。工业分部可用 FCFF 得到企业价值；银行应直接估股权；地产项目可以用已扣项目债务的权益 NAV。所有输入须在同一基准日、币种、税和权益比例下，内部销售、交叉持股和总部成本只处理一次。

统一案例：工业分部 FCFF 价值为企业价值 900，其分部净债务 300；银行分部剩余收益模型直接给出股权价值 500；地产分部项目 NAV 已扣项目债务，股权价值 400；母公司可用现金 100、母公司债务 200。前三段按 100% 经营口径估值，还需扣外部非控股权益 100、未分配总部成本现值 80、或有负债 50 和资产上行税负 40，则集团普通股价值为：

`900−300 + 500 + 400 +100−200−100−80−50−40 = 1,130`。

这里没有把银行存款当净债务，也没有再次扣地产项目债务。若工业 DCF 已分摊总部成本，就应删除 80；若非控股权益对应的分部只按母公司权益比例计入，也应删除 100。若总部现金为维持运营或受限资金，100 不能全额加入。

相对估值还需匹配分子：工业 EV/EBITDA 产生企业价值，银行 P/B 和地产 P/NAV 产生股权价值，必须先各自桥接才能相加。负 EBITDA、负利润或负账面权益使相关倍数没有通常经济含义，不能以绝对值修补。分部可比公司若采用不同会计准则、租赁口径、总额／净额收入或周期位置，也应先正常化。

最后才讨论集团层折价或溢价。可量化的税、总部费用、分层债务、低效资本配置和现金上行限制已经在 1,130 中处理；再套历史“控股折价”会重复。反过来，真正可验证且未进入分部现金流的共享渠道、采购或融资协同，可以单列概率加权价值。SOTP 的终审问题应始终是：每一元现金流、每一项资产、每一笔索偿和每一股潜在股份，是否只进入模型一次，并归属于正确的权利人。
