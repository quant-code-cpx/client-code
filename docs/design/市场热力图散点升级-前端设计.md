## 〇、背景与目标

### 当前问题

现有市场热力图采用 **TreeMap（矩形树图）** 展示全市场个股涨跌分布，存在以下不足：

1. **缺少"资金维度"**：TreeMap 只展示涨跌幅 + 市值/成交额，无法直观看到资金流入流出与涨跌的关系
2. **信息密度过高**：5000+ 只股票全挤在 TreeMap 中，色块过于密集、行业分区不明显
3. **交互层次单一**：缺少从宏观（行业级）到微观（个股级）的钻取路径

### 升级目标

新增**行业资金-涨跌散点图**作为页面主力视图，保留现有 TreeMap 作为"个股明细"补充视图，并优化 TreeMap 的可读性：

| 维度     | 新散点图                              | 现有 TreeMap（优化后）             |
| -------- | ------------------------------------- | ---------------------------------- |
| 粒度     | **行业/板块级**（~30-60 个点）        | 个股级（按行业分组，限制显示数量） |
| X 轴     | 涨跌幅 %（行业均值）                  | —                                  |
| Y 轴     | 资金净流入（亿元）                    | —                                  |
| 气泡大小 | 成交额                                | 市值/成交额                        |
| 颜色深浅 | 资金净流入绝对值（越大颜色越深）      | 涨跌幅（红涨绿跌）                 |
| Tooltip  | 行业内涨幅 Top5/10 + 资金流入 Top10   | 个股详情                           |
| 点击     | 路由跳转到行业详情 / 弹窗查看行业动态 | —                                  |

## 一、技术栈与约定

延续项目统一技术栈，无新增依赖：

| 技术           | 版本/说明                                                   |
| -------------- | ----------------------------------------------------------- |
| 框架           | React 19（Vite）                                            |
| UI 库          | MUI v7（`@mui/material`），使用 `sx` prop 做样式            |
| 图表           | ApexCharts（`react-apexcharts` / `apexcharts`）             |
| API 客户端     | 项目内 `src/api/client.ts` 的 `apiClient.post()`            |
| 布局容器       | `DashboardContent`（来自 `src/layouts/dashboard`）          |
| 自定义图表封装 | `src/components/chart/` 下的 `Chart` 组件和 `useChart` hook |

### 关键约定

1. **API 调用**：统一使用 `apiClient.post<T>(url, body)` 方式
2. **颜色规则**：资金净流入 → 红色系（深浅表示量级），净流出 → 绿色系（深浅表示量级），接近零 → 灰色
3. **涨跌颜色**：涨 → `error.main`（红），跌 → `success.main`（绿），平 → `text.secondary`（灰）
4. **金额单位**：
   - `SectorFlowItem.netAmount` / `amount` 单位为**万元**，展示时 ÷ 10000 转**亿元**
   - `SectorFlowRankingItem.netAmount` 等单位为**元**，展示时 ÷ 100000000 转**亿元**
5. **空值保护**：所有数值字段做 `?? 0` 兜底
6. **参考实现**：`src/sections/industry-rotation/rotation-flow-analysis-chart.tsx` 中已有气泡图实现模式可参考

## 二、数据来源 & API 端点

### 2.1 散点图数据源：行业板块资金流向

**主端点**：`POST /api/market/sector-flow`

```typescript
// 请求
{ trade_date?: string; content_type?: 'INDUSTRY' | 'CONCEPT' | 'REGION'; limit?: number }

// 响应
{
  tradeDate: string;
  sectors: SectorFlowItem[];
}
```

**`SectorFlowItem` 类型**（已在 `src/api/market.ts` 定义）：

```typescript
type SectorFlowItem = {
  tsCode: string; // 板块代码
  name: string; // 板块名称
  pctChange: number; // 涨跌幅 %  ← X 轴
  close: number; // 收盘
  amount: number; // 成交额（万元） ← 气泡大小
  netAmount: number; // 资金净流入（万元） ← Y 轴 + 颜色
  netAmountRate: number; // 净流入占比
  upCount: number; // 上涨家数
  downCount: number; // 下跌家数
  leadStock: string | null; // 领涨股
  leadPctChg: number | null; // 领涨股涨幅
};
```

> **单个端点已包含散点图所需的全部维度**：涨跌幅（X）、资金净流入（Y）、成交额（气泡大小）、涨跌家数（Tooltip）。

### 2.2 Tooltip 详细数据源：行业内个股排名

Tooltip 需要展示"行业内涨幅 Top5 / 资金流入 Top10"，有两种获取方式：

**方案 A（推荐）：复用已加载的 HeatmapItem[] 数据**

现有 `fetchHeatmapData` 返回全市场个股数据（含 `groupName` / `pctChg` / `amount`），可按 `groupName` 分组后取 Top N。但缺少个股级资金流数据。

**方案 B：额外调用 `fetchMainFlowRanking` 筛选**

`POST /api/market/main-flow-ranking` 返回全市场主力资金净流入排名（含 `industry` 字段），可按行业分组取 Top N。

**最终方案：A + B 结合**

- 涨幅 Top5/Top10：从 `HeatmapItem[]` 按 `groupName` 分组，取 `pctChg` 排名前 5/10
- 资金流入 Top10：从 `MainFlowRankingItem[]` 按 `industry` 分组，取 `mainNetInflow` 排名前 10
- 两组数据在页面加载时一并获取，Tooltip 渲染时直接从内存读取（不触发额外请求）

### 2.3 现有热力图数据源

保持不变：`POST /api/heatmap/data` → `HeatmapItem[]`

#### 自定义 Tooltip（核心交互）

```typescript
tooltip: {
  custom: ({ seriesIndex }: { seriesIndex: number }) => {
    const sector = sectors[seriesIndex];
    if (!sector) return '';

    const topGainers = topGainersByGroup[sector.name] ?? [];
    const topInflows = topInflowByGroup[sector.name] ?? [];
    const netYi = toYi(sector.netAmount);
    const amountYi = toYi(sector.amount);
    const chgColor = sector.pctChange >= 0 ? '#F44336' : '#4CAF50';
    const flowColor = netYi >= 0 ? '#F44336' : '#4CAF50';

    return `
      <div style="padding:12px;min-width:280px;font-size:13px;line-height:1.6">
        <div style="font-weight:700;font-size:15px;margin-bottom:6px">${sector.name}</div>
        <div>

          &nbsp;&nbsp;
          净流入: <span style="color:${flowColor};font-weight:600">${netYi >= 0 ? '+' : ''}${netYi.toFixed(2)}亿</span>
```

#### 四象限标注

在图表区域内叠加四象限文字说明（通过 ApexCharts annotations 或 MUI 绝对定位），帮助用户快速理解：

| 象限 | 位置     | 含义                  | 颜色          |
| ---- | -------- | --------------------- | ------------- |
| 右上 | X>0, Y>0 | 涨 + 资金流入（强势） | 红色/暖色背景 |
| 左上 | X<0, Y>0 | 跌 + 资金流入（抄底） | 黄色背景      |
| 右下 | X>0, Y<0 | 涨 + 资金流出（出货） | 橙色背景      |
| 左下 | X<0, Y<0 | 跌 + 资金流出（弱势） | 绿色/冷色背景 |

### 5.5 utils.ts 新增函数

#### 散点图颜色映射

```typescript
/**
 * 根据行业资金净流入额返回气泡颜色。
 * 净流入 → 红色系（深浅表示量级）
 * 净流出 → 绿色系（深浅表示量级）
 * 接近零 → 灰色
 *
 * @param netAmount 净流入金额（万元）
 * @returns 十六进制颜色值
 */
export function getScatterColor(netAmount: number): string {
  const yi = netAmount / 10000; // 转亿元

  if (Math.abs(yi) < 0.5) return '#9E9E9E'; // 灰色 — 几乎无资金流

  if (yi > 0) {
    // 净流入 — 红色系
    if (yi >= 20) return '#B71C1C'; // 深红（超大流入）
    if (yi >= 10) return '#D32F2F'; // 红色
    if (yi >= 5) return '#F44336'; // 标准红
    if (yi >= 2) return '#EF5350'; // 浅红
    return '#EF9A9A'; // 淡红（小额流入）
  }

  // 净流出 — 绿色系
  const absYi = Math.abs(yi);
  if (absYi >= 20) return '#1B5E20'; // 深绿（超大流出）
  if (absYi >= 10) return '#2E7D32'; // 绿色
  if (absYi >= 5) return '#4CAF50'; // 标准绿
  if (absYi >= 2) return '#66BB6A'; // 浅绿
  return '#A5D6A7'; // 淡绿（小额流出）
}

/**
 * 万元转亿元，保留指定小数位
 */
export function toYi(wan: number | null | undefined, decimals = 2): number {
  return +((wan ?? 0) / 10000).toFixed(decimals);
}
```

## 六、交互流程

### 6.1 散点图交互

```
用户进入 /market/heatmap
  → 默认展示散点图视图
  → 并行加载: fetchSectorFlow() + fetchMainFlowRanking() + fetchHeatmapData()
  → 散点图渲染完成

用户悬浮到某个行业气泡
  → 显示自定义 Tooltip:
    - 行业摘要（涨跌幅、净流入、成交额、涨跌家数）
    - 涨幅前5个股
    - 资金流入前5个股

用户点击某个行业气泡
  → 打开 HeatmapSectorDetailDialog
  → 弹窗内展示:
    - 摘要统计卡片
    - 涨跌排名表（Tab 1）
    - 资金排名表（Tab 2）
    - "查看行业详情"跳转按钮

用户切换板块类型（行业/概念/地域）
  → 重新调用 fetchSectorFlow({ content_type: ... })
  → 散点图重新渲染

用户切换到 TreeMap 视图
  → 隐藏散点图，显示优化后的 TreeMap
  → TreeMap 数据已在首次加载时获取（fetchHeatmapData）
```
