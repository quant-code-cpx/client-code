## 〇、范围澄清（v3 核心修订）

用户最新决定：**这个功能不重要，有就行，不能用也没关系；直接无后端，浏览器端实现；不影响其他功能、能跑即可。**

| 维度     | v2（已废弃）     | v3（本版）                                                       |
| -------- | ---------------- | ---------------------------------------------------------------- |
| 后端     | 需新增 WS 处理器 | **无后端**                                                       |
| 传输     | Socket.IO 推送   | **浏览器端 stock-sdk 直接 fetch**                                |
| 刷新     | 后端 15s 推送    | 前端 `setInterval` 15s 轮询当前票                                |
| 失败处理 | 后端兜底         | **优雅降级**：取不到就静默回退 EOD 快照，绝不报错/不影响其他功能 |
| 重要度   | —                | 低，best-effort                                                  |

**核心设计原则（用户硬要求）**：

1. **不影响其他功能** —— 全部 try/catch 包裹，失败静默；不动 `routes`/`nav`/`api`/全局状态。
2. **能跑就好** —— 浏览器能取到就实时刷新，取不到（CORS/限流/网络）就回退快照，不抛错、不空屏。

> ⚠️ 已知风险：浏览器直连腾讯/东财存在跨域（CORS）可能。本方案接受「取不到则降级」，符合用户「不能用也没关系」。开发期会在真实浏览器验证可用性，可用则保留实时，不可用则保留降级逻辑（UI 仍显示快照，徽标显示「收盘价/快照」）。

## 一、功能要点提炼（PM 视角）

### 1.1 用户原始诉求

- stock-sdk 适合则做实时行情；先方案后开发后测试。
- 在哪只股票详情就取哪只票实时数据；与指数/导航无关。
- **最新**：无后端、浏览器端实现、不重要、能跑就行、不影响其他功能；改完方案直接开发+测试到完成。

### 1.2 模块定位

- 增强个股详情头部价格区时效性：盘中显示该票准实时价，取不到则显示 EOD 快照。
- best-effort 功能，不承诺可用性，不用于交易决策。

### 1.3 功能要点

| #   | 功能点              | 数据来源                            |
| --- | ------------------- | ----------------------------------- |
| 1   | 头部实时价覆盖      | `sdk.getSimpleQuotes([sdk码])` 轮询 |
| 2   | 实时涨跌/涨跌幅     | SDK 返回字段                        |
| 3   | 数据时间 + 状态徽标 | 轮询时间戳 + 时段判断               |
| 4   | 交易时段感知        | 前端 9:30-11:30/13:00-15:00 判断    |
| 5   | 取不到回退快照      | `overview.latestQuote` 兜底         |

### 1.4 已确认决策（v3，采用推荐项，无需再问）

- 实时价**直接覆盖**头部主价格（取到时），取不到显示快照。
- 非交易时段**停止轮询**并显示快照 + 「收盘价」徽标。
- 进入详情页**自动开启**，无手动开关。
- 失败一律静默降级。

## 三、功能细化

### 3.1 结构树

```
StockDetailHeader（小改：价格区接入）
└── RealtimeQuoteBadge（新增）
    └── useRealtimeQuote(tsCode, snapshot)（新增 hook）
        └── src/utils/stock-code.ts: toSdkCode()（新增工具）
```

### 3.2 `useRealtimeQuote(tsCode, snapshot)` hook

- mount / `tsCode` 变化：若在交易时段，立即拉一次 + 启动 15s `setInterval`。
- 每次：`sdk.getSimpleQuotes([toSdkCode(tsCode)])`，成功写 state + 时间戳；失败 `catch` 静默，保留上次值。
- 非交易时段：不启动定时器，`session='closed'`。
- unmount / `tsCode` 变化：`clearInterval`，用 `cancelled` 标志防竞态。
- 返回：`{ quote, dataTime, session, isLive, isStale, source }`，`source: 'live' | 'snapshot'`。

### 3.3 `RealtimeQuoteBadge`

- 数据优先级：实时 `quote ?? snapshot`。
- 徽标：`实时`(success) / `延迟`(warning, isStale) / `收盘价`(default, 非交易时段或仅快照)。
- 价格更新 200ms fade。

### 3.4 数据流

```
进入详情页(code) → 交易时段? → 是: 立即拉 + 15s 轮询 sdk.getSimpleQuotes
                              → 否: 显示快照 + 收盘价徽标
每帧成功 → setState → 价格区 fade；失败 → 静默保留上次/快照
离开页面 → clearInterval
```

## 四、UI/UE 设计

### 4.1 概念

「Live Ticker on Detail Header」——头部价格区轻量「活」起来，失败无感降级。

### 4.2 项目规范（必守）

- 颜色仅 `theme.palette.*`/`varAlpha`；涨红跌绿仅数据色。
- 字号 ≥ 12px；价格等宽；MUI 子路径导入；sx prop；8 倍数间距。
- 更新瞬间 200ms fade，无闪烁。

### 4.3 头部价格区布局

```
[名称 代码 交易所 标签...]
  ¥34.56  ▲ +1.23 (+3.69%)   🟢实时·14:32:05
  昨收 33.33 · 今开 33.80 · 高 35.0 · 低 33.5
盘后/取不到：  ¥34.56  ▲...   ⚪收盘价   （快照值，停止跳动）
```

### 4.4 组件要点

- 实时价沿用 `priceColor`（涨 `error.main` 跌 `success.main`）；更新 fade。
- 徽标复用 `Label`；数据时间 `caption` 灰字。

### 4.5 交互

- 进页面自动开启；切 Tab 不影响；切 code 重启轮询。

### 4.6 双主题

- 红绿走 `theme.vars.palette.*Channel`，徽标用主题色，无硬编码。

## 五、实现步骤（阶段二）

### 5.1 顺序

1. `src/utils/stock-code.ts`：`toSdkCode('300364.SZ') → 'sz300364'`（+ 单测）。
2. `src/sections/stock-detail/hooks/use-realtime-quote.ts`：轮询 + 降级 + 时段。
3. `src/sections/stock-detail/realtime-quote-badge.tsx`：实时价 + 徽标。
4. 改造 `stock-detail-header.tsx`：价格区接入 Badge，实时优先、快照兜底。
5. `package.json`：`yarn add stock-sdk`。
6. `__tests__/`：`toSdkCode` 映射、hook 降级、Badge 三态。

### 5.2 关键技术点

- stock-sdk 仅在 hook 内动态/静态 import，不进全局 bundle 关键路径（懒加载可选）。
- 全程 try/catch；失败不 setState error，仅保留快照。
- 时段判断 `use-market-session`（本地时间，A 股时段）。
- `RealtimeQuoteBadge` memo，避免 Header 整体重渲染。

### 5.3 风险与回退

- CORS/源失败 → 静默降级快照，徽标「收盘价/快照」，**不影响任何其他功能**。
- bundle 体积：stock-sdk 零依赖、轻量，影响可忽略；如显著可改动态 import。
