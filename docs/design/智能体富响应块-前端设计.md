# 智能体富响应块前端设计

> 对应服务端架构任务 Batch 017。公共消息块、引用和 Tool 类型以 `server-code/docs/agent/api/` 与生成类型为唯一契约来源。

## 功能概述

在 Batch 016 会话壳上增加可审计富响应展示：安全 Markdown、表格、通用图表、股票 K 线、财务指标、风险提示、引用和 Tool 执行摘要。视觉继续使用量化研究终端的中性、紧凑风格，不接受服务端下发任意组件、HTML、ApexCharts options 或 formatter。

`VITE_AGENT_RICH_BLOCKS_ENABLED` 默认 `false`。关闭时 Markdown 仍安全展示，结构化块显示灰度提示；开启后固定白名单组件生效。

## 渲染管线

```text
AgentMessage.contentBlocks
→ 生成契约 parseMessageBlock
→ 前端更小展示预算检查
→ 固定 type → component 映射
→ 单块 ErrorBoundary
→ Markdown / Table / Chart / Kline / Financial / Risk
```

- 未知版本、未知类型、畸形字段和超限数据只降级当前块。
- ErrorBoundary 只发送 `blockId` 观测事件，不记录模型正文、Tool payload 或持仓数据。
- 流式阶段继续展示低成本纯文本；终态快照到达后再渲染完整 Markdown 和结构化块。
- MessageItem 不保存图表实例、reader、Promise 或任意组件工厂。

## 共享安全 Markdown

`src/components/markdown/` 由研究笔记和 Agent 共用：

- 使用 `react-markdown + remark-gfm`，不启用 `rehypeRaw`，并设置 `skipHtml`。
- URL 只允许 HTTPS、HTTP、mailto、站内绝对路径和锚点；外链附 `noopener noreferrer`。
- 图片统一降级为文字提示，代码只展示不执行。
- Markdown 长度有前端安全上限；流式阶段不构建 GFM 表格等高成本节点。

## 内容块

| 类型 | 前端行为 |
| --- | --- |
| `MARKDOWN` | 共享安全 Markdown，可解析内部 citation 链接 |
| `TABLE` | MUI Table、数值右对齐、单位进表头、null 显示 `—`、安全 CSV 复制 |
| `CHART` | 本地 adapter 生成有限 ApexCharts view model，提供文字摘要和数据表替代 |
| `KLINE` | 共享 StockKline 内核，交易日排序/去重、OHLC 校验、复权 warning、数据表替代 |
| `FINANCIAL_METRICS` | 报告期、公告日、可用时点分开展示，null 不转 0 |
| `RISK_NOTICE` | 服务端风险等级映射到 MUI Alert，不允许前端降低等级 |

比例口径固定：`PERCENT` 直接按百分数展示，`DECIMAL` 乘 100 后展示百分号。CSV 对以 `= + - @` 开头的文本增加前导单引号，防公式注入。

## Tool、引用与来源

- Tool 卡调用既有 `listToolCalls({ includePayload: false })`，只展示服务端脱敏摘要。
- 历史消息默认不批量请求 Tool；用户点击“查看 Tool 执行记录”后按需加载。
- Tool 卡展示状态、attempt、耗时、数据时点、安全错误信息和有限摘要，不展开数组或嵌套原始 payload。
- 引用展示标题、来源类型、publisher、获取时间和 locator；危险 URL 降级为纯文本。
- 每个数据块展示 source type、交易日/报告期/可用时点、timezone、currency、unit、scale、adjustment 和 quality flags。

## 图表与 K 线复用

- Agent 只向本地 chart adapter 传生成契约数据，不导入股票详情巨型页面。
- StockKline 默认渲染 K 线、成交量和最近 200 条数据表。
- 股票详情仍负责取数、均线、缩放、平移和历史懒加载；共享 StockKline 负责标准 OHLCV 外壳与数据表，原交互不回退。
- Apex x 轴 formatter 对 `undefined` 做防御，避免图表库内部空标签导致整块失败。

## 性能与可访问性

- runtime guard 使用比服务端协议更小的前端展示预算：表格 200 行、图表 1,200 点、K 线 600 条等。
- Tool 摘要按需加载；ApexCharts 继续由现有 Chart 组件动态 import。
- 图表提供 `role="img"` 与文字摘要，表格和 K 线提供可展开数据替代。
- 所有表格支持窄屏横向滚动；消息仍由 `react-virtuoso` 管理。
