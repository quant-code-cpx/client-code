# 行情菜单重构 — 技术方案

> **创建日期**：2026-04-19
> **适用范围**：`行情` 导航菜单下全部 5 个子页面 + 首页仪表盘联动
> **目标**：消除数据重复展示、明确页面职能分层、补齐功能缺口、优化信息架构

---

## 一、现状问题总结

### 1.1 数据重复矩阵

| 数据维度 | 出现位置（共几处） | 问题 |
|---------|----------------|------|
| 涨跌家数/比例 | 首页`DashboardMarketBreadth` + 概览`MarketDailySnapshotCard` + 概览`MarketSentimentCard` + 热力图`StatsChips` = **4处** | 用不同接口取近乎相同的数据 |
| 行业涨跌排行 | 首页`DashboardHotSectors` + 概览`MarketSectorRankingChart` + 资金动态`SectorFlowRankingPanel`/`SectorFlowPanel` + 热力图`HeatmapSectorBarChart` = **4处** | 功能几乎完全重复 |
| 资金流向(主力/散户) | 首页`DashboardMoneyFlow` + 概览`MarketMoneyFlowCard` + 资金动态`CapitalFlowSummaryCard` = **3处** | 同一个接口的不同展示层级 |
| 涨跌幅分布 | 概览`MarketChangeDistributionChart` + 热力图`HeatmapDistributionChart` = **2处** | 完全相同的柱状图 |
| 热力图(TreeMap) | 概览`MarketHeatmapChart` + 热力图独立页 + 行业轮动`RotationHeatmapChart` = **3处** | 概览的热力图与独立页高度重叠 |
| 行业资金流 | 资金动态`SectorFlowRankingPanel` + 行业轮动`RotationFlowAnalysisChart` = **2处** | 数据同源，视角稍异 |
| 行业估值 | 概览`MarketValuationCard`/`TrendChart` + 行业轮动`RotationValuationChart` = **2处** | 概览看全A，轮动看行业维度 |

### 1.2 功能缺口

| 缺失项 | 已有 API | 影响 |
|--------|---------|------|
| 市场成交量/额分析 | `fetchVolumeOverview()` | 组件`MarketVolumeChart`已写好但未挂载 |
| 概览页无北向资金 | `fetchHsgtFlow()` | 首页有，概览反而没有 |
| 概览页无刷新按钮 | — | 盘中无法手动刷新 |
| 指数脉搏 18 指数过多 | — | 信息过载，稀释核心指数的关注度 |

### 1.3 菜单定位模糊

- **首页 vs 市场概览**：~60% 数据重叠，缺乏递进关系
- **热力图独立页 vs 概览内嵌热力图 vs 行业轮动热力图**：三处热力图功能边界不清
- **资金动态的板块资金 Tab vs 行业轮动的资金流分析**：同维度数据分散在两个菜单

## 二、重构方案

### 2.1 菜单结构调整

**当前：**
```
行情
├── 市场概览
├── 指数详情
├── 资金动态
├── 行业轮动
└── 市场热力图
```

**重构后：**
```
行情
├── 市场总览        ← 重新定位：当日全景 Dashboard（去重 + 补缺）
├── 指数详情        ← 保持不变
├── 资金动态        ← 保持不变（最完整的专题页）
└── 行业分析        ← 合并：行业轮动 + 市场热力图
```

**变更说明：**
- ❌ 移除独立"市场热力图"菜单项
- ✅ "行业轮动" → 更名为"行业分析"，整合热力图作为子 Tab
- ✅ "市场概览" → 更名为"市场总览"，重新聚焦

### 2.2 各页面职能重新定义

| 页面 | 核心定位 | 用户场景 | 停留时间 |
|------|---------|---------|---------|
| **首页** | 5 秒速览 — "今天市场怎么样" | 登录后第一眼 | <30秒 |
| **市场总览** | 当日深度全景 — "今天具体发生了什么" | 盘中/盘后复盘 | 3~5分钟 |
| **指数详情** | 单指数钻取 — "这个指数怎么回事" | 研究特定指数 | 2~5分钟 |
| **资金动态** | 资金专题 — "钱去哪了" | 跟踪资金流向 | 3~10分钟 |
| **行业分析** | 行业专题 — "哪些行业在轮动" | 行业选择/配置 | 5~15分钟 |

## 六、UI 设计规范

### 6.1 整体美学方向

**Tone**：**精致实用主义（Refined Utilitarianism）**
— 不追求华丽动效，追求信息密度与可读性的极致平衡。参考 Bloomberg Terminal 的信息密度 + 现代仪表盘的视觉层次。

### 6.2 市场脉搏卡片重设计

```
┌───────────────────────────────────────────────────────────────────────┐
│ ● 市场脉搏                                     情绪分: 62 偏贪婪 🟠  │
│                                                 2026-04-18           │
├───────────┬───────────┬───────────┬───────────┬───────────┬──────────┤
│  上证指数  │  深证成指  │  沪深300  │  中证500  │  中证1000  │  创业板指  │
│  3,421.50  │  11,234.8  │  4,012.5  │  5,678.3  │  6,123.4  │  2,345.6  │
│  +1.23%    │  -0.45%   │  +0.89%  │  -0.12%  │  +2.01%  │  +0.56%  │
│  ▁▂▃▄▅▆   │  ▆▅▄▃▂▁   │  ▁▂▄▅▆▇  │  ▅▄▃▂▁▂  │  ▁▃▅▇▆▅  │  ▂▃▄▅▆▅  │
├───────────┴───────────┴──────[展开更多 12 个指数]──────────┴──────────┤
│  ▲涨停 42   ▼跌停 8   ▲大涨 156   ▼大跌 23   ■平盘 312   ●总计 5281 │
│  ████████████████████████░░░░░░░░░░░  72% 涨 ─────────── 28% 跌     │
└───────────────────────────────────────────────────────────────────────┘
```

**设计要点：**

- **情绪分 Badge**：右上角显示 0~100 分数 + 文字标签 + 色点（恐惧绿→贪婪红渐变）
  - `< 20` → 极度恐惧 🟢（`success.dark`）
  - `20~40` → 偏恐惧 🟢（`success.main`）
  - `40~60` → 中性 ⚪（`text.secondary`）
  - `60~80` → 偏贪婪 🟠（`warning.main`）
  - `> 80` → 极度贪婪 🔴（`error.main`）
- **指数折叠**：默认 6~8 个（第一行），点击"展开更多"显示余下指数，动画展开
- **指标行**：使用 Iconify 图标 + 数值 + 标签，紧凑单行排列，颜色语义化

## 十一、风险与注意事项

1. **旧路由兼容**：用户可能收藏了 `/market/heatmap` 或 `/market/industry-rotation`，必须保留 `<Navigate>` 重定向
2. **组件状态管理**：行业分析页合并后，Tab 切换时保持日期/周期状态同步
3. **API 请求优化**：合并页面后避免一次加载全部 Tab 数据，使用懒加载（仅当 Tab 激活时请求）
4. **首页组件不动**：首页的 dashboard 组件是独立的，不受本次重构影响
5. **Mock 数据**：需确认 `src/mocks/data/` 和 `src/mocks/handlers.ts` 覆盖所有接口
