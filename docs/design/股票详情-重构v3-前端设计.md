### 1.4 资深从业者补充（再次站位）

- **"今日定调"必须可点击**：定调一句话不能只是文本，应可点击展开解释（哪些规则触发、对应阈值、参考样本数）。否则用户不信任。
- **K 线区间选择需要"事件叠加"**：财报披露日、分红除权日、停牌复牌日应在 K 线上以图标标识，用户研究异动归因时高频使用，缺这个会反复切到事件日历模块。
- **筹码 Tab 必须有"历史回放"**：单日筹码即使展示了 7/30/90 日迁移，仍不如"时间滑块拖动看每日筹码图"直观。这是机构标配。
- **同行对比需 normalize**：直接列 PE/PB 看不出来，需要"同行业分位 + 历史百分位（5/10 年）"双维度。
- **"用此票回测"应保留参数草稿**：用户填一半参数关闭后再次点击应恢复，对接 v2 回测工作台草稿自动保存能力。

### 3.2 子模块新增/调整

#### 3.2.0 `MarketKlineCard` 周期范围（2026-05-04 已确认）

- **职责**：行情图只承载日级研究，不模拟实时行情。
- **数据**：仅调用 `chart({ period: 'D' | 'W' | 'M', adjustType, overlayCodes? })`；阶段二不得调用 `fetchMinuteKline()`。
- **交互**：周期切换按钮只保留「日 / 周 / 月」三项；隐藏 1/5/15/30/60 分钟按钮。
- **状态**：头部显示 `latestTradeDate` 与 `quoteStatus`；不显示"实时"、"盘中"、"X 秒前行情"文案。
- **边界**：如后端返回分钟数据，也不在本期 UI 暴露；未来接入实时数据时另起 v4 / 后续设计。

#### 3.2.1 `HeaderTodayLine`（v3 新增点击展开）

- **职责**：一句话定调 + 点击展开规则细节。
- **数据**：优先 `overview.todayHeadline`；为 null 时调 `useTodayHeadlineFallback()` 工具函数。
- **交互**：点击展开 Popover，列出"触发规则 + 阈值 + 当前值"。
- **状态**：fallback 时在文末加灰色 chip "前端规则"，提示用户来源。
- **边界**：非交易日返回"今日为非交易日（YYYY-MM-DD）"。

#### 3.2.2 `NotesDrawer`（v3 替代原 notes 主 Tab）

- **职责**：从头部"写笔记"按钮打开右侧抽屉，含笔记列表 + 新建。
- **数据**：`getStockNotes(tsCode)` + `overview` 当前价格快照。
- **交互**：
  - 抽屉内"新建笔记"跳转 `/research/notes/new?tsCode=&snapshotPrice=&snapshotTradeDate=&snapshotPctChg=&snapshotName=`。
  - 列表项点击进笔记详情。
  - 抽屉支持 ESC / 点击遮罩关闭。
- **状态**：loading Skeleton；空态显示"还没有笔记，开始记录第一条观察"。
- **边界**：旧路由 `?tab=notes` 重定向为"打开 NotesDrawer + tab=market"。

#### 3.2.3 `MarketKlineCard.EventMarkerToggle`

- **职责**：在 K 线上叠加事件标记（财报、分红、停牌复牌、解禁）。
- **数据**：`chart()` 响应附加 `events: Array<{ tradeDate, type, label, severity? }>`（后端补）。
- **交互**：默认开；点击事件 marker 弹 Popover 显示"事件 + 影响"；可在右上工具栏关闭。
- **状态**：事件密度过高时聚合为 `+N` 标记。
- **边界**：事件类型枚举固化 `EARNINGS / DIVIDEND / SUSPEND / RESUME / UNLOCK / RIGHTS_ISSUE / OTHER`。

#### 3.2.4 资金筹码子 Tab — 历史回放滑块

- **职责**：拖动时间滑块查看任一交易日的筹码分布。
- **数据**：后端新增 `chipDistribution.timeline: Array<{ tradeDate, distribution }>`，或新增端点 `chipDistributionTimeline()`。
- **交互**：滑块默认最右（最新交易日）；左右键步进；播放按钮按交易日逐日播放（200ms/帧）。
- **状态**：单日数据缺失时跳过；播放过程中数据请求并发控制（最多 1 个）。
- **边界**：跨度超过 250 个交易日时强制采样（每 5 日一帧）。

#### 3.2.5 对标子 Tab — 分位列

- **职责**：在同行表中加入"行业分位"+"历史百分位（5y）"。
- **数据**：peers 接口新增 `industryPercentile / historicalPercentile5y / historicalPercentile10y`。
- **交互**：列表头可排序；行 hover 显示百分位说明 tooltip。
- **状态**：分位为 null 时显示 "—" + "样本不足" tooltip。
- **边界**：新股（< 250 交易日）分位置灰。

### 3.3 数据流与状态管理（v3 补充）

## 七、需后端支持点（v3 新增/澄清；不重复 v2）

> v2 已列后端清单（[股票详情-重构-前端设计.md § 5.4](../archive/股票详情-重构-前端设计.md#54-后端支持落地清单)）。本节仅记录 v3 新增/优先级调整/字段澄清。

### 7.1 v3 新增（建议进 P1 / P2）

| 优先级 | 后端改动                                                                                                                                                             | 验收口径                                            |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| P1     | `chart()` 响应附 `events: Array<{ tradeDate, type: 'EARNINGS'\|'DIVIDEND'\|'SUSPEND'\|'RESUME'\|'UNLOCK'\|'RIGHTS_ISSUE'\|'OTHER', label, severity?: 1\|2\|3 }>`     | K 线事件 marker 一次拉取；前端不再调事件日历模块    |
| P1     | `peers()` 响应字段扩展：`industryPercentile / historicalPercentile5y / historicalPercentile10y`（PE/PB 分别返回）                                                    | 对标 Tab 分位列可用                                 |
| P1     | `overview.relatedAssets`：`{ watchlists: [{ id, name }], alerts: [{ id, status }], reports: [{ id, latest }], notes: [{ id, title, updatedAt }] }`，按当前 user 过滤 | 头部"已加入 X / X 条预警"chip 可显示                |
| P1     | `overview` 新增字段 `dataLineage?: { source: string; fetchedAt: string; metric?: string }[]`，按字段域聚合                                                           | 关键指标 tooltip 显示数据来源 / 取数时间 / 计算口径 |
| P1     | 新增 `POST /api/stock/detail/analysis/chip-distribution-timeline`：Body `{ tsCode, startDate?, endDate?, sample? }`，返回 `[{ tradeDate, distribution }]`            | 筹码历史回放滑块                                    |
| P2     | `overview.todayHeadline` 规则可配置（管理员后台维护规则字典与阈值）                                                                                                  | 避免规则硬编码在后端代码内                          |
| P2     | `peers()` 响应附 `peerGroup: { industry: string; conceptCodes: string[]; total: number }` 元信息                                                                     | 前端可展示"同行业共 X 只 / 同概念共 X 只"           |

### 7.2 v3 字段澄清（不算新增，但需后端确认）

| 项目                            | 澄清点                                                                                                                             |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `tsCode` vs `code` vs `ts_code` | 所有 stock-detail 端点统一使用 `tsCode`（驼峰）；前端 URL 仍允许 `?code=`，Body 转换在 `stockDetailApi` 层完成                     |
| `quoteStatus` 枚举              | `'OK' \| 'STALE' \| 'SUSPENDED' \| 'MISSING' \| 'NON_TRADING_DAY'`，明确五种                                                       |
| `capabilities` 字段全集         | `pattern` / `institutional` / `peers` / `signalSummary` / `chipTimeline` / `dataLineage`，按需增量返回；`realtimeQuote` 本期不需要 |
| `overlayCodes` 上限             | 建议后端限制 ≤ 3 个，超出返回 400 错误                                                                                             |
| `events.severity`               | 1=低 / 2=中 / 3=高，前端按 severity 渲染 marker 颜色透明度                                                                         |

### 7.3 v3 跨模块后端联动

| 跨模块                    | 后端联动需求                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 研究笔记 ← 详情页跳转     | `POST /api/research-note/create` 接收 `snapshotPrice / snapshotTradeDate / snapshotPctChg / snapshotName` 字段并存 |
| 价格预警 ← 详情页创建     | `POST /api/alert/price-rules/create` 接收 `tsCode` 预填，返回 `ruleId`；详情页头部 chip 实时刷新                   |
| 回测 ← 详情页"用此票回测" | `POST /api/backtests/runs/draft/save`（与回测工作台 v2 草稿保存共用）接收 `universe.include = [tsCode]`            |
| 自选股 ← 详情页加入       | `POST /api/watchlist/stocks/check` 检查归属；`POST /api/watchlist/stocks/batch` 加入指定组                         |
| 报告 ← 详情页生成         | 已实现，无需变更                                                                                                   |

### 7.4 本期明确不需要后端支持（避免误排期）

| 项目                     | 说明                                                                 |
| ------------------------ | -------------------------------------------------------------------- |
| 分钟级 K 线接口          | 本期行情图只保留日 / 周 / 月，不接 `fetchMinuteKline()` 与分钟周期。 |
| WebSocket / SSE 实时行情 | 当前无实时数据，本期不新增 `/api/realtime/quote`。                   |
| 30 秒轮询行情            | 不做自动轮询，只保留手动刷新日级概览。                               |
| 盘中状态文案             | 不展示"实时 / 盘中 / X 秒前行情"；只展示 `latestTradeDate`。         |
