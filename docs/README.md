## 维护规则

1. 设计完成、被替代或仅保留历史价值时，移入 `archive/` 并更新本索引。
2. 测试报告在该轮执行结束后归档；未关闭问题只在 `testing/已知问题待办.md` 维护。
3. 活跃待办只记录可执行事项；过期清单保留在归档，不重复制造状态来源。
