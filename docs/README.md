## 文档编写约定

1. **设计文档**（`design/`）面向 AI 代码生成模型，需包含：页面布局、组件结构、API 映射、交互细节和路由规划
2. **文件命名**：中文命名，格式 `<模块名>-前端设计.md`（功能设计）
3. **状态标记**：✅ 已实现 / 🔧 待实现 / 📋 需求稿 / 🗓️ 规划中
4. **新增文档**时请同步更新本 README
