## 一、功能要点提炼与补充（PM 视角）

### 1.1 用户原始诉求复述

> [llms.txt](https://github.com/klinecharts/KLineChart/blob/main/llms/llms.txt)用这个klinechart帮我重构行情图表的展示

参考截图为股票详情页「行情」Tab：顶部包含「分时 / 日 / 周 / 月」与复权选择；主体为 K 线、MA5/10/20/60、成交量；底部可展开 K 线数据表。

### 1.2 模块定位与价值主张

- **30 秒内回答**：当前股价处于什么趋势、近期波动区间在哪里、成交量是否配合、均线结构偏多还是偏空。
- **3 分钟内完成**：切换分时/日/周/月与复权口径，缩放或拖动定位历史区间，通过十字光标核对 OHLCV 与均线，并展开原始数据表复核。
- **边界声明**：本次只重构股票详情「行情图表卡」；「今日资金流向」表和「资金流向」历史图保留现有 ApexCharts，不改接口、不改页面路由、不引入画线交易工作台。

### 1.3 功能要点提炼（结构化）

### 1.4 资深量化/二级市场从业者补充（行业最佳实践）

1. **补充主副图指标入口**：默认主图 `MA(5,10,20,60)`、副图 `VOL`；建议允许主图切为 `BOLL`，副图切为 `MACD / KDJ / RSI`。这些指标可用现有 OHLCV 本地计算，不新增后端接口。原因：只看 K 线和成交量不足以完成趋势、动量、超买超卖三类基础判断。
2. **补充十字光标信息条**：展示交易日、开/高/低/收、涨跌幅、成交量、成交额；涨跌比较统一以当前周期上一根收盘价为基准。原因：A 股研究常需逐根核对，不应依赖浮层遮住蜡烛。
3. **保留复权口径显性提示**：复权选择始终显示在图表工具栏；不复权时显示轻量提示「跨除权除息日比较需谨慎」。原因：复权口径错误会直接导致形态和收益判断错误。
4. **成交量柱跟随涨跌色**：上涨/平盘用涨色、下跌用跌色，禁止继续使用统一蓝色。原因：量价关系需要一眼关联，单色柱降低读取效率。
5. **暂不开放 AVP / EMV**：现有 `amount` 为千元、`vol` 为手；KLineChart 的 `turnover` 单位必须先标准化并用样例验算。原因：官方文档明确 AVP、EMV 依赖 `turnover`，单位错会产生貌似精确但实际错误的指标。
6. **保留交易日语义**：D/W/M 轴按交易日连续排列，不为周末和节假日留空；分时轴保留午间休市的视觉断点或刻度提示。

### 3.2 `MarketChartCard`

- **职责**：承载行情图工具栏、当前读数、图表状态和详情专用 `MarketKlineChart`。
- **数据**：只接收 `tsCode`；D/W/M 由远端 loader 按需请求；T 由分时 loader 获取。
- **交互**：切周期、切复权、切指标、复位到最新数据、展开数据表。
- **状态**：固定图表内容高度，状态层覆盖 Canvas 区，不改变卡片整体高度。
- **边界条件**：切换股票/周期/复权时取消旧结果写入；少于 2 根 bar 时隐藏涨跌幅比较；无完整 OHLC 时展示数据表与 warning。

### 3.3 `MarketChartToolbar`

| 控件     | 默认值 | 行为                                                   | 持久化                       |
| -------- | ------ | ------------------------------------------------------ | ---------------------------- |
| 周期     | 日     | `T/D/W/M` 映射到 `minute/day/week/month`；触发引擎重载 | 组件会话内保留，不写 URL     |
| 复权     | 前复权 | 分时隐藏且不参与分时 loader key                        | 组件会话内保留               |
| 主图指标 | MA     | `MA(5,10,20,60)` / `BOLL(20,2)` / 无，互斥             | `localStorage`，按用户浏览器 |
| 副图指标 | VOL    | `VOL/MACD/KDJ/RSI/无`，一次只显示一个，避免挤压        | `localStorage`               |
| 复位     | —      | 滚动到最新一根并恢复默认 bar space                     | 不持久化                     |
| 数据表   | 收起   | 展开/收起最近 200 条标准化数据                         | 不持久化                     |

- 切周期不重置指标选择。
- 切到分时将主图样式改为 `area`；主图指标固定为「均价」，副图默认 VOL。
- 切出分时时恢复用户上一次 D/W/M 指标组合。
- 复权选项使用明确文本，不用只靠图标；「不复权」显示口径 warning。

### 3.4 `MarketChartLegendBar`

- **职责**：在 Canvas 外展示当前十字光标对应 bar；未 hover 时展示最新 bar。
- **字段**：`tradeDate/time, open, high, low, close, pctChg, volume, amount`；分时展示 `time, price, avgPrice, volume`。
- **颜色**：只有 `close / pctChg` 使用涨跌数据色；标签和其他数值保持中性。
- **格式**：价格 2 位；涨跌幅 2 位并带符号；成交量仅万/亿两级且保留 2 位；成交额按后端千元口径换算后展示万/亿。
- **交互**：订阅 `onCrosshairChange`；鼠标离开后回到最新 bar，200ms 淡入，不做数字滚动动画。
- **可访问性**：使用 DOM 文本并设置 `aria-live="polite"` 但节流到每动画帧一次，避免屏幕阅读器被连续播报。

### 3.5 `KlineChartHost` 生命周期

严格遵循 v10 顺序：

1. 容器挂载且宽高有效后调用 `init(container, options)`。
2. 立即设置 `locale='zh-CN'`、`timezone='Asia/Shanghai'`、右侧 Y 轴和主题样式。
3. 调用 `setSymbol({ ticker: tsCode, pricePrecision: 2, volumePrecision: 0 })`。
4. 调用 `setPeriod({ span: 1, type })`。
5. 调用 `setDataLoader(loader)`。
6. 创建主图/副图指标并订阅 `onCrosshairChange / onVisibleRangeChange`。
7. 主题变化只调用增量 `setStyles()`，不销毁实例。
8. 股票、周期或复权变化时更新上下文并调用 v10 重载路径；禁止沿用旧数据。
9. unmount 时先取消 action 订阅和分时轮询，再 `dispose(chart)`。

实例只创建一次；React StrictMode 开发环境下必须做到「创建—清理—再创建」无残留计时器和容器关联。

### 3.6 D/W/M 远端 `DataLoader`

#### 参数映射

| KLineChart                        | 后端请求                                  | 处理                                                         |
| --------------------------------- | ----------------------------------------- | ------------------------------------------------------------ |
| `symbol.ticker`                   | `tsCode`                                  | 原样传递 `600519.SH` 等 Tushare 码                           |
| `period.type=day/week/month`      | `period=D/W/M`                            | 显式映射，禁止字符串猜测                                     |
| 当前复权状态                      | `adjustType=qfq/hfq/none`                 | 分时不传                                                     |
| `type=init`                       | `limit=150`                               | 加载最近 150 根                                              |
| `type=forward` + 左边界 timestamp | `endDate=边界交易日前一自然日, limit=150` | 加载更早数据                                                 |
| `type=backward`                   | 当前 EOD 不自动加载                       | 回传空数组与 `backward:false`；手动复位/刷新走 `resetData()` |

#### 数据标准化

1. 把后端 `tradeDate` 转为 `Asia/Shanghai` 语义的毫秒时间戳。
2. 把 `open/high/low/close/vol/amount/pctChg` 转为有限数值或 `null`。
3. 仅绘制 OHLC 完整且满足 `high >= max(open, close, low)`、`low <= min(open, close, high)` 的 bar。
4. 按 timestamp 升序排序，以 timestamp 去重；同日重复时保留最后一条并记录 warning。
5. 统一引擎基础单位：`volume = vol × 100`（股）、`turnover = amount × 1000`（元）；同时保留原始 `volumeHands / amountK` 扩展字段供 DOM 信息条按项目口径展示。
6. 虽然基础单位已统一，AVP/EMV 仍需用真实样例验算公式与复权口径后才开放入口。
7. 无论成功、空数据还是失败，`getBars` 都必须调用 `callback`。
8. 使用 `hasMore` 回传 `{ forward: boolean, backward: false }`，不再以数组长度猜测为第一优先级。

#### 并发与缓存

- 用 loader generation 标识当前 `tsCode + period + adjustType`；旧请求完成后若 generation 不同则丢弃。
- 同一方向同一边界只允许一个请求；不并发加载相同页。
- 最近一次初始化结果可在组件会话内缓存；切回周期时优先即时展示，再后台 `resetData()` 校验。
- 不把行情数据写入全局 store，避免与其他股票详情串数据。

### 3.7 分时 `DataLoader`

- **初始化**：调用 `getTodayTimeline()`，把分时点映射为 area 数据；`open/high/low/close` 均取当前价，仅用于 KLineChart 分时面积绘制，不宣称为真实分钟 OHLC；扩展字段保留 `avgPrice`。
- **成交量**：SDK `volume` 为累计成交股数；第 N 点的单点成交量取 `max(currentCum - previousCum, 0)`，第一点不绘制伪增量柱。信息条可另显示累计量。
- **时间戳**：把交易日和 `HH:mm` 组合为 `Asia/Shanghai` 毫秒时间戳；禁止仅解析 `HH:mm`。
- **样式**：通过 `setStyles({ candle: { type: 'area' } })` 切到面积分时图；昨收使用价格线/轻量 overlay。
- **均价线**：注册一次 `TIMELINE_AVG` 自定义 price indicator，读取 KLineData 的 `avgPrice` 扩展字段，以 timestamp 为 key 返回均价；不得用错误单位伪造 AVP。
- **实时更新**：`subscribeBar` 在 A 股交易时段内每 15 秒拉一次，只把最新点传给 `callback(singleBar)`；相同 timestamp 覆盖，更新 timestamp 追加。
- **清理**：`unsubscribeBar` 负责清 timer；切股票、切周期、`resetData()` 和 `dispose()` 都必须走同一清理函数。
- **失败**：分时属于 best-effort；首次失败显示「分时数据暂不可用，可切换日线」，轮询失败保留上一点，不清空图表。
- **午间休市**：11:30–13:00 不轮询；X 轴保留上午/下午关键刻度，不用连续空白分钟填充。

### 3.8 指标管理

| 指标      | KLineChart 能力          | 参数           | 数据依赖 | 首期状态           |
| --------- | ------------------------ | -------------- | -------- | ------------------ |
| MA        | 内置，叠加 `candle_pane` | `[5,10,20,60]` | close    | 默认开启           |
| BOLL      | 内置，叠加 `candle_pane` | `[20,2]`       | close    | 可选               |
| VOL       | 内置独立 pane            | `[5,10,20]`    | volume   | 默认开启           |
| MACD      | 内置独立 pane            | `[12,26,9]`    | close    | 可选               |
| KDJ       | 内置独立 pane            | `[9,3,3]`      | OHLC     | 可选               |
| RSI       | 内置独立 pane            | `[6,12,24]`    | close    | 可选               |
| AVP / EMV | 内置                     | 官方默认       | turnover | 暂禁用，待单位验算 |

- 指标切换优先 `overrideIndicator` 或移除/创建指定 pane，不重置行情数据。
- 副图保持一个，防止在 560px 高度内堆叠过多 pane。
- 交易日周期切换后由引擎基于对应 bar 重新计算指标；不复用日线 MA 到周线/月线。
- 后端 `ma5/10/20/60` 在迁移期仍返回，用于对照测试；UI 以 KLineChart 本地结果为准。

### 3.9 状态机

| 状态      | 进入条件                        | UI                                     | 可执行动作               |
| --------- | ------------------------------- | -------------------------------------- | ------------------------ |
| `loading` | 首次请求未完成                  | 固定高度 Skeleton 覆盖图表区           | 切周期、切股票会替换请求 |
| `ready`   | 至少 1 根合法 bar               | 图表 + 信息条                          | 全部交互                 |
| `partial` | 有合法 bar，同时有无效/重复 bar | 图表 + 非阻塞 warning chip             | 展开数据表查看异常       |
| `empty`   | 请求成功但 0 根合法 bar         | 「该周期暂无可绘制行情」+ 切换周期建议 | 切周期、重试             |
| `error`   | 初始化或首屏请求失败            | 错误说明 +「重新加载」                 | 重试、切周期             |
| `stale`   | 分时轮询连续失败但已有数据      | 保留图表 +「数据可能延迟」chip         | 手动重试、切日线         |

状态互斥；禁止 `error + skeleton` 或 `empty + skeleton` 同时出现。

### 3.10 数据流与跨组件联动

```text

        │
        ▼
MarketChartCard ──生成 loader key──> KlineChartHost
        │                                │
        │                                ├─ getBars(init/forward/backward)

        │                                └─ onCrosshairChange
        │                                          │
        ├<────────── 状态 / warning / latest ──────┤

```

- 行情图状态不影响今日资金流与历史资金流请求；任一模块失败不阻塞其他卡片。
- 切换主页面 Tab 时组件按现有 React 生命周期卸载；回到行情 Tab 允许重新初始化，不在隐藏 DOM 中持续绘制。
- 本次不建立全局 `StockDetailContext`，避免与尚未完成的股票详情 v3 大重构相互阻塞。

## 四、UI/UE 设计（资深 UI/UE 设计师视角）

### 4.1 设计概念关键词

**Research Terminal + Native Continuity**

- Research Terminal：高密度但有秩序，关键行情读数始终贴近图表，不用大面积装饰。
- Native Continuity：价格、指标、成交量共享同一交互与时间轴，拖动时像一个完整研究工具而不是拼接图。

### 4.2 必须遵守的项目 UI 规范

- 颜色只来自 `theme.palette.*` / `theme.vars.palette.*` / `varAlpha(...)`；KLineChart style 对象也必须由主题工厂生成。
- A 股涨红跌绿只作为数据色：上涨用 `error.main`，下跌用 `success.main`；控件选中仍用 `primary.main`。
- 字号最小 12px；价格、OHLCV、坐标轴数字使用等宽数字特性。
- MUI 仅子路径导入；工具栏与状态层优先 MUI，Canvas 内绘制交给 KLineChart。
- 间距以 8px 为基础；卡片内边距桌面 16px，窄屏 12px。
- 动效只保留 200ms 状态淡入和主题切换；缩放/拖动使用引擎原生动效，不叠加 React 动画。

### 4.3 页面布局

```text
┌────────────────────────────── 行情图表卡 ──────────────────────────────┐
│ [分时][日][周][月]  [前复权⌄]  主图 [MA⌄]  副图 [VOL⌄]       [复位] │
├───────────────────────────────────────────────────────────────────────┤
│ 2026-07-31  开 54.20  高 58.80  低 53.90  收 58.10  +7.42%          │
│              量 823.40万手  额 46.72亿元                              │
├───────────────────────────────────────────────────────────────────────┤

│                                                                       │

│                                                                       │
```

#### 尺寸

| 断点      | 卡片宽度 |                    图表内容高度 | 工具栏                                           |
| --------- | -------- | ------------------------------: | ------------------------------------------------ |
| ≥ 1440    | 容器全宽 | 560px（主图约 400，副图约 120） | 单行                                             |
| 1024–1439 | 容器全宽 |                           520px | 指标控件可换到第二行                             |

### 4.4 工具栏设计

- 周期使用 `ToggleButtonGroup`，保持截图已有心智；当前项用 `primary.main` 与 2px 下边强调，不使用大面积实心蓝。
- 复权、主图指标、副图指标使用小尺寸 `Select`；标签始终可见，禁止仅显示缩写而无说明。
- 「复位」使用 IconButton + Tooltip，只在用户已离开最新数据或改变 zoom 后启用。
- 控件高度统一 32px；工具栏总高 48px（换行时 88px）。
- 图例不放在卡片右上空白处；MA 名称与数值贴近主图左上，由引擎 tooltip 与外部信息条共同呈现。

### 4.5 主图与副图视觉

- 蜡烛实体上涨 `error.main`，下跌 `success.main`，影线同向；平盘使用 `text.secondary`。
- 网格线使用 `divider` 低透明度；仅保留必要横线，纵向网格进一步降噪。
- Y 轴固定右侧；价格保留 2 位，成交量用万/亿缩写；轴文字使用 `text.secondary`。
- MA 使用四个主题序列色，不能与涨跌红绿完全相同；建议 `primary / warning / secondary / info`，60 日线使用 `info.dark` 而非涨色。
- 分时当前价面积填充使用 `primary.mainChannel` 的低透明度；价格线按相对昨收切涨跌色，均价线使用 `warning.main`。
- 最后价标记和昨收线低调显示；最后价标记可用涨跌数据色，昨收线使用 `text.disabled` 虚线。
- 成交量副图与主图之间允许拖动分隔线；最小高度 96px，防止误拖到不可见。

### 4.6 交互细节（micro-interactions）

1. **十字光标**：进入图表后信息条立即切到对应 bar；离开恢复最新 bar。
2. **缩放**：滚轮以光标位置为锚点；触控板双指自然缩放；手机双指缩放与单指水平拖动使用 KLineChart 10.0.1 原生行为。
3. **向左加载**：到左边界显示 16px 内联 loading 标记，不覆盖整个图表；新数据前插后视觉位置保持不跳。
4. **切周期/复权**：保留卡片高度，信息条先淡出，首批新数据到达后淡入；不短暂显示旧周期数据。
5. **指标切换**：只更新 pane；不重新请求历史数据，不重置当前可视区。
6. **复位**：滚回最新一根并恢复默认 bar space；不重置周期、复权、指标。
7. **数据表**：展开时保持图表位置；表格 sticky header，最多 320px 高，使用项目 `Scrollbar`。
8. **错误重试**：只重载当前图表数据，不触发资金流接口。

### 4.7 Loading / Empty / Error 文案

| 状态    | 标题                 | 辅助文案                                 | 操作                |
| ------- | -------------------- | ---------------------------------------- | ------------------- |
| Empty   | 该周期暂无可绘制行情 | 可能处于停牌、上市时间较短或数据尚未同步 | 切换周期 / 重新加载 |
| Error   | 行情图加载失败       | 资金流等其他数据不受影响                 | 重新加载            |
| Partial | 部分行情数据未绘制   | 存在 OHLC 缺失或关系异常，可在数据表核对 | 查看数据表          |
| T 失败  | 分时数据暂不可用     | 可继续查看日线，稍后再试                 | 查看日线 / 重试     |
| Stale   | 分时数据可能延迟     | 已保留最后一次成功数据                   | 立即刷新            |

### 4.8 暗色 / 亮色双主题适配

- 用 `createKlineChartStyles(theme)` 统一生成 candle、indicator、grid、axis、crosshair、separator、tooltip、overlay 色。
- 主题切换调用 `chart.setStyles(nextStyles)`，不重新 `init`，避免 Canvas 闪白与视口丢失。
- 透明色通过主题 channel 计算；不写死 `rgba()`。
- tooltip 背景使用 `background.paper`，边框使用 `divider`，阴影使用主题预设。
- 暗色主题下红绿饱和度降低一级，保证坐标文字与网格仍可读；颜色之外用实体/空心与文字符号辅助区分。

### 4.9 可访问性与响应式

- Canvas 容器保留 `role="img"` 和动态 `aria-label`，说明股票、周期、复权与最新收盘价。
- 所有图标按钮有可见 Tooltip 和 `aria-label`；Select 有显式 label。
- 周期切换、复权选择、指标选择、复位、数据表均可键盘操作；焦点环使用主题 `primary.main`。
- 数据表承担完整数值替代；Canvas 初始化失败时自动展开表格。
- 200% 浏览器缩放、1440/1920 宽度、iPad 横竖屏和 390px 手机宽度下不产生页面横向滚动。
- `prefers-reduced-motion` 下关闭面积图涟漪和额外淡入，仅保留必要状态切换。

### 5.5 测试策略

#### 纯函数单测

- 交易日字符串/ISO → 上海时区毫秒时间戳，在 UTC、Asia/Shanghai、America/New_York 测试环境结果一致。
- OHLC 缺失、NaN、关系异常不进入绘图数据，不被转成 0。
- 数据升序、timestamp 去重、分页边界不重复。
- `vol(手) × 100 → volume(股)`、`amount(千元) × 1000 → turnover(元)`；原始单位扩展字段保留，数字字符串安全转换。
- 分时 `HH:mm` 组合交易日正确，午间数据不凭空补点。
- 分时累计 volume 差分正确：递增得到单点量，首点不画伪增量，回退/重置不产生负柱。

#### Loader 单测

- `init` 请求 150 条，`forward` 用左边界前一日，`backward` 正确回传无更多。
- 成功/空/异常三条路径均只调用一次 callback。
- `hasMore` 精确映射到 `more.forward`。
- 快速切股票/周期/复权后旧请求不写入当前图表。
