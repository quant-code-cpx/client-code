## 二、WebSocket 可靠性增强

### 2.1 背景

- 后端 §3.3：WebSocket CORS 将从 `origin: '*'` 收紧为白名单
- 后端 §3.4：断开时将清理房间状态
- 后端 §5.3.3：计划增加事件回放机制（最近 N 条环形缓冲区）

### 2.2 当前状态

- 文件：`src/lib/socket.ts`
- 使用 socket.io-client 默认重连（无显式配置）
- 断线后**不会补发**离线期间事件
- 上下文 `src/contexts/sync-notification-context.tsx` 依赖事件触发 `fetchData()` 刷新

### 2.3 设计方案

#### 2.3.1 显式配置重连参数

```typescript
// src/lib/socket.ts
_socket = io(`${WS_BASE_URL}/ws`, {
  autoConnect: false,
  transports: ['websocket', 'polling'],
  path: '/socket.io',
  // ↓ 新增
  reconnection: true,
  reconnectionAttempts: 10,
  reconnectionDelay: 1000,
  reconnectionDelayMax: 30000,
});
```

#### 2.3.2 断线事件回放

后端将支持客户端在重连时携带 `lastEventTimestamp`，返回离线期间的事件列表。

```typescript
// src/lib/socket.ts — 新增重连回放逻辑
let lastEventTimestamp: number = Date.now();

export function setupReconnectReplay(socket: Socket): void {
  // 每次收到事件，更新时间戳
  socket.onAny((_event, ...args) => {
    lastEventTimestamp = Date.now();
  });

  // 重连后请求回放
  socket.on('connect', () => {
    socket.emit('replay_missed_events', { since: lastEventTimestamp });
  });

  // 接收回放批次
  socket.on('replayed_events', (events: Array<{ event: string; data: unknown }>) => {
    events.forEach(({ event, data }) => {
      socket.emit(event, data); // 触发本地事件处理器
    });
  });
}
```

#### 2.3.3 连接状态指示器

在 `DashboardLayout` 的 Header 区域新增连接状态图标：

| 状态   | 图标                                   | 颜色           |
| ------ | -------------------------------------- | -------------- |
| 已连接 | `solar:plug-circle-bold`               | `success.main` |
| 重连中 | `solar:refresh-circle-bold` (旋转动画) | `warning.main` |
| 已断开 | `solar:plug-circle-bold` (带斜杠)      | `error.main`   |

## 四、定时报告与订阅

### 4.1 背景

后端 §5.1.2 将新增 `ScheduledReportService`，支持 cron 配置的定时报告生成与推送。

### 4.2 当前状态

- Report 模块仅支持手动生成（`report-generate-dialog.tsx`）
- 报告类型：BACKTEST / STOCK / PORTFOLIO / STRATEGY_RESEARCH
- 格式：JSON / HTML / PDF

### 4.3 设计方案

#### 4.3.1 新增 API 类型

```typescript
// src/api/report.ts 追加

export type ReportScheduleFrequency = 'DAILY' | 'WEEKLY' | 'MONTHLY';

export type ReportSchedule = {
  id: string;
  userId: number;
  type: ReportType;
  title: string;
  params: Record<string, unknown>;
  format: ReportFormat;
  frequency: ReportScheduleFrequency;
  /** cron 表达式，如 "0 18 * * 1-5" (工作日 18:00) */
  cronExpression: string;
  enabled: boolean;
  lastRunAt: string | null;
  nextRunAt: string | null;
  createdAt: string;
};

export type CreateScheduleBody = {
  type: ReportType;
  title: string;
  params: Record<string, unknown>;
  format: ReportFormat;
  frequency: ReportScheduleFrequency;
  cronExpression?: string;
};
```

#### 4.3.2 UI 设计

**入口**：Report 列表页新增 Tab — "定时报告"

**定时报告列表**（`report-schedule-list.tsx`）：

- 表格列：报告名称 | 类型 | 频率 | 格式 | 上次运行 | 下次运行 | 启用状态开关
- 操作：编辑 / 删除 / 立即运行一次
- 新建按钮打开配置对话框

**定时配置对话框**（`report-schedule-dialog.tsx`）：

- 复用 `report-generate-dialog.tsx` 的类型/参数选择
- 新增字段：
  - 频率选择：每日 / 每周 / 每月（Select 组件）
  - 执行时间：根据频率动态展示
    - 每日 → 时间选择器（默认 18:00）
    - 每周 → 星期选择 + 时间选择器
    - 每月 → 日期选择 + 时间选择器
  - 格式限制为 HTML / PDF（定时报告不建议 JSON）

## 七、股票分析筹码精确化

### 7.1 背景

后端 §4.2 将接入 `cyq_perf`（获利比例/套牢比例/筹码集中度）和 `cyq_chips`（成本分布曲线），替代当前本地估算算法。

### 7.2 当前状态

- `src/sections/stock-detail/analysis/analysis-chip-tab.tsx`
- 数据类型含 `isEstimated: boolean` 标记，当前始终为 `true`（估算值）
- 展示：筹码分布直方图 + 汇总卡片

### 7.3 设计方案

#### 7.3.1 API 类型更新

```typescript
// src/api/stock.ts — chipDistribution 返回类型增强

export type ChipDistributionData = {
  tradeDate: string;
  currentPrice: number;
  isEstimated: boolean; // 接入 cyq_perf 后将为 false
  // ↓ 新增字段（来自 cyq_perf）
  profitRatio: number; // 获利盘比例
  trappedRatio: number; // 套牢盘比例
  avgCost: number; // 平均成本
  concentration90: number; // 90% 筹码集中度
  concentration70: number; // 70% 筹码集中度
  // ↓ 增强的分布数据（来自 cyq_chips）
  distribution: Array<{
    price: number;
    percentage: number;
    /** 该价位是否为获利区间 */
    isProfit: boolean;
  }>;
  concentration: number;
  keyLevels: Array<{ level: number; type: string }>;
};
```

#### 7.3.2 UI 增强

1. **AnalysisChipSummaryCard** 增强：

   - 新增：获利盘比例（环形进度条，绿色）/ 套牢盘比例（红色）
   - 新增：90% 筹码集中度 / 70% 筹码集中度
   - 新增：平均成本与当前价偏离度

2. **AnalysisChipDistributionChart** 增强：

   - 分布柱状图按"获利/套牢"分色（绿/红）
   - 当前价位标记线
   - 平均成本标记线
   - 密集峰值区域高亮

3. **估算标记移除**：
   - 当 `isEstimated === false` 时，移除 "数据为估算值" 的警告提示
   - 改为展示 "数据来源：Tushare 官方" 标签

### 9.1 背景

### 9.2 当前状态

- 股票详情页 K 线图仅支持 日/周/月 级别
- K 线组件位于 `src/sections/stock-detail/` 下

### 9.3 设计方案

#### 9.3.1 API

```typescript
// src/api/stock.ts 追加

export type MinuteKlineQuery = {
  ts_code: string;
  freq: '1min' | '5min' | '15min' | '30min' | '60min';
  trade_date?: string; // 默认最近交易日
};

export type MinuteKlineItem = {
  datetime: string;
  open: number;
  high: number;
  low: number;
  close: number;
  vol: number;
  amount: number;
};

export function fetchMinuteKline(query: MinuteKlineQuery) {
  return apiClient.post<MinuteKlineItem[]>('/api/stock/minute-kline', query);
}
```

- 新增日期选择器（仅在分钟级别时显示），可切换查看历史日的分钟线
- X 轴格式从 `YYYY-MM-DD` 切换为 `HH:mm`

#### 9.3.3 涉及文件

## 十二、聚合可视化 API 适配

### 12.1 背景

后端 §5.2.4 将新增聚合 API，减少前端多接口拼装。

### 12.2 预期新增的聚合 API

| API                | 用途                   | 前端受益                 |
| ------------------ | ---------------------- | ------------------------ |
| 行业对比雷达图     | 一次返回多维度对比数据 | 行业轮动页减少 API 调用  |
| 组合持仓变化时间轴 | 历史持仓演变           | 组合详情页新增持仓演变图 |
| 因子暴露变化趋势   | 时序因子暴露           | 因子分析页新增热力图     |

### 12.3 设计原则

- 新聚合 API 就绪后，逐步替换现有多接口并行调用
- 保持向后兼容：若聚合 API 不可用则回退到独立接口
- 减少 `Promise.all([api1(), api2(), api3()])` 模式，改为单次调用
