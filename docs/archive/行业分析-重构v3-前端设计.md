## 一、功能提炼

### 1.1 用户原始诉求复述

> “功能不变是硬性门禁，除非你发现确认是 BUG。”

> “行业分析的图表，比如散点图怎么解决数据集中的时候拥挤，不集中的部份太散乱的问题，以及部份图表的配色就很不好看。”

本轮只允许调整布局、视觉编码、信息密度、控件组织、图表显示尺度与状态呈现。现有字段、控件、API 入口、点击路径、权限和指标口径必须保留；越过门禁的行为仅限第 2.4 节逐项列明的已确认 BUG。

### 1.2 三角色审视

#### 1.2.1 资深金融产品经理（PM）

- 保留“全景热力图 / 行业轮动”双工作区，不把两类任务合成单页大盘。
- 保留共享交易日期、刷新、URL Tab、行业字典提示和跨 Tab 行业定位。
- 把全景设计稿与轮动设计稿拆开，确保每个现有控件都有明确视觉位置。
- 把散点拥挤治理分为“必须修复的全量线性范围”和“待确认的候选显示尺度”，不把候选伪装成已上线控件。

#### 1.2.2 资深量化/二级市场从业者

- 保持 X=板块涨跌幅、Y=板块资金净流入、气泡=成交额；任何显示变换不得写回原值。
- 保持 A 股涨红跌绿；方向色不用于 Tab、周期、选中态。
- 保持个股级 21 档涨跌分布，不得换成“30 个行业分布”冒充原指标。
- 修复 6M/1Y 被静默压成 60 日的问题；不得隐藏现有周期，也不得继续展示伪周期。
- 保持动量与估值的真实语义：动量为多周期评分，估值为日期截面的历史分位，它们不因全局周期而改指标定义。

#### 1.2.3 资深 UI/UE 设计师

- 视觉方向采用“Research Cartography + Dense Ledger”：主图区定位，排行区解释，详情区承接研究动作。
- 用边框、留白、对齐和固定标题区建立层级，减少重阴影和无业务含义的装饰色。
- 保留所有现有筛选；宽屏并排，中屏上下排，移动端分段控件允许横向滚动。
- 详情弹窗、详情抽屉和管理员快照作为设计稿中的明确状态变体，不再用一句“状态正常”代替。

### 2.1 共享外壳与真实状态

| 项目 | 当前行为 | 保留口径 |

### 2.4 API 端点映射

#### 2.4.1 共享与全景

| 端点 | 当前请求 | 消费位置 |
| --- | --- | --- |
| `POST /api/industry/dict-mapping` | `source=sw_l1`、`target=dc_industry`、`includeUnmatched=true` | 页头字典、跨 Tab 映射 |
| `POST /api/market/sector-flow` | `trade_date`、`content_type`、`limit=30` | 散点板块数据 |

### 2.5 已确认 BUG（唯一允许的功能行为修正）

| ID | 源码事实 | 修复口径 |
| --- | --- | --- |
| IA-B01 | 21 桶已包含每只股票，Donut 又加入涨跌停和平盘，导致总计重复 | 总数只取 `sum(ranges.count)`；涨跌停作为桶内 KPI，不再二次相加 |
| IA-B02 | 默认散点不加载 `items`，首次详情的个股、映射和轮动按钮为空 | 复用现有 `heatmap/data` 按需补全并缓存；不新增后端端点 |
| IA-B03 | 外部 `focusedSector` 持久存在，Drawer 关闭后立即回退重开 | 把外部焦点作为一次性事件消费，Drawer 开关只由子级本地状态控制 |
| IA-B04 | 六个组件共七处把 6M/1Y cap 为 60；部分后端 DTO 也限 60 | 端到端支持 120/250；保留五个周期，不允许隐藏或伪装 |
| IA-B05 | 动量柱把数组索引当颜色数值范围，负值可能使用默认红色 | 按真实动量值着色：负值绿色、非负红色 |
| IA-B06 | 散点轴按绝对值 P90 固定范围，完整数组中的极端点可能不可见 | 线性轴按全量范围加 8% padding；不裁点、不抖动 |
| IA-B07 | 前端向 ADMIN 展示触发按钮，后端仅允许 SUPER_ADMIN，ADMIN 必得 403 | 面板仍对 ADMIN/SUPER_ADMIN 可见；触发只对 SUPER_ADMIN 显示，ADMIN 保留查询 |

### 2.6 非 BUG 的设计债

| 问题 | 影响 | 本轮策略 |
| --- | --- | --- |
| 硬编码图表颜色 | 暗色主题和一致性失控 | 设计令牌化；实现用主题色 |
| 散点标签和中心簇拥挤 | 重叠、难点选 | 必修全量线性边界；候选均衡尺度另行确认 |
| 五组索引纵向过长 | 主图被压缩 | 改为五个索引 Tab；五组数据与点击能力全部保留 |
| 轮动内容过长但层级弱 | 扫读成本高 | 总览→四维→主图→专项图→详情，保持原顺序和控件 |
| 各卡状态样式不一致 | 页面跳动、错误不易定位 | 统一视觉样式，但不新增现有 API 不支持的状态 |
| 四维与热力图辅助请求静默失败 | 空态可能被误读为无数据 | 显示现有 error/empty 区分；不创造 Partial 状态字段 |

## 三、功能细化

### 3.1 模块结构树

```text
行业分析
├─ 共享页头：标题 / 字典说明 / 日期 / 刷新
├─ 一级 Tab：全景热力图 / 行业轮动
├─ 全景热力图
│  ├─ 散点 / TreeMap
│  ├─ 散点：行业 / 概念 / 地域
│  │  ├─ 四象限气泡图 + Apex 工具栏
│  │  ├─ 五组信息索引
│  │  └─ 行业详情弹窗
│  ├─ TreeMap：五种分组 + 两种面积 + 100/200/300
│  ├─ 行业涨跌统计：涨跌幅 / 涨跌家数
│  ├─ TreeMap 专属：个股 21 档涨跌分布
│  └─ ADMIN/SUPER_ADMIN：快照管理
└─ 行业轮动
   ├─ 1W / 1M / 3M / 6M / 1Y
   ├─ 四张总览
   ├─ 四维 Top10
   ├─ 轮动热力图：涨跌幅 / 净流入
   ├─ 动量排名 + 收益对比
   ├─ 资金净流入
   ├─ PE/PB 估值分位
   └─ 行业详情 Drawer：6 指标 + 4 Tab
```

### 3.2 共享页头

- **职责**：管理共享日期、刷新、Tab、行业字典与跨 Tab 提示。
- **数据**：日期继续输出 `YYYYMMDD`；字典继续使用会话缓存。
- **交互**：切 Tab 写入 `?tab=0|1`；刷新只递增 `refreshKey`，不伪造统一刷新进度。
- **状态**：显示真实字典覆盖、未匹配或失败提示；不显示无接口支撑的完整度、快照健康或 dataThrough。
- **边界**：保留默认行业轮动；日期空值继续代表后端最新交易日。

### 3.3 全景散点

- **职责**：比较最多 30 个行业/概念/地域板块的涨跌、资金与成交额。
- **数据**：并行请求 `sector-flow` 与 `main-flow-ranking`；字段单位保持源码定义。
- **交互**：保留行业/概念/地域；保留 hover Tooltip、气泡点击、五组索引点击和 Apex zoom/pan/reset。
- **索引**：净流入、净流出、涨幅、跌幅、中心拥挤五组改为 Tab，默认净流入；切换只改变列表呈现，不改变排序或数据。
- **标签**：减少默认文字标签数量属于显示调整；所有板块仍可 hover、缩放和从索引访问。
- **轴**：阶段二必修采用真实全量线性范围；候选均衡尺度仅保留为虚线注释。
- **状态**：沿用 Skeleton、卡内错误、暂无数据；任一并行请求失败不得显示“完整”。

### 3.4 TreeMap

- **职责**：按面积和涨跌色查看个股横截面。
- **控件**：保留按行业、沪深300、中证500、上证50、创业板；保留总市值/成交额；保留 100/200/300。
- **数据**：继续请求 `heatmap/data`；行业模式携带申万来源和映射字段。
- **交互**：保留个股 Tooltip；当前节点没有详情点击，设计稿不得增加“点击详情”。
- **摘要**：保留涨停、上涨、平盘、下跌、跌停五个 KPI。
- **状态**：Skeleton、错误文本、暂无数据。

### 3.5 行业涨跌统计与个股分布

- **行业统计**：两模式始终存在；保留“涨跌幅 / 涨跌家数”。当前不可点击详情。
- **个股分布**：仅 TreeMap 状态显示；输入必须是 `HeatmapItem[]`，不是 30 个板块。
- **图形**：允许把五段 Donut 重排为以零为中轴的 21 档柱状图；五个 KPI 和 21 档明细仍全部保留。
- **总数**：只使用 `sum(ranges.count)`；涨跌停、平盘不得二次相加。
- **明细**：允许默认折叠以缩短页面，但必须提供明确“展开 21 档明细”入口；展开内容字段保持区间、家数、占比。

### 3.6 全景详情与跨 Tab

- **摘要**：保留涨跌幅、净流入、成交额、涨/跌家数。
- **排名**：保留涨跌排名和资金排名两 Tab，各最多 30 行，字段与单位不变。
- **补全**：首次行业散点点击时复用现有 `heatmap/data` 按需补全个股和映射；请求期间只在弹窗内容区显示 Skeleton。
- **地域/概念**：没有可靠行业映射时保留摘要和可用排名，明确说明“暂无对应行业轮动”，不伪造跳转。
- **跨 Tab**：映射成功才显示“查看 N 日轮动”；进入轮动后外部焦点只消费一次。

### 3.7 管理员快照

- **可见性**：面板仅 ADMIN/SUPER_ADMIN 可见。
- **SUPER_ADMIN**：目标日期、触发聚合、确认弹窗、查询快照全部显示。
- **ADMIN**：保留目标日期和查询快照；隐藏无权限的触发按钮，避免必然 403。
- **结果**：保留触发成功/失败 Alert；保留交易日期、分组维度、数据来源、股票总数预览。
- **边界**：面板日期是快照操作日期，不与页头日期强绑定。

### 3.8 行业轮动主体

#### 3.8.1 周期与总览

- 保留 1W/1M/3M/6M/1Y，默认 1M。
- 保留涨跌比、全行业平均区间收益、领涨 Top3、领跌 Top3。
- 总览不新增点击详情；日期和周期口径继续显示在平均收益卡。

#### 3.8.2 四维 Top10

- 保留动量、收益、资金、估值低位四列及说明 Tooltip。
- 保留每列 Top10 和行点击 Drawer。
- 四接口并行失败时显示错误说明，不再静默伪装为空；不改变各接口参数。

#### 3.8.3 轮动热力图

- 保留“涨跌幅 / 净流入”颜色模式和节点点击。
- 主收益请求失败显示错误；辅助资金失败显示“净流入暂不可用”，涨跌模式仍可用。
- Tooltip 继续同时展示涨跌幅和区间净流入。

#### 3.8.4 动量、收益、资金、估值

- **动量**：保留 Top10/15/20/全部、横向柱、排名 Tooltip 和点击详情；动量 API 不因全局周期改评分口径。
- **收益**：保留行业多选、搜索、freeSolo、最多8、不选前15；保持分组柱状图；当前不新增柱点击详情。
- **资金**：保留 Top20、横向柱、亿元单位和点击详情。
- **估值**：保留 PE/PB、截止日期、低/中/高图例、滚动区域和点击详情；不把全局周期解释成估值窗口。

### 3.9 行业详情 Drawer

- **打开来源**：四维行、轮动热力图、动量柱、资金柱、估值柱、全景跨 Tab。
- **头部**：行业名称、当日涨跌幅、关闭按钮。
- **指标**：涨跌幅、最新点位、净流入、区间收益、PE 分位、PB 分位。
- **Tab**：收益走势、资金流向、成分股、板块行情。
- **成分股**：保留名称/代码、涨跌幅、PE_TTM、PB、总市值；行点击进入 `/stock/detail?code=...`。
- **周期**：切周期时 Drawer 保持打开并按天数重取详情。
- **日期边界**：当前详情接口不接 `trade_date`；本轮不得宣称 Drawer 与页头日期完全同步。若后续补日期参数，必须另立后端契约设计。

### 3.10 状态与响应式

| 状态 | 视觉 | 行为 |
| --- | --- | --- |
| Loading | 与卡片内容同高 Skeleton | 禁用对应图表点击 |
| Error | 卡内 Alert/错误文本 | 不影响其他独立卡片 |
| Empty | “暂无数据”或现有专业空态 | 不把失败当空数据 |
| Mapping missing | 字典差异提示 | 隐藏不可执行的轮动按钮 |
| Permission | ADMIN 不显示触发按钮 | 查询功能仍保留 |

响应式：≥1200px 保持主图/索引并排；900–1199px 索引下移；<900px 单列；分段控件在移动端横向滚动，不删除选项。详情 Dialog/Drawer 在移动端全宽。

## 四、UI/UE 设计

### 4.1 设计概念

**Research Cartography + Dense Ledger**

- Research Cartography：零轴、象限、方向色和面积共同构成可核对的市场地图。
- Dense Ledger：排行、指标、图例和详情按稳定列对齐，降低长页扫读成本。

### 4.2 项目 UI 规范

- 实现只使用 `theme.palette.*`、`theme.vars.palette.*Channel`、`varAlpha(...)`。
- 涨/流入使用 `error`，跌/流出使用 `success`；缺失使用 `grey`。
- Tab、周期、选中态使用 `primary/info/warning/secondary`，不借用涨跌色。
- 字号不小于 12px；金额、百分比和排名启用等宽数字。
- 间距使用 8/16/24；卡片用边框和留白建立层级，阴影使用主题预设。
- 动效仅用于 hover/focus 和数据更新淡入；图表点不做飞入动画。

### 4.3 全景桌面布局

```text
┌ 行业分析 / 字典提示 ────────────────────────── [交易日期] [刷新] ┐
│ [全景热力图] [行业轮动]                                       │
├────────────────────────────────────────────────────────────────┤
│ [散点图][树形图]  [行业][概念][地域]                           │
├─────────────────────────────────────────────┬──────────────────┤
│ 散点四象限主图 + Apex zoom/pan/reset        │ 五组信息索引 Tab │
├─────────────────────────────────────────────┴──────────────────┤
│ 行业涨跌统计 [涨跌幅][涨跌家数]                               │
├ TreeMap 状态变体 ───────────────────────────┬──────────────────┤
│ 五分组 / 两面积 / 100·200·300 / TreeMap     │ 个股 21 档分布   │
├─────────────────────────────────────────────┴──────────────────┤
│ ADMIN/SUPER_ADMIN 快照管理                                    │
└────────────────────────────────────────────────────────────────┘
```

设计稿使用长画布同时表达散点主状态、TreeMap 状态变体、详情弹窗和管理员快照，不把互斥控件同时放进正式工具栏。

### 4.4 轮动桌面布局

```text
┌ 行业分析 ───────────────────────────────────── [日期] [刷新] ┐
│ [全景热力图] [行业轮动]   [1W][1M][3M][6M][1Y]             │
├ 涨跌比 ┬ 平均收益 ┬ 领涨 Top3 ┬ 领跌 Top3 ─────────────────┤
├ 动量 Top10 ┬ 收益 Top10 ┬ 资金 Top10 ┬ 估值低位 Top10 ─────┤
├ 行业热力图 [涨跌幅][净流入] ────────────────────────────────┤
├ 动量排名 [Top数量] ─────────┬ 收益对比 [行业多选≤8] ────────┤
├ 资金净流入 Top20 ───────────┴────────────────────────────────┤
├ 估值分位 [PE][PB] / 截止日期 / 图例 ────────────────────────┤
└ 详情 Drawer：6 指标 + 4 Tab + 成分股跳转                     ┘
```

### 4.5 关键交互

- 五组信息索引 Tab 保留全部数据；行点击继续打开全景详情。
- 图表 reset 只恢复当前图表范围，不重置日期、板块类型或周期。
- 当前不可点击的 TreeMap、行业统计、收益对比和总览不绘制“点击详情”暗示。
- 详情弹窗和 Drawer 支持现有关闭方式；一次关闭保持关闭。
- 长行业名截断时用 Tooltip 展示全名；所有点击目标不小于 40×40px。
- 候选均衡尺度使用虚线框和“未上线候选”标记，不使用实心 ToggleButton 外观。

### 4.6 暗色/亮色适配

- 网格、零轴和分隔线使用 `divider` / `text.disabled`。
- 气泡与 TreeMap 边界使用 `background.paper`，保证重叠可区分。
- 颜色不得成为唯一编码；正负号、单位、标签、图例至少提供一种冗余表达。
- 亮暗主题正文对比度目标 ≥4.5:1，图形边界 ≥3:1。

## 五、实现步骤

### 5.1 实现顺序

1. 为当前控件、请求体、可点击入口、权限和 URL Tab 补行为回归测试。
2. 修复 IA-B01、IA-B05、IA-B06 等纯前端统计/显示 BUG。
3. 复用现有 `heatmap/data` 修复 IA-B02，不新增后端端点。
4. 修复一次性跨 Tab 焦点和 SUPER_ADMIN 触发权限显示。
5. 端到端修复 120/250 日周期；保持五个周期全部可用。
6. 重排全景组件，保留 TreeMap、统计、分布、详情和快照全部控件。
7. 重排轮动组件，保留每张图表的原图形类型、筛选和点击边界。
8. 统一主题色、卡片状态、响应式和键盘焦点。
9. ESLint fix → ESLint 零输出 → `yarn build`；阶段二末执行 `web-design-guidelines`。

### 5.2 关键技术点

- 保留散点原始 X/Y/Z；轴范围和候选显示变换只生成显示字段。
- 对空数组、单点、全零、同值、NaN、极端值建立纯函数测试。
- TreeMap 请求缓存键至少包含日期、分组和指数；详情补全不得复用错误分组数据。
- 保持当前 API 全部使用 `apiClient.post()`，参数只放 Body，`trade_date` 保持 `YYYYMMDD`。
- 不增加 `dataThrough`、完整度、快照健康等无现有接口支撑的前端字段。
- 轮动详情在本轮保持当前日期契约，不暗改后端接口。

### 5.3 风险与回退

| 风险 | 预防 | 回退 |
| --- | --- | --- |
| 候选均衡尺度被误当现有功能 | 文档和稿件均标“未上线候选” | 阶段二完全不实现 |
| 120/250 日性能不足 | 索引、EXPLAIN、P95 测试 | 优化查询；不隐藏周期、不回退伪60日 |
| 首次详情补全请求偏大 | 仅点击时请求并按日期/类型缓存 | 保留摘要并显示补全失败，不伪空表 |
| 长页首屏过重 | 继续按当前 Tab 条件挂载和现有请求时机 | 不引入新全页预取 |
| 主题色对比不足 | 亮暗截图与对比检查 | 调整 token 深度 |
