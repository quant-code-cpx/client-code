## 2. 修复清单

### FIX-022 · 因子库 / 因子管理 P0：FactorStatus 枚举错配

- **现象**：进入 `/factor/library` 直接白屏；控制台 `Cannot read properties of undefined (reading 'color')`。
- **根因**：BE 返回 `factor.status` 包含 `HEALTHY` / `MISSING`，FE 枚举只有 `FRESH` / `STALE` / `FAILED` / `NEVER` / `DISABLED`，导致 `STATUS_META[status]` 为 `undefined`。
- **修复**：
  - `src/api/factor.ts` `FactorStatus` 扩为 7 元组（加 `HEALTHY` / `MISSING`）。
  - `src/sections/factor/constants.ts` `STATUS_META` 同步扩展，新增 `UNKNOWN_STATUS_META` 与 `getStatusMeta(status)` 工厂函数。
  - `factor-library-card.tsx` / `factor-library-table.tsx` 改用 `getStatusMeta(status)` 代替直接索引。
- **验证**：刷新 `/factor/library`，33 个因子正常显示。

### FIX-023 · 状态总览 P0：BE 返回 `byFactor` 而非 `items`

- **现象**：`/factor/admin?tab=status` 进入后 `items.reduce` 崩溃。
- **根因**：BE `/api/factor/admin/precompute/status` 返回 `{generatedAt, latestDate, totalDatesWithData, byFactor:[...]}`，与 FE `{items:[...]}` 契约不一致。
- **修复**：在 `src/api/factor.ts` 把 `adminPrecomputeStatus` 改为 async 适配函数：
  - 若 raw 已含 `items`，直通；
  - 否则把 `byFactor` 映射为 `PrecomputeStatusItem[]`，并基于 `latestDate` 计算 `staleDays` 与 `status`（UP_TO_DATE / STALE / NEVER）。
  - 在 `factor-admin-kpi-row.tsx` 的 `deriveKpi`、`factor-admin-view.tsx` 的 `setStatusItems` 增加 `Array.isArray(...)` 防御。
- **验证**：KPI 显示 33 / 33 / 0 / 0；状态总览表格正常。

### FIX-024 · 任务历史 P0：`job.progress` 未防御性兜底

- **现象**：`/factor/admin?tab=jobs` 渲染时 `job.progress.done` 崩溃。
- **修复**：`factor-admin-jobs-table.tsx` 在迭代时统一加 `const progress = job.progress ?? { done: 0, total: 0 };`，3 处 `.done` / `.total` 引用改用 `progress.done` / `progress.total`。

### FIX-025 · 任务历史 P0：BE-1 端点契约错配

- **现象**：FIX-024 修复后立即在 `job.jobId.slice` 处崩溃。
- **根因**：BE-1 当前返回的是覆盖度统计（`{tradeDate, factorCount, totalStocks, ..., status:'OLD'}`），完全没有 `jobId` / `operator` / `createdAt` / `type` 等 FE 必需字段。
- **修复**：把 `adminJobList` 改写为 async 适配层，过滤掉缺 `jobId` 的脏数据，并兜底 `progress`：

  ```ts
  export async function adminJobList(dto): Promise<AdminJobListResponse> {
    const raw = await apiClient.post<unknown>('/api/factor/admin/jobs', dto);
    const obj = (raw ?? {}) as Record<string, unknown>;
    const rawItems = Array.isArray(obj.items) ? obj.items : [];
    const items = rawItems
      .filter((row) => typeof row.jobId === 'string' && row.jobId.length > 0)
      .map((row) => ({ ...row, progress: row.progress ?? { done: 0, total: 0 } }));
    return { items, total: obj.total ?? items.length, page: dto.page, pageSize: dto.pageSize };
  }
  ```

- **验证**：`/factor/admin?tab=jobs` 显示「暂无任务记录」空态，无崩溃。
- **后续**：BE-1 按 `docs/archive/因子管理-重构-前端设计.md` 重新对齐字段后，可移除该过滤逻辑。
