## 三、已修复的前端 Bug

### CONCEPT-BUG-01：概念板块 Chip 全部为空

- **症状**：公司概况子Tab → 概念板块区域显示12个无标签的 chip
- **根因**：`StockConceptItem` 类型定义字段名与后端实际返回不匹配
  - 前端期望：`{ conceptCode, conceptName }`
  - 后端实际：`{ tsCode, name }`
- **修复文件**：
  - `src/api/stock.ts` — 更新 `StockConceptItem` 类型定义
  - `src/sections/stock-detail/stock-detail-company-tab.tsx` — 更新 `key`/`label` 字段引用
- **验证**：12个概念板块chip均正常显示名称 ✅

### APEX-BUG-01：融资融券 Tab ApexCharts pageError

- **症状**：切换到"融资融券"子Tab时抛出 `tooltip.shared cannot be enabled when tooltip.intersect is true`
- **根因**：`RzyeTrendChart` 和 `RzjmreChart` 设置 `tooltip: { shared: true }` 但未设置 `intersect: false`；ApexCharts bar 图默认 `intersect: true`，两者冲突
- **修复文件**：`src/sections/stock-detail/analysis/analysis-margin-chart.tsx`
  - `RzyeTrendChart` options: `tooltip: { shared: true }` → `tooltip: { shared: true, intersect: false }`
  - `RzjmreChart` options: `tooltip: { shared: true }` → `tooltip: { shared: true, intersect: false }`
- **验证**：ESLint ✅，build ✅

### DIV-BUG-01：分红配股接口 404

- **接口**：`POST /api/stock/detail/dividend-financing`
- **响应**：404 — `Cannot POST /api/stock/detail/dividend-financing`
- **影响范围**：分红融资子Tab完全无法加载，显示原始技术错误消息（用户体验差）

- **建议**：后端实现该端点；前端当前以降级方式处理，错误消息可改为友好提示

### FS-DUP-BUG-01：财务报表接口返回重复记录

- **接口**：`POST /api/stock/detail/financial-statements`
- **影响**：
  - **利润表**（income）：`2026-03-31` 出现×2，`2025-06-30` 出现×2（两条完全相同的记录）
  - **现金流量表**（cashflow）：所有4个报告期均重复（8条数据实为4个期各2条）
  - **资产负债表**（balance）：无重复 ✅
- **前端表现**：利润表和现金流量表显示重复列
- **建议**：后端排查数据库查询是否存在多表 JOIN 导致的重复行，或在业务层去重
