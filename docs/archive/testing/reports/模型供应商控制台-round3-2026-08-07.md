# 模型供应商控制台测试报告 — Round 3（2026-08-07）

## 修复目标

解决“深度探测通过，Agent 正式运行仍报模型供应商不可用”的假阳性，并确保新失败运行能向用户展示可操作、可定位且不泄露上游原文的错误。

## 根因与修复

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 探测与正式调用不等价 | 旧探测只发送 `Reply with OK`，不带默认推理、结构化输出和工具参数 | 按部署当前默认推理策略、最大输出上限、结构化输出与工具声明执行一至两次最小调用 |
| 5xx 诊断过度归一 | 所有上游 5xx 都被折叠为“暂不可用” | 保留 HTTP 状态、经白名单校验的上游请求 ID；已识别的推理/结构化/工具/视觉兼容错误返回具体调整建议 |
| 历史失败刷新后退化 | 消息列表未返回 Run 的 `errorCode/errorMessage` | 后端 DTO/查询、OpenAPI 生成类型和前端失败卡片已全链路透传 |

能力仍由管理员声明，不根据官方端点或中转站做静态阻断。视觉输入在统一消息协议尚无图片探测载荷时明确标记“未执行”，不伪造支持或不支持结论。
