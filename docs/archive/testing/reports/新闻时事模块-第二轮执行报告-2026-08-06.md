# 新闻时事模块第二轮执行报告

> 日期：2026-08-06，Asia/Shanghai  
> 契约：News API v1.2（本轮无字段变更）  
> 方法：业务场景优先、Outside-in TDD、RED → GREEN → Refactor  
> 结论：✅ Round 2 前端增强完成；真实新闻成功态仍受后端生产门禁约束

## 1. 本轮交付

- 刷新改为保留旧列表；失败显示非阻断告警，不再通过 remount 清空内容。
- 可见且在线时每 60 秒执行轻量探新；隐藏或离线时暂停，只提示“有新内容”，不擅自替换当前列表。
- 详情加入容量 20 的 LRU 缓存、revision 失效和显式重试；`7001` 不提供无意义重试。
- 列表接入 `react-virtuoso`，保留后端顺序并增加视觉日期分隔；1,000 条合成数据维持小 DOM。
- 390px 下筛选区收起为底部 Drawer；指定证券改为本地股票 API 搜索、多选、去重及 20 个上限。
- 产物全部位于前端仓库，未修改 News API v1.2 契约。

## 4. 真实浏览器验收

- 使用已有登录会话访问 `/market/news`，桌面端标题、筛选、错误态和 coverage 独立呈现。
- 切换到 390×844 后只显示“筛选新闻”紧凑入口；Drawer 具备 `dialog` 语义并可正常关闭。
- 在 Drawer 选择“指定证券”，真实调用本地股票搜索得到“浦发银行 · 600000.SH”，选择并提交后 URL 为 `?scope=SECURITIES&codes=600000.SH`。
- Drawer 提交后关闭，摘要更新为“1 项条件”；页面无横向溢出，浏览器 console 无 error/warn。
- 本地后端仍保持 `NEWS_ENABLED=false`，因此页面稳定显示模块未启用状态；本轮没有伪造真实新闻成功态或虚拟滚动的浏览器通过结论。
- 验收结束后恢复原页面、默认 viewport，并关闭临时测试标签。
