- News 开关：当前 Docker app/worker 配置与运行环境为 `NEWS_ENABLED=true`。未认证访问 highlights 返回 `401`，只证明路由存在，不计作新闻成功态。
- 数据：News 数据库实查 6,906 篇文章、4,869 条证券关联、4 条 feed health；最新文章时间为 `2026-08-09 17:35:57+08`。
- 浏览器：应用内浏览器用于功能回归（其 CSS 视口固定为 `1280×720`）；Chrome 用于严格桌面视觉验收，已确认实际 CSS 视口 `1440×900`。两者在已执行页面均为 0 error / 0 warn。
- 账号与权限：测试 fixture 的 fallback 账号在当前数据库不存在；数据库仅有 ACTIVE 的 SUPER_ADMIN 账号。用户已授权识别本地验证码并使用 Docker 配置的 SUPER_ADMIN 凭据登录 `localhost:3039`；未读取浏览器 cookie/storage，未绕过验证码，未执行批量回补、删除或其他数据写操作。

## 业务与契约基线

- 业务请求统一使用 POST；`trade_date` 按 `YYYYMMDD` 传输，后端 `null` 不替换为 `0`。
- 事件日历：日期、范围、事件类型、影响力与关键词共同决定查询；月历、时间线、表格视图共享同一查询结果，纯视图切换不应重新请求。
- 因子管理：覆盖 KPI、状态、任务、回补、调度和审计边界；只读验收不得触发批量写操作。
- 股票选股器：修改条件只形成 dirty 状态，不应在点击“开始选股”前请求；执行请求应包含修改后的条件。
- 行业分析：1W/1M/3M/6M/1Y 分别映射 5/20/60/120/250；全景与轮动共享统一行业语义。
- 首页新闻：首页只替换既定新闻区；新闻点击后应深链到 `/market/news?article=...`，并以真实 list/detail/coverage 请求打开详情。
- 全局：默认 PC 视口无页面级横向溢出；亮暗主题均可用；键盘焦点可见；Console 无新增 error/warn；Network 无失败或重复关键请求。
