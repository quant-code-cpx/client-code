# 行业分析页面联调测试报告（2026-05-17）

## 测试范围

- 页面：`/market/industry?tab=1`
- 业务模块：行业轮动概览、四象限 Top 10、行业热力图、动量排名、收益对比、资金流向、估值分位、行业详情抽屉、成分股、周期切换。
- 联调对象：前端 `src/api/market.ts` 与后端 `/api/industry-rotation/*` 系列接口。

## 业务理解

- 行业轮动页展示同一行业在不同周期下的收益、资金、估值、动量与成分股情况。
- 行业名称可能来自不同口径：东财板块、申万行业、同花顺板块、个股基础资料行业字段。
- 成分股不能只按 `stock_basic_profiles.industry = 行业名` 精确匹配，否则细分行业和主题板块会出现空数据。
- 估值分位应展示最新可用估值数据日期，而不是强依赖最新交易日。

## 发现并修复的问题

| 问题                           | 根因                                      | 修复                                         |
| ------------------------------ | ----------------------------------------- | -------------------------------------------- |
| 日期选择器和刷新按钮大小不一致 | 控件高度未统一                            | 统一为 40px                                  |
| 估值低位无数据                 | 后端按最新交易日查估值，但估值表存在滞后  | 后端改为取最新可用估值日期                   |
| 资金净流入排序方向错误         | 图表侧未按业务期望降序                    | 改为净流入降序                               |
| 动量排名排序方向错误           | 图表侧未按业务期望降序                    | 改为动量降序                                 |
| 详情抽屉出现“未提供接口”       | 前端暴露内部占位实现                      | 删除占位文案，复用详情接口数据               |
| 成分股为空                     | 只按个股基础资料行业精确匹配，口径过窄    | 后端按申万成员、同花顺板块、个股行业三级回退 |
| 成分股真空时只有表头           | 缺少空态                                  | 增加明确空态行                               |
| 详情指标长期 `--`              | 成交额/动量值无真实接口字段               | 替换为最新点位、区间收益等有来源指标         |
| 估值 tooltip 语义误导          | 后端字段实际是 3 年分位                   | 文案与字段统一为 3 年分位                    |
| 快速切换出现 429               | 多组件并发发起相同 return-comparison POST | 前端 API 层增加 in-flight 请求去重           |

## 回归结果

- 前端接口单测：`src/api/__tests__/market.test.ts`，15 个用例通过。
- 后端行业轮动单测：`src/apps/industry-rotation/test/industry-rotation.service.spec.ts`，19 个用例通过。
- 浏览器 smoke：周期 `1W / 1M / 3M / 6M / 1Y` 全部核心模块可见，未发现非 WebSocket console error，未再出现 429。
- 前端 lint/build：通过。
- 后端 build：通过。

## 后续建议

- 将行业详情抽屉的成分股源头标识（申万/同花顺/个股行业）作为调试字段或 tooltip 暴露给内部用户，便于排查行业口径问题。
- 针对 `/market/industry` 增加 E2E 覆盖：首屏加载、周期切换、详情抽屉、成分股非空与空态。
- 对高频切换类页面建立统一的请求去重/取消/节流规范，降低后端限流压力。
