## Bug 列表

### BUG-ANO-001（已修复）

- **标题**：近期同股异动轨迹中的检测值显示原始浮点数而非格式化值
- **严重度**：中
- **复现步骤**：
  1. 打开任意异动详情抽屉
  2. 查看"近期同股异动轨迹"区域
  3. 历史行的"检测值"列显示 `11.53950145558257` 而非 `--`
- **根因**：`anomaly-type-config.ts` 的 `formatAnomalyValue()` 函数 `default` 分支返回 `String(value)`，当后端 history 条目的 `anomalyType` 为 `null` 时触发
- **修复文件**：`src/sections/alert/anomalies/anomaly-type-config.ts`
- **修复内容**：将 `default: return String(value)` 改为 `default: return PLACEHOLDER`（即 `'--'`）
- **关联后端问题**：BE-ISSUE-ANO-01

### BUG-ANO-002（已修复）

- **标题**：切换筛选 Chip 时产生 React `setState during render` 警告
- **严重度**：中（功能可用，但违反 React 规范，在 Concurrent Mode 下可能引发渲染不稳定）
- **复现步骤**：
  1. 打开异动监控页面
  2. 点击任意异动类型 Chip（如"大额净流入"）
  3. 控制台出现：`Cannot update a component (RouterProvider) while rendering a different component (AlertAnomaliesView)`
- **根因**：`use-anomaly-monitor-state.ts` 中 `setFilter` / `resetFilter` 的 `setFilterState` updater 函数内部直接调用 `writeQuery()`（即 `setSearchParams`），导致在 React 的 state 更新阶段再次触发路由 state 更新
- **修复文件**：`src/sections/alert/anomalies/use-anomaly-monitor-state.ts`
- **修复内容**：
  1. 将 `writeQuery` useCallback 声明移至所有 useEffect 之前
  2. 移除 `setFilter` 和 `resetFilter` 的 updater 内部对 `writeQuery` 的调用
  3. 新增专用 `useEffect(() => { writeQuery(filter); }, [filter, writeQuery])` 在 render 外部同步 state → URL
