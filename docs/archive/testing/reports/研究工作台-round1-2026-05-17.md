## 2. 本轮修复

### FIX-017（WL-001 · P0 · code-bug）自选股表格因 `quote.close` 为 null 崩溃

- **文件**：`src/api/watchlist.ts` + 6 个相关组件文件
- **现象**：进入自选股页直接白屏，控制台报 `Cannot read properties of null (reading 'toFixed')`。后端 `quote` 对象 `_count`、`close` 可能缺失。
- **修复**：所有访问 `_count.stocks`、`quote.close` 改为可选链 + 默认值；增加类型守卫。
- **验证**：eslint 通过；进入页面正常渲染分组与股票列表。

### FIX-018（WL-009 · P0 · code-bug）NumericCell 类型签名过窄

- **文件**：`src/sections/watchlist/watchlist-stock-table-row.tsx`
- **现象**：后端有时返回 `close` / `change_pct` 等字段为 `string`（例如 `"12.50"`），`NumericCell({ value: number })` 直接 `value.toFixed()` 崩溃。
- **修复**：`NumericCell` 签名扩为 `number | string | null | undefined`，内部 `typeof value === 'string' ? Number(value) : value` 归一。
- **验证**：eslint 通过；列表显示价格、涨跌幅、目标价均正常。

### FIX-019（ES-002 · P1 · code-bug）事件查询表格字段名错配

- **文件**：`src/sections/event-study/constants.ts`、`src/sections/event-study/event-query-tab.tsx`
- **现象**：8 类事件（业绩预告、分红、股东、解禁、IPO 等）的查询结果表格全部空白，控制台无报错。
- **根因**：列定义 `field` 沿用 snake_case（`ts_code / ann_date / end_date / ex_date / stk_div / cash_div / holder_name / change_vol / change_ratio / float_date / float_share / float_ratio / exp_date / audit_result / audit_agency / report_type / p_change_min / p_change_max`），但后端实际返回 camelCase。
- **修复**：
  1. `constants.ts` 中 8 个事件类型的列定义全部改为 camelCase；
  2. `event-query-tab.tsx` 引入 `fDate`，新增模块级 `DATE_FIELDS Set` 与 `formatEventCell()` 帮助函数，对所有日期类字段统一渲染为 `YYYY-MM-DD`。
- **验证**：eslint 通过；查询业绩预告 / 分红 / 解禁 / IPO 等事件，表格字段渲染正确，日期格式统一。
