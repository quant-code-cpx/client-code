## 发现并修复的问题

### BUG-SD-688525-01 · 股本结构 Tab 崩溃

- 表现：进入“公司与股本 → 股本结构”后触发 `Cannot read properties of undefined (reading 'length')`，页面进入路由 ErrorBoundary。
- 根因：后端 `/api/stock/detail/share-capital` 返回 `{ tsCode, latest, history }`，不返回 `changes`；前端无条件读取 `data.changes.length`。
- 修复：`stock-detail-share-capital-tab.tsx` 将 `changes/history` 做数组兜底，并兼容历史行的 `changeDate` 字段；`src/api/stock.ts` 类型改为匹配真实后端形状。
- 回归：`StockDetailShareCapitalTab` 单测 + 浏览器定向回归均通过。

### BUG-SD-688525-02 · 股票选择框 code-only value 尾随空格

- 表现：生成研报弹窗默认股票输入值为 `688525.SH `。
- 根因：`StockSearchAutocomplete` 的 `getOptionLabel` 直接拼接 `${tsCode} ${name}`，当 name 为空时留下尾随空格。
- 修复：改为过滤空字段后 join。
- 回归：新增受控 value 单测，弹窗默认股票值回归为 `688525.SH`。

## 未修复风险

- `OBS-SD-A`：设计文档要求 stock-detail 端点请求体统一 `tsCode`，但当前后端 `StockDetailDto` 和前端单测明确要求 overview/today-flow 使用 `{ code }`。本轮不改前端，避免破坏现有后端契约；已记录到 `docs/testing/已知问题待办.md`。
