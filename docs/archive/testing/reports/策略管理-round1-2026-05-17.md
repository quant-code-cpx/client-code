## 2. 修复清单

### FIX-026 · 策略详情 P3：业绩快照展示 BE 404 原始报文

- **现象**：进入 `/strategy/:id`，「业绩快照」区直接显示 `Cannot POST /api/strategies/performance`。
- **根因**：BE `/api/strategies/performance` 端点尚未实现，`apiClient.post` 抛出的错误 message 直接被 FE 渲染。
- **修复**：`src/sections/strategy/components/strategy-performance-card.tsx` catch 块新增对 `Cannot POST|GET` / `404` 的识别，统一替换为友好文案「业绩数据暂不可用」。
- **验证**：刷新 `/strategy/cmp9yluni000ypk4fvqa0oozn`，业绩快照区显示「业绩数据暂不可用」。

### FIX-027 · 历史对比 P3：BE 404 原始报文兜底

- **现象**：进入 `/strategy/signal/history/compare?strategyIds=...` 时 Alert 内显示 `Cannot POST /api/signal/history/compare`。
- **根因**：BE `/api/signal/history/compare` 端点尚未实现，FE 直接展示原始 error.message。
- **修复**：`src/sections/signal/view/signal-history-compare-view.tsx` 的 `fetchCompare` catch 块按同样模式识别 404，替换为「多策略对比接口暂不可用」。
- **验证**：刷新对比页（带激活策略参数），Alert 显示「多策略对比接口暂不可用」。
