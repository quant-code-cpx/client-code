# 智能体富响应块测试方案

## 测试目标

验证 Batch 017 只渲染公共白名单内容块，恶意、未知、过新和超限输入不能执行代码或破坏整条消息；同时验证金融单位、比例、null、复权、来源、Tool 摘要和引用对用户可核验。

## 自动化分层

- Markdown：XSS、协议、GFM、流式和研究笔记复用。
- Guard/formatter：canonical union、超限、null/0、比例和 CSV 注入。
- 组件：Tool 卡、引用、图表替代、K 线排序/去重、股票详情 adapter。
- MSW：富消息和 `payloadIncluded=false` Tool 摘要 fixture。
- Playwright：移动端完整富回答、局部降级、Tool 按需加载、无横向溢出和应用 console 检查。

