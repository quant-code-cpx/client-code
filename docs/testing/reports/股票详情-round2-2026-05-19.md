## 已修复 Bug

### BUG-SD-001 · K 线均线图例标签未随周期切换更新

| 字段         | 内容                                                                                                                                                |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **模块**     | 股票详情 → 行情 Tab → K 线图 → 图例标签                                                                                                             |
| **严重等级** | P2                                                                                                                                                  |
| **根因**     | `code-bug`                                                                                                                                          |
| **发现**     | 2026-05-19 Round 2                                                                                                                                  |
| **现象**     | 切换到"周"或"月"周期后，均线图例仍显示"5日均线""10日均线"，而非"5周均线"                                                                            |
| **根因分析** | `stock-detail-market-tab.tsx` 中 series name 和 tooltip maNames 硬编码为 `'5日均线'` 等字符串，未引用 `period` 状态                                 |
| **修复方案** | 在 `categories` 后添加 `const maUnit = period === 'W' ? '周' : period === 'M' ? '月' : '日'`，将所有均线 name 改为模板字符串 `` `5${maUnit}均线` `` |
| **修复文件** | `src/sections/stock-detail/stock-detail-market-tab.tsx`                                                                                             |
| **状态**     | ✅ Fixed — ESLint clean, yarn build pass                                                                                                            |
