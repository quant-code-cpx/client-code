## Bug 记录

### BUG-FM-01 · 状态筛选完全失效（P1，已修复）

- **发现**: FL-008 回归确认（2026-05-23），OBS-FM-A 原记录升级
- **现象**: 选任一状态 Chip（数据新鲜/尚未预计算等）→ 返回 0 结果
- **根因**: `factor-library-view.tsx` `visibleFactors` 过滤段用 `filters.statuses.includes(f.status)` 精确匹配，BE 实际返回 `status:"MISSING"`（别名 NEVER）和 `status:"HEALTHY"`（别名 FRESH），精确匹配失败
- **修复**: `src/sections/factor/view/factor-library-view.tsx`：在状态过滤逻辑中加入别名展开

  ```diff
  - arr = arr.filter((f) => f.status !== undefined && filters.statuses.includes(f.status));
  + const expandedStatuses = new Set<string>(filters.statuses);
  + if (filters.statuses.includes('FRESH')) expandedStatuses.add('HEALTHY');
  + if (filters.statuses.includes('NEVER')) expandedStatuses.add('MISSING');
  + arr = arr.filter((f) => f.status !== undefined && expandedStatuses.has(f.status));
  ```

- **回归验证**: 选"尚未预计算"→ 33 个因子正确展示 ✅
