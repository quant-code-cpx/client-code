## 2. 代码修复清单

### BUG-CAL-01（已修复 ✅）

- **问题**：事件详情抽屉的 `detail` 字段，当后端返回对象（如 `{"floatRatio":1.7331,"floatShare":1710000}`）时，直接 `JSON.stringify` 后以原始字符串展示，影响可读性
- **文件**：`src/sections/alert/calendar/event-detail-drawer.tsx`
- **修复**：检测 `typeof event.detail === 'string'`，若为对象则遍历 `Object.entries` 渲染 `<Fragment key={k}>` 键值网格（`gridTemplateColumns: 'auto 1fr'`）
- **验证**：ESLint exit 0 + `yarn build ✓ built in 7.50s` + 浏览器抽屉正常显示键值对

### BUG-CAL-02（已修复 ✅）

- **问题**：表格视图存在 React key 重复警告，当同一股票同一天有多条相同类型的事件时（如「301428.SZ-20260520-FLOAT」），`rowKey` fallback 生成重复 key
- **文件**：`src/sections/alert/calendar/calendar-table-view.tsx`（第 49 行）
- **修复**：在 `rowKey` fallback 中追加 `title` 字段：`${e.tsCode}-${e.date}-${e.type}-${e.title}`
- **验证**：ESLint exit 0 + `yarn build ✓` + 浏览器控制台无重复 key 警告

## 3. 后端数据问题（前端无法修复）

| ID          | 影响项                       | 现象                                                                                                              | 根因                                                  |
| ----------- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| BE-ISSUE-01 | 统计卡「Top 影响力」始终为 0 | 后端不返回 `impactLevel` / `impactScore` 字段，`getEventImpactLevel()` 所有事件均 fallback 为 `LOW`，HIGH 计数=0  | 后端未填充事件影响力分级字段                          |
| BE-ISSUE-02 | 统计卡「自选相关」始终为 0   | 后端不返回 `isInWatchlist` 字段，`events.filter(e => e.isInWatchlist)` 始终为空                                   | 后端未标记事件与自选股的关联关系                      |
| BE-ISSUE-03 | 关键词搜索服务端无效         | 前端已正确在 POST body 中携带 `"keyword":"..."` 参数，后端返回全量数据（12,134 条），说明后端未实现关键词过滤逻辑 | 后端 `/api/alert/calendar/list` 未处理 `keyword` 字段 |
| BE-ISSUE-04 | 历史同类事件始终空           | 抽屉内「历史同类事件参考」显示「暂无历史数据」                                                                    | 后端 mock/真实数据库无历史事件数据                    |

> **前端关键词搜索实现验证（CAL-017 调查结论）**：
> 通过 Playwright 截获网络请求，确认输入关键词后前端立即发起新 POST 请求且 body 包含 `"keyword":"..."` 字段，符合设计规范；搜索结果不变是因为后端未过滤，非前端 Bug。
