## Bug 报告

### BUG-WL-01 · 目标距离公式分母错误

| 字段         | 内容                                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------------- |
| **严重等级** | P1                                                                                                   |
| **根因分类** | `code-bug`                                                                                           |
| **发现时机** | WL-012（添加股票设置目标价后验算）                                                                   |
| **现象**     | 000001.SZ 现价 10.77，目标 12.51，系统显示 +13.84%（错误）                                           |
| **期望**     | +16.16%（正确：(12.51-10.77)/10.77×100）                                                             |
| **根因**     | `utils.ts` `computeTargetDistance`：`const pct = ((target - close) / target) * 100`，分母用了 target |
| **修复文件** | `src/sections/watchlist/utils.ts`                                                                    |
| **修复内容** | `/ target` → `/ close`                                                                               |
| **状态**     | ✅ FIXED & 验证通过                                                                                  |

### BUG-WL-02 · 编辑股票后报价数据丢失

| 字段         | 内容                                                                                                      |
| ------------ | --------------------------------------------------------------------------------------------------------- |
| **严重等级** | P1                                                                                                        |

| **状态**     | ✅ FIXED & 验证通过                                                                                       |

### BUG-WL-03 · 增删股票后卡片计数不同步

| 字段         | 内容                                                                                                                                                                            |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **严重等级** | P2                                                                                                                                                                              |
| **根因分类** | `code-bug`                                                                                                                                                                      |
| **发现时机** | WL-015（批量删除 2/3 支后计数显示 0）                                                                                                                                           |
| **现象**     | 批量删除后卡片显示 "0 支股票"（应为 1）；重新添加股票后仍显示 0（summary 已更新但 `_count.stocks = 0` 优先）                                                                    |
| **期望**     | 增删后卡片计数即时正确反映                                                                                                                                                      |
| **根因**     | `handleRemoveStock`/`handleBatchRemoveStocks` 只更新 `_count.stocks`，未同步 `summary.stockCount`；`handleAddStockSuccess` 刷新 `summary` 但不更新 `_count.stocks`，导致 0 优先 |
| **修复文件** | `src/sections/watchlist/view/watchlist-view.tsx`                                                                                                                                |
| **修复内容** | 1. remove 系两个 handler 同时更新 `_count.stocks` 和 `summary.stockCount`；2. `handleAddStockSuccess` 刷新 summary 时同步写入 `_count: { stocks: summary.stockCount }`          |
| **状态**     | ✅ FIXED & 验证通过（111 组卡片正确显示 "2 支股票"）                                                                                                                            |
