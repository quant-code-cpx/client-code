## 重要环境说明

> **必须使用 `yarn demo` 而非 `yarn dev` 启动服务器**。
>
> `yarn demo` = `VITE_DEMO_MODE=true vite`，会在 `main.tsx` 中启动 MSW (Mock Service Worker)，拦截所有 API 请求返回 mock 数据。
>
> `yarn dev` 不启动 MSW，所有请求走真实后端（localhost:3000）。真实后端当前因历史数据不足，相关性矩阵全部返回 `null`，页面只能显示"样本不足"，功能测试无法进行。
>
> 此为 **环境配置问题（BUG-FC-01，已关闭），不是代码 bug**。

### BUG-FC-01 · 热力图全部"—"（已关闭，P0→环境问题）

| 字段         | 内容 |
|-------------|------|
| **发现轮次** | 上轮 session（2026-05-23 前半段）|

| **状态**     | ✅ 已关闭（环境问题，非代码 bug）|

## 观测项（非 code bug）

### OBS-FC-A · Pearson 重新计算后摘要仍显示"Spearman"

| 字段     | 内容 |
|---------|------|
| **等级** | P3 |
| **现象** | 切换方法到 Pearson 并重新计算，摘要卡片仍显示"方法 **Spearman**" |
| **根因** | Mock 数据 `factor.json` 中 `method: "spearman"` 固定写死，不随请求变化。摘要卡片显示 `result.method`（来自 API 响应）而非 UI 状态 |
| **影响** | Demo 模式下无实际影响；真实后端应返回请求中指定的 method |
| **状态** | 🟢 Mock 限制，无需修复（真实后端会正确返回 `method: "pearson"`）|

## 功能验证亮点

1. **NULL_SENTINEL 兜底**：`NULL_SENTINEL = -2` 机制正确处理 null 相关系数，热力图显示"样本不足"色（灰色），不崩溃
2. **Dirty 检测准确**：因子增减、方法切换、股票池切换均正确触发 `paramsDirty`，threshold 变更不触发（设计正确）
3. **抽屉内容丰富**：方法/计算口径/最小样本/并列秩处理/显著性说明/建议动作/正交化+高级分析按钮全部正确
4. **正交化跳转完整**：URL 参数 `mode=orthogonalize`、`factors=pb,pe_ttm`、`tab=orthogonalize` 三者均正确，因子高级分析页预填因子正确
5. **少于2因子防护**：`tooFew` 逻辑正确 disabled 计算按钮，"请至少再选 1 个因子"提示及时
