### 1.2 Bug 修复

**BUG-PF-001 ✅（已修复）**

- **文件**：`src/sections/portfolio/portfolio-card.tsx`
- **现象**：列表页组合卡片菜单"编辑"/"删除" MenuItem 点击后，React Portal 事件冒泡穿透到父 Card 的 onClick，触发导航到详情页，而非打开对应 Dialog
- **根因**：MUI Menu 渲染在 Portal 中，MenuItem click 事件通过 React fiber tree 冒泡到 Card 的 onClick
- **修复**：在两个 MenuItem 的 onClick handler 中增加 `e.stopPropagation()`
- **验证**：点击菜单项后正确打开编辑/删除 dialog，不再跳转详情页 ✅

- 建议后端修复：空结果返回 `{ items: [], total: 0 }`

### 3.2 Bug 修复

**BUG-UM-001 ✅（已修复）**

- **文件**：`src/sections/user-manage/kpi-summary.tsx`、`src/sections/user-manage/view/user-manage-view.tsx`
- **现象**：执行"禁用"/"启用"用户操作后，KPI 统计卡片"已禁用"计数不更新，仍显示旧值；但表格行状态已正确变更
- **根因**：`KpiSummary` 组件内部用 `useEffect(fn, [])` 独立管理 stats 请求，挂载后只请求一次，状态变更后无触发机制刷新
- **修复**：
  1. `KpiSummary` 新增 `refreshKey?: number` prop，加入 `useEffect` 依赖
  2. `UserManageView` 新增 `kpiRefreshKey` state，在 `handleCreate`、`handleConfirm`（成功后）、`executeBulkStatus`（完成后）中 `setKpiRefreshKey(k => k + 1)`
- **验证**：禁用→KPI "已禁用 1"；启用→KPI "已禁用 0"，实时同步 ✅
