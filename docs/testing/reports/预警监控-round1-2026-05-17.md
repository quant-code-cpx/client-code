## 2. 已修复缺陷

### FIX-020 · AA 查看证据链 P0 崩溃 — `getAnomalyTypeConfig` 未识别类型

**根因**：

- `anomaly-detail-drawer.tsx:321 / :354` 对 `detail.relatedAnomalies` 与 `detail.history` 做 `.map()`，循环内 `const cfg = getAnomalyTypeConfig(rel.anomalyType)`
- 当后端 `history.anomalyType` 不在 FE 三类枚举（`VOLUME_SURGE / CONSECUTIVE_LIMIT_UP / LARGE_NET_INFLOW`）中时，`ANOMALY_TYPE_MAP[type]` 返回 `undefined`
- 紧随其后 `<Label color={cfg.color}>` 触发 `Cannot read properties of undefined (reading 'color')`
- 直接被 React Router ErrorBoundary 接管，整个 `/alert/anomalies` 路由白屏，仅显示原始堆栈

**修复**：

文件 `src/sections/alert/anomalies/anomaly-type-config.ts`：

```ts
const UNKNOWN_ANOMALY_TYPE_CFG: AnomalyTypeConfig = {
  type: 'VOLUME_SURGE',
  label: '未知异动',
  shortLabel: '未知',
  color: 'info',
  icon: 'solar:question-circle-bold',
  ruleDesc: '后端返回未识别的异动类型，已按未知项展示',
  unitHint: '',
};

export function getAnomalyTypeConfig(
  type: AnomalyType | string | null | undefined
): AnomalyTypeConfig {
  if (!type) return UNKNOWN_ANOMALY_TYPE_CFG;
  return ANOMALY_TYPE_MAP[type as AnomalyType] ?? UNKNOWN_ANOMALY_TYPE_CFG;
}
```

**回归**：刷新 `/alert/anomalies` → 点查看证据链 → Drawer 正常打开，history 条目 Label 显示「未知」、原值字段保留（暴露 OBS-AA-B）。

### FIX-021 · AL 页面 P0 加载崩溃 — `(summary ?? []).slice is not a function`

**根因**：

- 后端 `/api/alert/limit-summary` 返回 `summary` 字段非数组（可能空对象 / null / 单对象）
- `top-summary.tsx` 多处 `(summary ?? []).slice()`、`summary.reduce()`、`summary.length` 直接当数组用
- 触发 `TypeError: (...).slice is not a function`，整页崩溃

**修复**：

文件 `src/sections/alert/limit/top-summary.tsx`：

- 组件入口新增 `summaryList = useMemo<LimitSummaryDay[]>(() => (Array.isArray(summary) ? summary : []), [summary])`
- 所有后续使用全部替换 `summary` → `summaryList`：
  - `kpis` 内 `today / avg5UpCount`
  - `sparklineUp / sparklineMaxStreak` 两个 useMemo
  - JSX 内 `summary && summary.length >= 2` 与对应 `summary.length / summary[0]?.limitUp / .maxStreak`

**回归**：刷新 `/alert/limit-list` → 页面正常加载，6 张 KPI、题材 Top 10、梯队、主表、tabs 全部渲染。
