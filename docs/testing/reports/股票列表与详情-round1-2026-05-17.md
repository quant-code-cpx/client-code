## 2. 本轮修复（已合入）

### SD-007 + SD-013 · 财务 YoY 着色与 A 股「红涨绿跌」legend 一致

- **文件**：`src/sections/stock-detail/stock-detail-financials-tab.tsx`
- **现象**：legend 文案「同比颜色: 红涨绿跌」但实际渲染相反（+正 → success.main 绿，−负 → error.main 红）。同时关键指标 subtab 的「营收同比 / 净利润同比」两列原本无色彩，与设计稿不一致。
- **修复**：
  - 利润表 YoY caption color：`yoyVal > 0 ? error.main : yoyVal < 0 ? success.main : text.secondary`
  - 关键指标 `FINANCIAL_FIELDS` 引入 `riskSemantic?: boolean`，对 `revenueYoy` / `netprofitYoy` 设为 true；按相同规则上色。
- **验证**：脚本读取 cell `color` 值，`-13% → rgb(34,197,94)`、`+1.9% → rgb(255,86,48)`；与 legend 一致。

### SD-014 · 公司与股本「成立日期」字段错配 + 未格式化

- **文件**：`src/sections/stock-detail/stock-detail-company-tab.tsx`
- **现象**：`established = str(basic?.listDate)` → 直接渲染 ISO `1991-04-03T00:00:00.000Z`；且 listDate 实际为「上市日期」，与标签「成立日期」语义不符（Tushare basic 不返回 setupDate）。
- **修复**：
  - 引入 `fDate` 格式化（`src/utils/format-time`）。
  - InfoRow 标签从「成立日期」改为「上市日期」（与页面头部一致）。
- **验证**：浏览器 DOM 文本 `上市日期1991-04-03`。

每次修改均通过：

```
node_modules/.bin/eslint --fix <file>   # 退出 0
node_modules/.bin/eslint <file>         # 退出 0 且无输出
yarn build                              # ✓ built in 7.x s
```
