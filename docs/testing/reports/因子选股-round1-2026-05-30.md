## Bug 修复记录

### BUG-FAS-001 · 条件命中漏斗显示"剔除 NaN，缺失 "

| 字段 | 内容 |
| ---- | ---- |
| **严重等级** | P1 |
| **根因分类** | `code-bug` |
| **根因** | `cutCount = item.beforeCount - item.passCount`，而后端 `conditionPassCounts[].beforeCount` 尚未实现（BE-3），返回 `undefined`，`undefined - 2595 = NaN`；同理 `item.missingCount` 为 `undefined`，渲染为空白 |
| **修复文件** | `src/sections/factor/screening/screening-funnel-preview.tsx` |
| **修复内容** | 1. `maxBefore` 计算改用 `d.beforeCount ?? d.passCount`；2. 新增 `effectiveBefore` fallback；3. `passRatio` 当 `beforeCount` 未定义时默认为 1；4. `cutCount` 改为 `beforeCount !== undefined ? ... : null`；5. 显示层用 `?? '—'` 兜底，渲染为 "— → N（剔除 —，缺失 —）" |
| **状态** | ✅ 已修复 |

| 字段 | 内容 |
| ---- | ---- |
| **严重等级** | P1 |
| **根因分类** | `code-bug` |
| **根因** | 前端读 `summary.universeCount`，但后端实际返回的字段名为 `universeSize: 3883` |
| **修复文件** | `src/sections/factor/screening/screening-result-kpi-strip.tsx` |
