## Bug 修复记录

### BUG-PA-01（已修复）

| 字段         | 内容                                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------- |
| **严重等级** | P2                                                                                                       |
| **根因分类** | `code-bug`                                                                                               |
| **问题描述** | 删除"自选股组"或"组合持仓"规则时，confirm dialog 文案为 `确定删除股票  的「涨幅超过」规则？`，标的名空缺 |
| **根因**     | `alert-price-rule-table.tsx` 中硬编码 `确定删除股票 {deleteTarget?.tsCode}`，未处理 `tsCode=null` 的情况 |
| **修复方案** | 新增两个辅助函数（`getDeleteSourceTypeName` / `getDeleteTargetLabel`），按 `tsCode / watchlistId / portfolioId` 分支返回正确来源类型名称与标的标签 |
| **修复文件** | `src/sections/alert/alert-price-rule-table.tsx`                                                          |
| **修复效果** | 单股：`确定删除股票 300308.SZ 的「涨幅超过」规则？`；自选股组：`确定删除自选股组 「XXX」 的…`；组合：`确定删除组合 「YYY」 的…` |
| **回归验证** | PASS — textContent `"确定删除股票 300308.SZ 的「涨幅超过」规则？"` 符合预期                              |

### OBS-PA-WATCHLIST（P2，backend-bug）

| 字段     | 内容                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| **现象** | 新建规则弹窗切换"自选股组"模式时，下拉列表为空                                             |
| **根因** | `getWatchlists()` API 返回 401 Unauthorized，异常被 `.catch(() => {})` 静默吞掉，前端得到空数组 |
| **影响** | 无法通过 UI 创建自选股组维度预警规则                                                      |
| **状态** | 后端鉴权 / 权限问题，非前端 bug；前端已正确调用                                           |
