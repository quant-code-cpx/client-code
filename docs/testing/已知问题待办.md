# 已知问题待办（Testing Backlog）

> 本文件记录测试过程中发现、**当前尚未完全修复**的问题。  
> 已修复问题归入对应页面的测试报告（`docs/testing/reports/`）。  
> 每个问题必须填写：模块、严重等级、根因分类、状态、下一步行动。

---

## 严重等级说明

| 级别 | 含义                                |
| ---- | ----------------------------------- |
| P0   | 阻断核心流程，需立即修复            |
| P1   | 主要功能受损，计划内修复            |
| P2   | 次要功能 / 展示缺陷，不影响核心使用 |
| P3   | 体验优化 / 边缘场景，后续迭代处理   |

## 根因分类说明

| 类型            | 含义                          |
| --------------- | ----------------------------- |
| `code-bug`      | 前端代码逻辑错误              |
| `data-missing`  | 后端数据库历史数据不足        |
| `data-coverage` | 数据口径 / 数据表覆盖范围不够 |
| `design-gap`    | 业务设计未明确该场景          |
| `backend-bug`   | 后端接口逻辑错误              |
