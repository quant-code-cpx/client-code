# 知识库：从零到一的金融、投资、交易与量化知识路线

> 状态：内容总纲 v1
> 日期：2026-08-13
> 受众：没有金融、经济、会计、统计或编程基础的学习者
> 结构边界：只规划“大专题 → 小专题 → 知识点”，不展开知识点正文
> 市场视角：以中国个人投资者和 A 股为主要落点，同时建立全球比较能力

## 一、路线设计原则

1. 先学“怎样不受伤”，再学“怎样赚钱”；风险、诈骗、合规和账户安全前置。
2. 先理解钱、企业、经济和市场为何存在，再学习指标、策略和模型。
3. 先理解股票背后的公司，再研究股票价格；先理解数据口径，再计算信号。
4. 先学习统计证据和研究设计，再接触回测、机器学习和自动交易。
5. 先完成模拟、成本和压力测试，再进入小资金实盘；杠杆与衍生品最后开放。
6. 概念从生活语言进入，再过渡到财务语言、数学语言、代码语言和交易语言。
7. A 股规则、税费、账户权限、交易时段等动态内容必须记录“权威来源、版本、生效日、复核日”，不能当成永久常量。
8. 历史表现、模型输出和专家观点都不是保证；知识库提供判断工具，不提供确定性收益承诺。

## 路线维护边界

- 本版只冻结“大专题—小专题—知识点”三级目录，不展开定义、案例、公式推导、练习、测验或交易建议。
- 后续补充内容时一次只处理一个小专题，必须保留其所属大专题和知识点边界；发现遗漏时先修改路线版本，再扩写正文。
- 制度、税务、交易时段、申报限制、涨跌幅、费用、适当性门槛等动态内容，必须记录主管机关、效力状态、修订或废止关系、暂缓条款、过渡期、适用主体、适用产品、适用账户、发布日期、生效日期、截至日期和下次复审日期。
- 历史事实、统计数据、实证结论与观点判断必须分开；任何收益示例都同时展示成本、风险、样本区间和不确定性。
- 路线不承诺“学完即可盈利”；最终目标是建立可验证、可复盘、能识别未知并优先保证资本生存的决策体系。
